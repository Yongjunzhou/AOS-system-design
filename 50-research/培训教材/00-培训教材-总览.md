> 本文件是培训教材的权威框架。与教材书共享同一套架构——**一个源（教材书），两个产品（书=叙述形态，训练=研讨/问题形态）**；术语表、概念档案集、误解清单的权威都长在书末附录，训练引用书，不各自维护。

**教学主线（由浅入深）**：发尺子（概念的语法）→ 我们在做什么（工程）→ 三基座（定/造/读标尺）→ 需求工程（标尺从哪来）→ 需求的完整性（标尺要全）→ 设计开发落地（标尺怎么被造）→ 评审验证确认（三个看门人）→ 工程师（把四层背在身上的人）→ 架构（最重要的决定）→ 架构设计（五块设计）→ 架构决策（不可逆的提前投资）→ 配置管理（让一直在变说得清）→ 治理（谁掌舵）→ 整合（走完全程）→ 架构师（回到把链背在身上的人，回答书名）→ **附录（把尺子收进五个抽屉，随时回来取用）**。

## 三、单元模板（六件套）

每个单元六个小节，顺序固定：

1. **单元导读**——主题、开场破题提示、本单元要反转的直觉（书"反直觉命题"）、本轮题卡的内在逻辑、同类分组说明。
2. **题卡（打印分发）**——学员版问题纸，答题要求固定（组内讨论 25 分钟 / 答案 ≤5 行 / 上台讲解 4–5 分钟 / 观点不同必须给理由）。设计规则见[问题萃取流程 附录 · 题卡设计规则 15 条](00-培训教材-问题萃取流程.md)（出题操作规程，**单一权威在此**；本块只保留题卡件套定义）。
3. **点评要点·讲师版**——每题三栏：各组答案常见形态分级（弱/中/好）+ 讲师判读、产品侧 vs IT侧、**反转话术**、参考答案要点（引用书章节）。
4. **知识卡片**——一页图（书"概念总图"）+ 金句（书"本章判据"提炼）。
5. **课后作业**——3 题：2 题来自书"练习"（与题卡同源），1 题**"回部门落地"**（借鉴《正向设计》"请给出部门最应该改进的三个事项"，两周后回来报告）；**回部门落地可附作业指南**（照着做的步骤 + 话术，见问题萃取流程第6步）。
6. **课后阅读指引**——对应书章 + 附录检索位（附录 A 术语表 / B 概念档案集 / C 误解清单 / E 练习答案）。

## 四、书↔训练逐格映射

| 书（教材书） | 训练（培训教材） |
|---|---|
| 章首·误解现场 | 题卡 Q1（破题题） |
| 开篇·本章枢纽（骨架先行） | 导读概念锚点 + 讲师版骨架点评 |
| 第一幕 是什么（概念卡四问化） | 讲师版九格点评（四问卡逐格） |
| 第二幕 不是什么（磨边弧） | 真悖论 / 辨边界题素材 |
| 第三幕 往哪去（运用）+ 案例进展（幕末） | 第二组·落地 / 方法时刻题 |
| 方法底座时刻 | 方法时刻题（问题萃取流程 规则 15） |
| 章末·认知反转（见过→拥有） | 讲师版反转话术（掌握线落点） |
| 本章判据 / 概念总图 | 知识卡片（一页图 + 金句） |
| 练习 / 自查 | 题卡 Q2~Q5 + 课后作业 |
| 案例设定（冰链 / 恒信） | 题卡题目语境 + 讲师版产品侧 vs IT侧 |

## 五、分组研讨规则

- **同题异答**：产品组和 IT 组拿到**相同的 5 题**，各自用自己的工作语境作答。
- **镜像对照**：老师把两边的答案摆在一起点评——产品组的例子和 IT 组的例子是**同一个概念的两面**，这正是本套概念"领域中立"的证据。
- **案例走位**：主案例章 = 恒信主 2/4/6/7/11/13、冰链主 3/5/9/10/12、第8章双线判词、第14章双线合流、第15章双线合流续；另一条线做"镜照"段落。
- **答题纪律**：允许观点不同，但必须给出理由；每题答案不超过 5 行；每组选派一人上台讲解。

## 七、问题萃取流程（从教材到讨论问题的方法）

把教材书某一章转成一个培训单元（六件套）的**可复用八步流程**：①读透章 → ②掌握清单 → ③误解库 → ④陷阱清单（含网搜）→ ⑤纠错策略 → ⑥落地工具 → ⑦合成题卡 → ⑧逐格同步。已跑通第1、2章（单元一/二）。详见 [00-培训教材-问题萃取流程.md](00-培训教材-问题萃取流程.md)，铺开单元三~十六按它重跑。每章八步分析**每一步的结果内容**单独存档为 `教材书/0N-第N章-主题-从教材到问题分析.md`（与教材书章文件同目录、章原名+后缀，只记每步结果内容，如 [02-第2章-工程-从教材到问题分析.md](../教材书/02-第2章-工程-从教材到问题分析.md)）。**单元八（工程师）为角色章**，无新概念档案，走"六项能力清单"收束（分析见 [08-第8章-工程师-从教材到问题分析.md](../教材书/08-第8章-工程师-从教材到问题分析.md)）；**单元十五（架构师）与单元十六（附录）为特殊单元**：单元十五（架构师）为角色收束章，无新概念档案，走"十项能力清单"收束（分析见 [15-第15章-架构师-从教材到问题分析.md](../教材书/15-第15章-架构师-从教材到问题分析.md)）；单元十六（附录）走"参考原理收束"——以五个抽屉结构 + 该查时查全替代概念档案（分析见 [16-附录-把尺子收进五个抽屉-从教材到问题分析.md](../教材书/16-附录-把尺子收进五个抽屉-从教材到问题分析.md)）。
