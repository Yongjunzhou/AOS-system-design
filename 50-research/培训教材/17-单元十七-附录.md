## 一、单元导读

### 主题

这一章回答全书收束处的问题：**这本书的尺子收在哪里？** 正文十五章发的是概念、判据和案例——它们收在书末的五个抽屉里（附录 A 术语表 / B 概念档案集 / C 误解清单 / D 标准索引 / E 练习答案）。附录不新增任何概念，它的掌握标准是它自己演示的内容：**该查时查全，不是每次量全、不是从不查。** 学完这一章，你不必多背一个概念，但要知道"该查时去哪取尺子"。

### 开场破题（对应附录头部）

念出书里附录开头那句话："正文十五章，发的是概念、判据和案例。本附录把它们归档成五个抽屉，供你随时回来取用。" 然后问各组：附录自己说它"不新增任何概念"——那它是谦虚，还是真没什么可学的？"正文读完了，附录可有可无"这句话，你同不同意？大多数人一开始都站在"附录 = 书的尾巴"这边——这正是这一章要推翻的直觉。

### 本单元要反转的直觉

- **附录可有可无，正文读完就够了**（× 五抽屉是"查"字落地的地方，掌握标准长在这里）
- **附录不新增任何概念 = 附录没内容 / 不用学**（× 不新增概念恰恰是价值——把正文发过的尺子收进随时能回来取用的地方）
- **真懂的人从不查附录**（× 掌握 = 该查时查全，不是从不查；该查时不查才是没掌握）
- **背熟术语表 = 会用**（× 术语宪法的功能是查不是背；同词异义时回来确认指称）
- **把附录从头读到尾 = 掌握了附录**（× 字典不是读的是查的；掌握 = 该查时查全，不是每次量全）
- **跨域对不上的词，先凭感觉讨论**（× 先查本表，再谈别的——恒信"合同编号" vs 冰链"数据所有权"）
- **E 区给的是标准答案，照抄就对了**（× 给的是"往哪个方向想、用哪把尺子"，不是唯一答案）
- **附录内容我都学过了，不用查**（× 学过 ≠ 记得在哪；"学过了"正是最需要查的时候）

### 本轮题卡的内在逻辑（10 题 2×5 + 方法时刻）

**第一组 · 概念与原理（先立概念）**：Q1 附录是什么 + "不新增任何概念"破题（破题·概念本身）→ Q2 正文 / 五抽屉 / 第1章九格尺子的关系（概念关系）→ Q3 附录可有可无 vs 掌握标准（真悖论）→ Q4 背熟 vs 查（真悖论）→ Q5 字典读 vs 查（真悖论）。由"是什么"走到"为什么"。

**第二组 · 落地与实践（用尺量）**：Q6 术语宪法 + 跨域先查表（判据运用·跨部门争论）→ Q7 档案字典 + 误解两用（判据运用·第13章版本当基线）→ Q8 标准出处 + 答案方向（判据运用·第3章评审会）→ **Q9 方法时刻·该查时查全**（规则 15：亲手做一次"该查时查全"练习——查一个概念 / 用检索练习代替重读）→ Q10 回部门"查全体检"（落地生根）。判据运用 + 落地动作。

### 同类分组说明

产品组与 IT 组答同一组题，答案互为镜像。这一章的题尤其适合镜像对照：附录的术语表里本来就躺着两个世界的词——恒信"合同编号"（第8章对账 / 第14章三方对不上）与冰链"数据所有权"（第10章立 / 第12章受控导出），是"同一个概念、两个世界、判据不变"的现场证明。两边各用自己的词做"该查时查全"练习，查全路径（A 术语宪法 → B 档案 → C 误区 → D 出处 → E 方向）结构相同。**这一章不教新概念，教的是"你会不会回来取尺子"。**

## 二、题卡（打印分发）

**答题要求**：组内讨论 25 分钟 / 答案 ≤5 行 / 上台讲解 4–5 分钟 / 观点不同必须给理由。

### 第一组 · 概念与原理

**Q1｜附录到底是什么？"不新增任何概念"是谦虚还是实话？**
"有人把附录当一本书的尾巴：正文读完了，附录可有可无。可这一章开头就说它『不新增任何概念』——既然不新增，它到底在干嘛？请用五个抽屉给『附录是什么』下一个定义，并说说『不新增任何概念』这句话，是谦虚还是实话？"

追问：① 五个抽屉各是什么（A 术语表·宪法 / B 概念档案集·规格 / C 误解清单·警示 / D 标准索引·出处 / E 练习答案·对照）？② "不新增任何概念"听起来像"没内容"——为什么恰恰相反，这是它的价值所在（把正文发过的尺子收进随时能回来取用的地方）？③ 你们上次读完一本书 / 一份手册，多久没回来看过它的附录 / 索引了？

**Q2｜正文、五抽屉、第1章九格尺子，什么关系？**
"请给出 正文、附录 A/B/C/D/E、第1章九格尺子 的关系——为什么说附录是第1章那个『查』字落地的地方？恒信的『合同编号』和冰链的『数据所有权』跨域对不上了，先查哪个抽屉再谈别的？附录 C 和 §1.8.3 预告表是什么关系？附录 E 和训练教材题卡是什么关系？"

追问：① 九格尺子"该查的时候查全"——五个抽屉怎么把"查"字落地（说不清的词翻 A 或 B / 误解错在哪翻 C / 原理出处翻 D / 对答案翻 E）？② 跨域先查表 + 出处/定义分工——恒信"合同编号" vs 冰链"数据所有权"先查 A；"出自哪个标准"查 D、"怎么定义"查 A/B、"对答案"查 E——按"问什么"决定查哪个抽屉？③ 你们把"书"和"手册 / 工具"分得开吗——附录是叙述还是参考？

**Q3｜附录既然不新增概念，为什么还要学它？**
"附录不新增任何概念，正文读完了，它可有可无——很多人这么想。可这一章又说：附录的掌握标准（该查时查全）正是附录自己要演示的。两个都对吗？什么判据分清『什么时候该查、什么时候不必查』？"

追问：① 该查时查全 vs 每次量全 vs 从不查——三种态度各自错在哪？② "该查时查全"是不是说"查得越勤越好"？什么时候"不必查"反而是对的（正在用的、随手能调用的、已内化的）？③ 你们部门最近一次"这个词什么意思"的争论，是查了，还是争了？

**Q4｜"真懂的人从不查表"和"背熟术语表 = 会用"——哪个对？**
"『真懂的人从不查表』和『背熟术语表 = 会用』——这两句是同一个直觉的两面：把『查』当『不熟』。可这一章说：掌握 = 该查时查全，不是每次量全、不是从不查。哪个对？什么判据区分『该查』和『不该查』？"

追问：① 术语宪法的功能是"查"不是"背"——遇到同词异义（如恒信"合同编号" vs 冰链"数据所有权"），背过的人为什么还要回来查表？② "查"在什么场合是负价值（每次量全：逢词必查、打断思路），什么场合是正价值（该查时查全：说不清 / 要检验时）？③ 你们团队有人"从不查"某个规范 / 标准，靠的是记忆还是运气？

**Q5｜"薄格可省，不可跳过"——省什么、不跳过什么？**
"字典是读的还是查的？——有人把附录 B 从头读到尾、每格都背，觉得这样才叫『查全』；可这一章说字典式查询『薄格可省，不可跳过』。『可省』和『不可跳过』听起来像打架——到底省什么、不跳过什么？什么判据分清『该查哪格』和『哪格可以省』？"

追问：① 字典式查询从①定义开始到⑧误区为止——为什么必须从定义开始？② "薄格可省"省的是内容薄的格（定义已够用），"不可跳过"不可跳过的是判断本身——尤其⑧误区格：最容易切错的那刀没人警告，跳过误区格 = 把最容易错的地方跳过去了？③ 你们上次查一个概念档案，是查缺的那格，还是从头背到尾？

### 第二组 · 落地与实践

**Q6｜恒信"合同编号"和冰链"数据所有权"都在吵——先查表还是先讨论？**
"恒信为『合同编号』要不要改，法务 / 财务 / 业务三方各执一词；冰链为 M3 温度数据的『数据所有权』归属，也吵到架构评审。附录 A 的引语说：遇到跨域对不上的词，先查本表，再谈别的。用『术语宪法』和『跨域先查表』两个判据，给这两个跨部门争论各开一张『先查表再讨论』的动作清单。"

追问：① 跨域先查表——"先查本表再谈别的"，查的是什么（这个词指称哪个概念 / 哪个世界 / 哪个指称）？② 为什么"先查"比"先争"省时间（查错概念 = 白争：恒信编号是"合同对象"、冰链数据所有权是"追溯责任"，两个词两套定义）？③ 你们部门最近一次跨部门争论，吵之前查过双方各自的术语表吗？

**Q7｜第13章"版本号 = 基线"怎么判错的？**
"第13章，冰链把固件版本当基线，疾控审计时批次追溯查不清；恒信靠『另存为 v2』管合同版本——两个团队都把『版本』当『基线』。当时要是先翻附录 B 的『基线』卡⑧误区格（版本号≠基线）+ 附录 C 第12行预习『版本是刻度、基线是参照』，审计那关会不会更好过？用『档案字典』和『误解两用』两个判据，说出两个团队各自漏了哪个查询动作。"

追问：① 档案字典：字典式查询从①定义到⑧误区——冰链背了定义、跳过了哪格（⑧误区：版本号就是基线）？② 误解两用：C 区读前预习 / 读后检验——两用都做，和只用一半（只当预习不当检验）差别在哪？③ 你们查概念档案，是从①定义到⑧误区走全，还是只记定义？

**Q8｜"质量"的出处和"等级 ≠ 质量"的说法，分别查哪个抽屉？**
"第3章冰链评审会，有人拿『精度规格比竞品高』当『质量没问题』。评审被追问：『质量』这条定义的权威出处是什么？——翻附录 D 找到 ISO 9000:2015 §3.6.2；那『等级高 ≠ 质量好』这个说法对不对？——翻附录 E 第3章答案要点：高档车可以是差质量。用『标准出处』和『答案方向』两个判据，说明 D 和 E 各自回答什么问题、什么情况该查哪个抽屉。"

追问：① 标准出处：D 区回答"这条原理出自哪个标准"——版本号为什么是正文实际引用的版本（锚定概念、防引用错版本）？② 答案方向：E 区为什么给"方向"不是唯一答案——"等级高 ≠ 质量好"是唯一答案，还是"往哪个方向想"的方向？③ 你们引用一个标准时，是查到条款号（锚定概念），还是只写标准名？

**Q9｜亲手做一次"该查时查全"练习（方法时刻）**
"这一章的方法底座时刻就是『该查时查全』本身——附录不新增任何概念，它的掌握标准就是它的内容。请亲手做一次『该查时查全』练习：① 从附录 A 挑一个你刚学过的词，用 B（档案）/ C（误区）/ D（出处）/ E（答案方向）四抽屉把它查全一次；② 或者：把你们部门最近一次『复习』改成『检索练习』——不重读，直接合上书回答『这个概念的定义 / 误区 / 出处』，答不上来的那格，就是你要查的格。做完对照『该查时查全 vs 每次量全 vs 从不查』三态——你落在哪个态？"

追问：① 你查的这个词，最容易被切错的误区格是哪格（B 卡⑧ / C 区行）？② 你的"检索练习"暴露了哪格没查全——该查时查全的标准是什么（答不上来的那格 = 该查的格）；附录收束说"概念是刀，系统是大象"——你这次查全是在"磨刀"，还是"数刀"？③ 你刚才是"该查时查全"，还是"每次量全"（从头到尾全读）？——有标签是见过，该查时查全才算拥有。

**Q10｜给你们的部门做一次"查全体检"**
"结合你们部门现状，用『该查时查全』给部门做一次『查全体检』——选出最近一次『说不清 / 跨部门争论 / 引用标准只写名字』的事，用五个抽屉把它查全，给出最该改进的三件事，每件落到一个动作。"

追问：① 五抽屉先查哪两个（最常被争的词查 A/B，最常被引错的标准查 D）？② 你们部门有没有"从不查"/"每次量全"的人——怎么用"该查时查全"纠正（该查时查全不是查得越勤越好，也不是从不查）？③ 两周后回来报告：查全了哪个词 / 哪条标准、部门改了什么动作？

## 三、点评要点·讲师版

> 点评纪律：先表态后翻案 / 反转精确不造新误解 / 判据配机制 / 归责到可对照动作 / 教机制不教断言 / 先立尺子再翻案 / 拉开强度层次 / 每个纠正落到可操作动作 / 单一权威不另立标准 / 网搜当佐证。

### Q1 附录到底是什么？"不新增任何概念"是谦虚还是实话？

| 答案分级 | 形态 | 讲师判读 |
|---|---|---|
| 弱 | "附录是书的尾巴，不新增概念所以没内容，读完正文就够了。" | 正是要翻的——把"不新增"当"没价值" |
| 中 | "附录有五抽屉。" 结论对，判据缺 | 五抽屉说出了，"该查时查全"的掌握标准没接上 |
| 好 | "附录不新增任何概念，它把正文发过的尺子收进随时能回来取用的地方——A 术语宪法 / B 档案字典 / C 误解警示 / D 标准出处 / E 答案方向；掌握 = 该查时查全，不是每次量全、不是从不查。" | 定义 + 参考原理 + 掌握标准全咬合，能当场给"附录是什么"下结论 |

**产品侧 vs IT侧**：产品组举"M3 温控箱查'固件版本是不是基线'得回第13章"；IT 组举"查'合同编号'归哪个概念得回第8章"。两边都要翻"附录 = 尾巴"——五抽屉是查字落地的地方，掌握标准（该查时查全）长在这里。

**反转话术**（对应附录头部 + 附录收束）：附录不新增任何概念，恰恰是它的价值——它是一本"尺子收容所"，不教你新概念，教你"该查时去哪取尺子"。五个抽屉：**A 术语表** = 术语宪法（正文用词唯一权威，T-01~112）；**B 概念档案集** = 字典（23 张完整九格 + 12 散见各章，共约 35 张）；**C 误解清单** = 警示（15 行"病 → 药 → 判据"三栏）；**D 标准索引** = 出处；**E 练习答案** = 对照（与训练教材题卡同源）。第1章说九格是"该查的时候查全"的尺子——**这五个抽屉，就是那个"查"字落地的地方。** "不新增任何概念"不是谦虚，是实话，也是它的全部底气。

**参考答案要点**：五抽屉见头部；"不新增任何概念"见头部 + 附录收束；该查时查全见头部用法段。

### Q2 正文、五抽屉、第1章九格尺子，什么关系？

| 答案分级 | 形态 | 讲师判读 |
|---|---|---|
| 弱 | "附录 = 索引，正文 = 内容，九格 = 学习方法。" | 关系结构错误——五抽屉不是索引，是规格 |
| 中 | 能说"附录 = 第1章查字落地的地方"，但 C/E 的关系没接上 | "查字落地"对了，预告表 / 题卡同源缺 |
| 好 | "正文是叙述（从头读到尾），五抽屉是参考（随时回来取用）；九格尺子说'该查的时候查全'，五抽屉把'查'字落地——说不清的词翻 A/B、误解错在哪翻 C、出处翻 D、对答案翻 E；C 是 §1.8.3 预告表的完整版；E 与训练教材题卡同源（考把话说准）。" | 关系结构 + 落地 + 同源全到位 |

**产品侧 vs IT侧**：产品组查"数据所有权"（第10章立 / 第12章受控导出）；IT 组查"合同编号"（第8章对账 / 第14章三方对不上）。两边都容易把附录当"目录"——五抽屉各有规格，不只是指针。

**反转话术**（对应头部 + A/C/E 引语）：正文与附录不是"内容 vs 指针"的关系，是**"叙述 vs 参考"**的关系——正文是挥刀的人，附录是刀的目录 / 规格 / 警示 / 出处 / 对照。第1章九格尺子说"该查的时候查全"，五抽屉就是那个"查"字落地的地方：遇到说不清的词翻 A 或 B；"这个误解错在哪"翻 C；"这条原理出自哪个标准"翻 D；做完练习想对答案翻 E——**按"问什么"决定查哪个抽屉**。附录 C 是 §1.8.3 预告表的完整版；附录 E 与训练教材题卡同源——同源不是相同，E 给方向，题卡考你有没有把话说准。

**参考答案要点**：五抽屉关系见头部；C 预告表见 C 引语；E 同源见 E 引语 + 附录收束。

### Q3 附录既然不新增概念，为什么还要学它？

| 答案分级 | 形态 | 讲师判读 |
|---|---|---|
| 弱 | "附录可有可无，正文读完就够了；该查时查全就是每次都要查。" | 两个极端都要翻——把"不新增"当"没价值"、把"查全"当"每查" |
| 中 | "该查时查全，不是每次量全、不是从不查。" 三态说出了，场合判据缺 | 三态对了，"什么时候不必查"没接上 |
| 好 | "正文阶段不必查（内容都学过），查的时刻在'说不清 / 要检验'时——该查时查全；每次量全是把字典当全书读，从不查是记忆崇拜。" | 三态 + 场合判据 + 机制全到位 |

**产品侧 vs IT侧**：产品组"背熟固件版本号，审计时凭记忆答"；IT 组"背熟合同状态字典，评审时凭记忆答"。两边都要翻"从不查 = 懂"——该查时不查才是没掌握。

**反转话术**（对应头部用法段 + 附录收束）：附录不新增任何概念，所以"正文阶段不必查"——你学的内容都来自正文。但"不必查"不等于"从不查"：当你**说不清一个词、要检验一个说法、要对练习答案**时，就该回来查——这就是**该查时查全**。三个极端排开：**每次量全**（字典当全书读、逢词必背）是过度——字典不是读的；**从不查**（凭记忆硬扛）是记忆崇拜——该查时不查才是没掌握；只有**该查时查全**是掌握标准。反身：你们部门最近一次"这个词什么意思"的争论，是查了，还是争了？

**参考答案要点**：三态见头部用法段 + 附录收束；该查时查全见第1章九格尺子。

### Q4 "真懂的人从不查表"和"背熟术语表 = 会用"——哪个对？

| 答案分级 | 形态 | 讲师判读 |
|---|---|---|
| 弱 | "真懂的人从不查表，背熟就算会用。" | 正是要翻的——把"查"当"不熟" |
| 中 | "背熟不够，还要会用。" 结论对，场合判据缺 | "什么时候该查"没分清 |
| 好 | "术语宪法的功能是查不是背——同词异义时回来确认指称（恒信编号 vs 冰链数据所有权）；该查时查全（说不清 / 检验时），每次量全（逢词必查）是负价值，从不查是记忆崇拜。" | 术语宪法 + 三态 + 场合判据全到位 |

**产品侧 vs IT侧**：产品组"水忠凭手感不用查"；IT 组"万晖凭记忆不用查规格"。两边都要翻"从不查 = 懂"——查的是尺子，不是面子。

**反转话术**（对应 A 引语 + 头部）："真懂的人从不查表"和"背熟术语表 = 会用"是同一个直觉的两面——**把"查"当"不熟"**。但术语宪法的作用恰恰是"查"：凡是正文用词以本表为准；遇到同词异义（恒信"合同编号" vs 冰链"数据所有权"），背过的人也要回来查表——因为**背的是词的形，查的是概念的指称**。查在什么场合是负价值？每次量全——逢词必查、打断思路；查在什么场合是正价值？该查时查全——说不清、要检验时。反身：你们团队有人"从不查"某个规范 / 标准，靠的是记忆还是运气？

**参考答案要点**：术语宪法见 A 引语；跨域先查表见 A 引语；三态见头部 + 附录收束。

### Q5 "薄格可省，不可跳过"——省什么、不跳过什么？

| 答案分级 | 形态 | 讲师判读 |
|---|---|---|
| 弱 | "字典就是读的，从头背到尾才算查全。" | 正是要翻的——把"查"当"读全" |
| 中 | "薄格可省，不可跳过。" 句子说了，机制缺 | "省什么、不跳过什么"没分清 |
| 好 | "字典式查询查缺的那格，不是全背；薄格可省省的是内容薄的格（定义已够用），不可跳过不可跳过的是判断本身——尤其⑧误区格：最容易切错的那刀没人警告。" | 可省 / 不可跳过的机制 + 误区格全到位 |

**产品侧 vs IT侧**：产品组背"配置卡"从头到尾；IT 组背"基线卡"从头到尾。两边都容易跳过误区格——跳过"版本号≠基线"，第13章就判错。

**反转话术**（对应 B 引语）：字典是查的，不是读的。"薄格可省"和"不可跳过"不打架——**省的是内容薄的格**（定义已够用的格不用背），**不可跳过的是判断本身**：每一格都要过目，再定省不省；尤其**⑧误区格**——最容易切错的那刀，跳过了，就是第13章把"版本号"当"基线"。反身：你们上次查一个概念档案，是查缺的那格，还是从头背到尾？

**参考答案要点**：字典式查询见 B 引语；从①定义到⑧误区见 B 引语；⑧误区格见 B 区各卡。

### Q6 恒信"合同编号"和冰链"数据所有权"都在吵——先查表还是先讨论？

### 金句（书"附录收束"与"本章判据"提炼）

- **附录不新增任何概念——它只是把正文发过的尺子，收进了一个随时能回来取用的地方。**
- **掌握 = 该查时查全，不是每次量全、不是从不查。**
- 术语宪法：凡是正文用词以本表为准；跨域先查表——遇到跨域对不上的词（恒信"合同编号" vs 冰链"数据所有权"），先查本表，再谈别的。
- 档案字典：字典式查询，从①定义开始到⑧误区为止——**薄格可省，不可跳过**。
- 误解两用：读完正文用 C 检验把话说准；读正文之前用 C 当预习。
- 标准出处：问"出自哪个标准"查 D，问"怎么定义"查 A/B。
- 答案方向：要点给的是"往哪个方向想、用哪把尺子"，不是唯一答案。
- 学习闭环：遇到任何一题答不上来，先回对应章节，再回这五个抽屉。
- **概念是刀，系统是大象。切得再细，也要缝得回来。**

1. **书练习（检索练习）**：选一章（如第13章），先合上书回答"版本 / 基线"的定义、误区、出处——答不上来的，翻附录 B 的"基线"卡（从①定义到⑧误区，尤其⑧误区格：版本号≠基线）+ 附录 C 第12行（"版本是刻度、基线是参照"）+ 附录 D（ISO 10007:2017）查全。（附录 E 第13章答案要点可对照）
2. **书练习（出处 + 方向）**：用附录 D 把"质量 / 架构 / 治理"三条定义的权威出处各查到条款号（ISO 9000:2015 §3.6.2 / ISO/IEC/IEEE 42010:2011 / ISO/IEC 38500）；再用附录 E 核对某一章"自查 · 这些说法对吗"的对/错速查——说出哪一条你原本把话说准了、哪一条没准。
3. **回部门落地**：结合现状，用"该查时查全"给部门做一次"查全体检"——选最近一次"说不清 / 跨部门争论 / 引用标准只写名字"的事，用五个抽屉把它查全，给出最该改进的三件事，每件落到一个动作。**两周后回来报告**：查全了哪个词 / 哪条标准、部门改了什么动作、效果如何。

### 作业指南（回部门落地的步骤 + 话术）

> 照着做，45 分钟查全一个词 / 一条标准：
>
> 1. **选一个词（先立枢纽）**：选"最近在部门里争论过 / 说不清 / 跨域对不上"的词——最常被争论的词，往往正是查全价值最大的词。
> 2. **抽屉一 · 术语宪法（A）**：翻开附录 A 查这个词的编号 / 英文 / 一句话定义 / 主章——它指称的是哪个概念？是不是同名异物？**话术**："我们先定这个词指称的是哪个概念，再谈别的。"
> 3. **抽屉二 · 档案字典（B）**：若在 23 张卡里，从①定义到⑧误区逐格过；不在则回主章概念卡——薄格可省、不可跳过，尤其⑧误区格：最容易切错的那刀。
> 4. **抽屉三 · 误解清单（C）**：在附录 C 找这个词所在章行，读"病 → 药 → 判据"三栏——读前预习 / 读后检验两用都做了吗？把话说准了吗？
> 5. **抽屉四 · 标准出处（D）**：这条原理出自哪个标准？在 D 区找到锚定它的标准 / 文献——版本号是正文实际引用的版本，引用时写到条款号。
> 6. **抽屉五 · 答案方向（E）**：若与某章练习相关，翻 E 的答案要点——给的是"往哪个方向想、用哪把尺子"，不是唯一答案。
> 7. **跨域先查表**：这个争论是不是跨域对不上的词（像恒信"合同编号" vs 冰链"数据所有权"）？查表后还吵吗？——先查再谈，比先争省时间。
> 8. **出查全报告**：五抽屉各查到了什么、这个词的正确用法一句话、你们部门最该改的一个动作（如把口头定义改成回表确认）。
>
> 卡住时：答不上来的那一格就是该查的格（检索练习标准）；查了还吵 = 没查"指称"（同一个词两个所指）；五抽屉都不用查 = 这个词你们正在用、随手能调用——那就对了，该查时查全不是每次量全。
