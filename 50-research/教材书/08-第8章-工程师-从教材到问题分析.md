## 第 1 步 · 剖章立骨：核心内容地图

**这一章回答的问题**：工程师到底是个什么样的物种？头衔、证书、年限都不定义工程师——六项能力才定义。怎么判断一个人是不是工程师，怎么长成、怎么失败、怎么被检验？

**三幕对齐（省一步推导）**：
- **第一幕 是什么（定界）**：1.1 一句开场白（把四层背在身上）→ 1.2~1.6 六项能力逐项（①科学素养 / ②方法论素养 / ③实践能力 / ⑤工程判断·⑥可复现意识合节 / ④职业伦理收幕尾"能力不中性"）→ 1.7 三个领域同一副骨架 + 案例进展①老周—— 喂第一组·概念题（见树见林）；
- **第二幕 不是什么（磨边弧）**：2.1 不是技术员 → 2.2 不是科学家 → 2.3 不是手艺人 → 2.4 不是"会写代码的人" → 2.5 不是头衔、证书、年限（名义不定义能力）+ 案例进展②李工—— 喂真悖论·辨边界题；
- **第三幕 往哪去（运用）**：3.1 怎么长成（判断依据升级）→ 3.2 能力的叠加顺序 + 成长的标志 → 3.3 被任命 ≠ 成为 → 3.4 怎么死掉（失败四式）→ 3.5 怎么被检验（产品数据）+ 案例进展③双线判词—— 喂第二组·落地 / 方法时刻题（规则 15）。

### 六项能力清单（四问化：是什么 / 不是什么 / 判据）

| 能力 | 是什么（含拆解动作） | 不是什么 | 判据 | 对应层 | 缺了会怎样 |
|---|---|---|---|---|---|
| ① 科学素养 | 回答"做的东西凭什么能行"——理解原理 / 判断边界 / 应用建模；培养靠预测对账（改动前写下预测，事后对账找偏差） | 不是"懂科学不被忽悠"的科普义；不是背公式、翻旧经验、信玄学 | 没遇过的情况——我从原理推，还是翻旧经验，还是信玄学？ | 第一层 工程科学 | 换场景就抓瞎，只会套模板 |
| ② 方法论素养 | 把工作组织成方法——过程设计（输入/输出/检查点）/ 显性化（写成文档规则标准）/ 过程治理（检查过程在跑、识别偏差、改进过程） | 不是背方法论名词（那是方法论词典）；不是算法化（方法必须留判断空间） | 我的方法能被别人学会吗？还是只有我会？ | 第二层 方法论 | 靠人传人，人走方法走 |
| ③ 实践能力 | 亲手把方案变成现实、东西坏了能修好——动手实现 / 工具驾驭 / 排错集成；实践只能从"做"里长 | 不是会写代码、会画图（那是载体） | 我最近一次亲手落地，是什么时候？ | 第三层 工具实践 | 有想法落不了地 |
| ④ 职业伦理 | 工程师身份的定义性特征（职业不是差事；NSPE：服务必须保护公众健康安全福祉）；能力不中性，④定义方向 | 不是道德说教、不是规章制度 | 压力面前，我会不会为进度悄悄牺牲可靠性？相关方知情吗？有记录吗？ | 第四层 价值与伦理 | 会出事——泰坦尼克、挑战者、737 MAX |
| ⑤ 工程判断（横切） | 四层的横切面——冲突里怎么选、在约束下做对的取舍（ABET：applied with judgment；约束越多判断价值越大） | 不是"会做决定"（"先上再说"也是判断，但是坏的判断） | 规则没有覆盖的地方，我能做对的取舍吗？ | 横切四层，不属于任何一层 | 有流程也选不对，约束一变就懵 |
| ⑥ 可复现意识（元能力） | 元能力——第2章试金石在个人身上的落点：追求"换个人也能交付"，把个人能力变成组织能力（写成可教规则/可查文档/可检验标准） | 不是手艺（手艺全部本事在本人身上） | 我的判断换个人能接住吗？我把它写成规则、文档、标准了吗？ | 元能力——横在四层之上 | 手艺——你在质量在，你走质量走 |

前四项与第2章四层结构一一对应；⑤是"横切"、⑥是"元"，恰恰是工程师区别于"会做工程的人"的地方。**整张表就是"工程师是个怎样的物种"的第一层答案。**

### 核心概念（角色章的"概念"= 清单 + 两把尺子 + 一个判词任务 + 两个反直觉命题）

1. **工程师**（无新档案，以清单定义）：把四层结构背在身上的人。判据：六项能力一项一项亮起来（①科学素养 / ②方法论素养 / ③实践能力 / ④职业伦理 + ⑤工程判断·横切 + ⑥可复现意识·元）；头衔不定义工程师。
2. **⑥可复现意识**（元能力）：第2章试金石在个人身上的落点——"换个人也能交付"，把个人能力变成组织能力；判断能被接住，就成了组织的一部分，人走了判断不走。
3. **⑤工程判断**（横切）：规则没有覆盖的地方做对的取舍——不是"会做决定"，是"在约束下做对的取舍"（"先上再说"也是判断，但是坏的判断）。
4. **④职业伦理**（方向定义者）：能力不中性——能力放大"选择的规模"，方向由④定义；①③⑤顶配④为零的人破坏比"不会做"的人大得多。
5. **四个相邻角色**（技术员 / 科学家 / 手艺人 / 会写代码的人）：和工程师像但不一样，一条条磨过去。
6. **名义三件套**（头衔 / 证书 / 年限）：名义不定义能力——头衔可印上可收走 / 证书只证明考过一次试 / 年资可能是手艺的壳子。

### 关联概念（近界 · 辨析）

- **六项能力 ↔ 第2章四层结构**：前四项与四层一一对应，⑤横切四层、⑥元——一套结构，两个说法（学科四层 vs 人六项）。
- **⑥可复现意识 ↔ 第2章试金石**：试金石"换个人能交付质量相当的结果"的具象化=换个人拿着你负责的产品数据能接着种、继续演进。
- **④职业伦理三问 ↔ 第7章三个看门人**：相关方知情 / 评审 / 记录——正是第7章评审要相关方知情、结论记录在案、验证确认要客观证据的门禁在压力下的落点；"没有记录"的地方既是价值层失守，也是评审缺席。
- **⑤工程判断 ↔ 第2章"约束越多判断价值越大"**：判断=在约束下做取舍；"先上再说"也是判断，坏在没让相关方知情、没走评审。
- **能力的最终体现 ↔ 第6章一棵树**：枝干概要定义（管结构）+ 叶子详细定义（管内容可验证），用分解/分配/分析把需求长成可检验的叶子——树就是能力落到地面上的形状。
- **技能四层 ↔ 六项能力**：思维与认知地基≈①⑤、工程方法≈②、技术工具≈③、软技能≈④；⑥可复现是横在四层之上的元能力。
- **成长 ↔ 判断依据换尺度**：怎么做→会选→会取舍→守底线；从执行者长成工程师。
- **失败四式 ↔ 六项能力缺项**：手艺型缺⑥ / PPT 工程师缺③ / 守不住底线缺④ / 能力失控方向错（④）。
- **双线判词 ↔ 3.5 产品数据**：判词（案例进展①②③）和产品数据量的是同一把尺子。

### 核心原理

**第一幕 · 是什么的底层机制**
1. 工程师是把四层结构背在身上的人——学科四层缺一层工程不完整，人四层缺一项能力工程师不完整（第2章四层结构在个人身上的落点）。
2. 六项能力不是平行的——前四项与四层对应，⑤横切四层、⑥是元能力；⑤⑥恰恰是工程师区别于"会做工程的人"的地方。
3. ①科学素养靠预测对账培养——没有预测的实践不产生科学素养，只有"调参数调到对"（那是手艺）。
4. 方法论必须留判断空间——写过头就退化成"技术员照单执行"；方法论素养=把工作组织成方法（过程设计/显性化/过程治理）。
5. 实践能力只能从"做"里长——读和听几乎不产生它；到"独立做"那一级，判断才开始进场。
6. 工程判断力不是"会做决定"，而是"在约束下做对的取舍"——"先上再说"也是判断，但是坏的判断（取舍没让任何相关方知情、没走评审）。
7. 能力不中性——能力放大"选择的规模"，方向由④定义；①③⑤顶配、④为零的人破坏比"不会做"的人大得多（737 MAX 不缺会算的工程师，缺守住底线的工程师）。
8. 价值层失守三问（相关方知不知情 / 有没有评审 / 有没有记录）——客观原因不留记录；价值层失守恰恰发生在"没有记录"的地方（第7章三个看门人的落点）。

**第二幕 · 磨边弧的机制（不是什么）**
9. 技术员和工程师的分界不是学历，是"规则留白时谁来拍板"——判断落在人身上是工程师，判断可完全交给规则是技术员。
10. 科学家问"世界是什么"，工程师问"应该造出什么"——求真和求有用是两种目标、两种物种。
11. 手艺人 vs 工程师区别只有一条：交付依赖不依赖具体的人——手艺结果绑定在人身上，工程结果可脱离具体的人。
12. 写代码是载体不是判据——载体人人都可以拥有，判据不是人人都有。
13. 名义不定义能力——头衔是组织发的位置（可印上可收走）、证书是社会认证（只证明考过一次试）、年资是时间累积（二十年可能都在用手艺的壳子）。

**第三幕 · 往哪去的机制（运用）**
14. 成长的本质是判断的依据换尺度——怎么做→会选→会取舍→守底线；判断依据从"怎么做"升到"守什么"，物种就从执行者长成工程师。
15. 六项能力有自然叠加顺序——先③实践、再①科学素养、然后⑤工程判断、接着⑥可复现意识、最后④职业伦理；④最贵因为它约束的不是"会不会做"，而是"做的方向"。
16. 被任命 ≠ 成为——头衔是入场券，能不能坐稳靠六项能力清单；能力可以长，名头只是时间的快照。
17. 失败四式各缺一项——手艺型缺⑥（判断不可接住）、PPT 工程师缺③（方法论悬空）、守不住底线缺④（价值层失守）、能力失控④定义方向错（能力越强方向错破坏越大）。
18. 六项能力抽象在人身上不可直接检验——最终体现是能否设计开发出高质量产品数据（第6章一棵树：枝干概要 + 叶子详细）；能力再强开发不出来也不成立；换个人拿着能接着种才算数。
19. 判词量的是同一把尺子——老周①③⑤顶配缺②⑥、李工有②③缺①④⑥；案例进展①②③和 3.5（产品数据）量的是同一把尺子；两个都不是完整的工程师，都在长成。

**反天赋论（方法底座时刻，显式命名）**：能力可检验、可训练，不是天生的——把六项能力列成清单，就是为了让你一项一项亮起来；头衔不定义人。

### 本章判据（六把尺子 + 一把成长尺 + 一把终极尺）

1. **科学素养**：我做的东西，凭什么能行？换个上下文还成立吗？
2. **方法论素养**：我的方法能被别人学会吗？还是只有我会？
3. **实践能力**：我最近一次亲手落地，是什么时候？
4. **职业伦理**：压力面前，我会不会为进度悄悄牺牲可靠性？有没有让相关方知情？
5. **工程判断**：规则没有覆盖的地方，我能做对的取舍吗？
6. **可复现意识**：我的判断换个人能接住吗？我把它写成规则、文档、标准了吗？
7. **成长尺**：判断的依据在哪个尺度（照做 / 会选 / 会取舍 / 守底线）？
8. **终极尺**：能力再强，也要看能不能开发出高质量的产品数据——换个人拿着它，能不能做出来、继续演进？

## 第 2 步 · 量学立标：掌握清单

### 概念层（应能定义与辨析）

1. 能定义"工程师"（把四层结构背在身上的人——四层各一项能力 + 横切⑤ + 元⑥），并能说出六项能力清单及各自对应层。
2. 能辨析 工程师 vs 技术员（规则留白处判断 vs 照单执行——分界不是学历，是"规则留白时谁来拍板"）。
3. 能辨析 工程师 vs 科学家（创造未存在的世界 vs 研究现存世界——求有用 vs 求真）。
4. 能辨析 工程师 vs 手艺人（结果可脱离具体的人 vs 依赖个人——唯一分界=交付依赖不依赖具体的人）。
5. 能辨析 工程师 vs 会写代码的人（判据 vs 载体——写代码是载体不是判据）。
6. 能说出"名义不定义能力"三件套（头衔=组织可印上可收走的位置 / 证书=只证明考过一次试的认证 / 年资=可能是手艺的壳子的时间累积）。
7. 能说出六项能力各自对应的第2章四层结构，以及⑤⑥的特殊性（横切 / 元）。
8. 能说出三个领域同一副骨架、权重不同（系统工程管缝·①⑤最重 / 软件工程管过程·②③主战场 / 硬件工程管物理·①④红线）。
9. 能说出失败四式（只会做 / 只会说 / 守不住底线 / 能力失控）与成长的叠加顺序（③→①→⑤→⑥→④）。

### 原理层（应能解释为什么）

1. 能解释为什么工程师是把四层结构背在身上的人（学科四层缺一层工程不完整；人四层缺一项能力工程师不完整）。
2. 能解释为什么⑤⑥是工程师区别于"会做工程的人"的地方（横切 / 元）。
3. 能解释为什么①科学素养靠预测对账培养（没有预测的实践不产生科学素养）。
4. 能解释为什么方法论必须留判断空间（写过头退化成技术员照单执行）。
5. 能解释为什么实践能力只能从"做"里长（读和听几乎不产生；独立做判断才进场）。
6. 能解释为什么工程判断力不是"会做决定"而是"在约束下做对的取舍"（"先上再说"也是判断但是坏的判断）。
7. 能解释为什么能力不中性、④定义方向（能力放大选择的规模，方向由④定义；①③⑤顶配④为零破坏更大）。
8. 能解释价值层失守三问为什么成立（相关方知情 / 评审 / 记录；客观原因不留记录）。
9. 能解释为什么手艺人 vs 工程师唯一分界是"交付依赖不依赖具体的人"。
10. 能解释为什么名义不定义能力（头衔可印上可收走 / 证书只证明考过一次 / 年资可能是手艺的壳子）。
11. 能解释为什么成长的本质是判断依据换尺度（怎么做→会选→会取舍→守底线）。
12. 能解释为什么六项能力有叠加顺序且④放最后（④最贵，约束方向）。
13. 能解释为什么被任命 ≠ 成为（头衔是入场券，坐稳靠能力清单；能力可长，名头是时间快照）。
14. 能解释失败四式各缺哪一项（手艺型缺⑥ / PPT 工程师缺③ / 守不住底线缺④ / 能力失控方向错④）。
15. 能解释为什么能力最终体现在产品数据上（六项抽象在人身上不可直接检验；树=枝干概要+叶子详细；换个人能接着种）。
16. 能解释为什么反天赋论成立（能力可检验可训练；头衔不定义人）。

### 判据层（应会用）

1. **六项能力体检**：逐项自问六把尺子（科学素养 / 方法论素养 / 实践能力 / 职业伦理 / 工程判断 / 可复现意识）——三种场合（招人面试 / 团队体检 / 自己对照）各会用。
2. **角色判据**：换个人，用同样的需求和方法，能交付质量相当的结果=工程师；交付依赖你=手艺人——哪怕你也会写代码、画图纸。
3. **价值层三问**：相关方知不知情 / 有没有评审 / 有没有记录——当场打勾；"没有记录"的地方就是失守可能潜伏的地方。
4. **成长尺**：判断的依据在哪个尺度（照做 / 会选 / 会取舍 / 守底线）——定位自己下一步往哪升。
5. **终极尺**：能力再强，也要看能不能开发出高质量的产品数据——换个人拿着它做出来、继续演进，能力才成立。

| ★2 | 载体 ≠ 判据（写代码是载体不是判据） | 1 / 7 / 14 / 16 | "会写代码是载体不是判据"脱口；招人先问判据不问载体 |
| ★3 | 名义不定义能力（头衔 / 证书 / 年限） | 2 / 3 / 9 / 16 | 名义三件套脱口；"头衔可印上可收走"脱口 |
| ★4 | 能力不中性，④定义方向 | 5 / 6 / 18 | "能力放大选择的规模，方向由④定义"脱口；737 MAX 对照 |
| ★5 | 试金石"换个人能接住"（⑥可复现） | 1 / 7 / 8 / 14 / 15 | 试金石一句 + 三种场合（招人 / 交接 / 复盘）各用一次 |
| ★6 | 角色分界四对（技术员 / 科学家 / 手艺人 / 会写代码） | 4 / 11 / 13 / 14 | 四道"不是 X"脱口；"规则留白时谁来拍板"成为问句 |
| ★7 | 能力最终体现 = 高质量产品数据 | 12 / 15 / 19 | "聊一聊判断不了；看产品数据"脱口 |
| ★8 | 反天赋论（能力可检验、可训练） | 2 / 3 / 10 / 20 | "能力是练出来的，头衔不定义人"脱口；缺项可补 |

### 纠错红线十条

1. **先表态后翻案**：先让学员说"会写代码就是工程师，这还用讨论吗"，再翻，不让结论先入。
2. **反转精确不造新误解**："载体不是判据"别翻成"写代码不重要 / 工程师不用会写代码"；"头衔不定义工程师"别翻成"头衔没用 / 该取消职称"；"能力不中性"别翻成"能力本身是坏的"。
3. **判据配机制**：每条反转都有"为什么"（机制）和"怎么当场验证"（判据）。
4. **归责到可对照动作**："他不是工程师"落到"⑥没打勾——判断换个人接不住 / ④没打勾——压力面前为进度让路"，不归咎"人不行"。
5. **教机制不教断言**：教"为什么能力不中性"（方向由④定义、737 MAX 不缺会算的工程师），不教"讲伦理就安全"。
6. **先立尺子再翻案**：先给六项能力体检判据，再翻李工"我已是高级工程师"。
7. **拉开强度层次**：★★★ 常识（会写代码=工程师 / 有证书=工程师 / 经验多=工程师 / 能力强=值得信赖 / 聊一聊就能判断）重点翻。
8. **每个纠正落到可操作动作**：讨论完给"回去做一件事"（用六项体检给团队某人打勾、落判词）。
9. **单一权威不另立标准**：判据引用书（六把尺子 + 成长尺 + 终极尺），不发明新尺子。
10. **网搜当佐证**：N1~N7 只作"这不是书里一个人的说法"佐证，药与判据全在书内。

## 第 6 步 · 化尺为用：落地工具

### 作业指南（主产出）：用六项能力体检表给团队"最像工程师的人"做一次体检 + 落判词

> 目标：把六项能力清单从"背诵对象"变成"判人的尺子"——给团队里一位公认最像工程师的人做一次六项体检，落一条判词（谁缺哪项、在长成哪一项），再反身给自己打勾。
> 场景：回部门落地。时长：一次 45 分钟；两周后复查。

1. **挑对象（先立枢纽）**：选团队里"公认最像工程师的人"——最像的，往往也最容易在某一项打不上勾。
2. **项目一 · 六项体检打勾**：①科学素养——他做的东西"凭什么能行"能讲出原理吗？②方法论素养——他的方法能被别人学会吗？③实践能力——他最近一次亲手落地是什么时候？④职业伦理——压力面前会为进度牺牲可靠性吗？⑤工程判断——规则没覆盖的地方能做对取舍吗？⑥可复现意识——他的判断换个人能接住吗（写成文档/规则/标准了吗）？
3. **项目二 · 落判词**：对照两条基准线——老周①③⑤顶配缺②⑥（手艺极致）、李工有②③缺①④⑥（伪工程）——你的对象像哪条线？缺的是哪一项？**话术**："他不是不会做，是做的能力不可复制"（像老周）/ "他不是不会说，是说的和做的对不上"（像李工）。
4. **项目三 · 反身自检**：用同一张清单给自己打勾——你缺的那一项，正是你在"背清单"而不是"用清单"的地方（反天赋论：缺的项可补，能力是练出来的）。
5. **项目四 · 落到产品数据**：问最后一个问题——他/你开发的产品数据（文档/代码/工艺），换个人拿着能接着种吗？这是六项能力唯一可检验的落点。
6. **出体检报告**：六项各打勾/缺项，落判词，最该先补最缺的一项；两周后复查补了什么。

**卡住怎么判断**：打不上勾的那一项就是最该补的；⑥打不上勾=手艺型（判断换个人接不住），④打不上勾=最危险（能力越强方向越偏）；价值层三问（相关方知情/评审/记录）当场打勾——"没有记录"的地方就是④可能缺席、也是①和⑥最容易现形的地方。

### 工作检查单（配套素材）

| 检查项 | 是/否 | 否 → 可讨论发现 |
|---|---|---|
| 六项能力逐项能打勾？ | □ | 打不上勾的那一项=最该补的 |
| 判断换个人能接住？（⑥可复现） | □ | 手艺型——你在质量在、你走质量走 |
| 判断写在规则/文档/标准里了吗？ | □ | ⑥可复现意识缺位 |
| 压力面前为进度牺牲可靠性了吗？（④） | □ | 能力越强、④越缺、越危险 |
| 相关方知情吗？有评审吗？有记录吗？ | □ | 价值层失守恰恰发生在"没有记录"的地方 |
| 判断的依据在哪个尺度？（照做/会选/会取舍/守底线） | □ | 成长尺定位下一步往哪升 |
| 产品数据换个人能接着种吗？ | □ | 能力再强，开发不出高质量产品数据不成立 |

## 第 7 步 · 淬问成题：题卡（10 题 2×5）

### 第一组 · 概念与原理（5 题）

**Q1（破题 · 见树见林① · 概念本身）**
"恒信 IT 部要招一名『高级工程师』，Ada 主持面试。候选人甲是算法高手，笔试几乎满分，口答流畅得像背书——『会写代码的，不就是工程师吗？』候选人乙带着软考高级证书，职称评审的材料叠了一沓——『有职称、有证书，还不算工程师？』候选人丙干了二十年，项目数不清，可当 Ada 问到『你的判断，换个人接得住吗』，他答不上来——『干了这么多年，经验还不够吗？』Ada 问了三个人同一个问题：『换个人，用同样的需求，交付的东西能和你质量相当吗？』三个人都沉默了。三句话三个『工程师』，错在哪？『工程师』到底是个什么样的物种？"
追问：① 六项能力清单——四层各一项 + 横切⑤ + 元⑥，怎么构成一个整体？每项各配一句判据（①科学素养"凭什么能行"为什么靠预测对账长出来）？② "会写代码 / 有证书 / 经验多"分别把什么当成了判据（载体 / 名义 / 年资）？③ 反身：你自己判断身边谁是工程师，用的是这三样里的哪样，还是看他开发出的产品数据（换个人能不能接着种）？

**Q2（见树见林② · 概念关系）**
"请给出 工程师 和 技术员、科学家、手艺人、会写代码的人 这四种身份的关系，并说明：为什么说『写代码是载体不是判据』？六项能力里，⑤工程判断为什么是横切、⑥可复现意识为什么是元？"
追问：① 技术员和工程师的分界为什么不是学历（规则留白时谁来拍板）？② 手艺人 vs 工程师唯一分界=交付依赖不依赖具体的人——老周为什么不在这条线的工程师那边？③ 反身：你们团队里"被当成工程师、其实是技术员/手艺人/会写代码的人"的例子，缺的是清单里的哪一项？

**Q3（真悖论 · 头衔 vs 能力）**
"李工的名片上印着『高级工程师』，恒信还上了敏捷、CI/CD、测试——方法论和工具都在。可 Ada 面完三个人，旁听席上的李工也意识到：『换个人能交付吗』这个问题的答案，他这些年也没答上来过。有头衔、有方法论、有工具，到底算不算工程师？什么判据能分清『头衔』和『能力』？"
追问：① 头衔是组织发的位置（可印上可收走）、证书是社会认证（只证明考过一次试）、年资是时间累积——为什么三个都定义不了工程师？② 李工按六项能力清单：有②③、缺①④⑥——为什么方法论和工具都在，四层却站不稳（容量评估被砍 / 为进度悄悄牺牲可靠性没让相关方知情 / CI/CD 靠隐藏命令）？③ 反身：你们部门里有没有"头衔先于能力"的人？拿掉头衔，他还立得住吗？

**Q4（真悖论 · 能力强 vs 值得信赖）**
"冰链的老周十五年温控产品，车间里没有一份完整测试方案，但他『心里有数』——哪个批次容易出问题、哪种工况要降额、哪家供应商不可靠，全在脑子里；他①科学素养顶配、③实践能力顶配、⑤工程判断顶配，每个取舍都准。他是工程师吗？『能力越强的工程师越值得信赖』对吗？还是『能力不中性，④定义方向』？"
追问：① 老周缺②⑥——为什么手艺的极致不是工程师的画像（做的能力不可复制）？② 737 MAX 不缺"会算的工程师"，缺"守住底线的工程师"——为什么能力放大的是选择的规模，方向由④定义？能力越强、④越缺，为什么越危险？③ 反身：你们团队里技术最强的那个人，④职业伦理这条打过勾吗？

**Q5（真悖论 · 照单执行 vs 规则留白）**
"『工程师就是照着流程做的人』——有人说：流程全覆盖、照单执行，最不容易出错，这才是工程师。这一章却说：那是技术员；工程师在规则没有覆盖的地方做判断。哪个对？技术员和工程师的分界到底是什么？"
追问：① 判断落在人身上是工程师、判断可完全交给规则是技术员——分界为什么不是学历？② ⑤工程判断的判据是"规则没有覆盖的地方能做对的取舍吗"——"先上再说"也是判断，为什么是坏的判断（没让相关方知情、没走评审）？③ 方法论写过头会退化成"技术员照单执行"——方法必须留判断空间，为什么？④ 反身：你最近一次"规则留白"的决策，是你自己判断负责了，还是推给了流程？你判断的依据在哪个尺度（照做/会选/会取舍/守底线）？

### 第二组 · 落地与实践（5 题）

**Q6（判据运用 · 双线判词 · 六项体检）**
"用六项能力清单，给老周和李工下判词：老周是①③⑤顶配缺②⑥（手艺的极致），李工是有②③缺①④⑥（伪工程）。先把这两条判词逐项打勾验证，再说说：两个人都是『缺』，缺的性质有什么不同？谁更接近工程师？"
追问：① 老周的里子（判断顶配）vs 面子（不可复制）；李工的面子（方法能说清）vs 里子（守不住底线）——两个人都不是完整的工程师，那"在长成"是什么意思（都在用清单量自己、补缺项）？② 判词（案例进展①②③）和 3.5（产品数据）量的是同一把尺子——老周缺的②⑥和李工缺的①④⑥，各自露在产品数据的哪里？③ 反身：你更接近哪条线？缺的是哪一项？

**Q7（判据运用 · 失败四式 · 四宗死法）**
"失败四式——只会做不会说（手艺型）、只会说不做（PPT 工程师）、守不住底线（价值层失守）、能力失控（有能力的坏工程师）。用六项能力清单，说出每一宗死法缺的是哪一项。哪一宗最危险？为什么？"
追问：① 手艺型死于判断不可接住（⑥缺席）——老周为什么不是被辞退，而是死于"团队发现他的判断不能复制"？② 守不住底线（④缺席）为什么最普遍也最隐蔽（症状不是不会做，是做的时候没守住；泰坦尼克/挑战者/737 MAX 的共同点）？③ 反身：你最近一次技术决策更接近哪一宗？缺的是清单里的哪一项？

**Q8（判据运用 · 成长尺 + 被任命 ≠ 成为）**
"李工被任命为『高级工程师』那天，名片换了、工资涨了——但 Ada 那个问题他还是答不上来。为什么『被任命』不等于『成为』？怎么判断一个人是不是真的在长成工程师（判断的依据在哪个尺度）？"
追问：① 成长的本质=判断的依据换尺度：怎么做→会选→会取舍→守底线——你判断的依据现在在哪个尺度？② 六项能力有叠加顺序：先③实践（读和听几乎不产生实践能力，只能从做里长）、再①科学、然后⑤判断、接着⑥可复现、最后④伦理——④为什么放最后（它约束方向）？③ 反身：你最近一次"为一件做了也没人反对的事说不"，是对自己还是对别人？

**Q9（方法时刻 · 规则 15 · 反天赋论 + 判词变体）**
"李工有『高级工程师』头衔、老周没头衔——可这一章的方法底座时刻是反天赋论：能力可检验、可训练，不是天生的；头衔不定义人。把六项能力清单从『背诵对象』变成『判人的尺子』：先用它判李工（缺哪几项？证据是什么？）、再判老周、最后反身判你自己的团队——谁缺哪一项？用什么判据检验（不是头衔、不是感觉）？"
追问（判词变体）：① 你给李工判"缺①④⑥"，证据各是什么（容量评估被砍 / 没让相关方知情没记录 / CI/CD 靠隐藏命令）？给老周判"缺②⑥"，证据是什么（方法不成体系 / 车间没有一份完整测试方案）？② 反身判团队：拿掉名片和年资，用六项逐项打勾——你们团队"最像工程师的人"缺哪一项？他正在长成的是哪一项？③ 反天赋论还意味着什么——缺的项能不能补？怎么补（①科学素养靠预测对账、③实践从做里长、判断依据换尺度）？——能答全六项能力的四问、能用清单量别人量自己，才算拥有，这把尺子现在装进你手里了吗？

**Q10（落地生根 · 回部门体检 + 判词）**
"结合你们部门现状，用六项能力体检表给一位『被当成工程师的人』（或你自己）做一次体检——逐项打勾，指出缺项，落一条判词（像老周缺②⑥还是像李工缺①④⑥？），给出最该先补的一项，落到一个动作。"
追问：① 六项体检 + 价值层三问（相关方知情/评审/记录）先查哪两项？② 你们的招聘/晋升，用的是六项判据，还是"会写代码/有证书/经验多"三个错判据？③ 两周后回来报告：谁打了勾、缺了哪项、补了哪个动作？
