# 方法论的底座：第1章的底色、理念、思路与方法

> 本书方法论的 DNA——第1章是它的示范章，本文件点明其四层，并为每一层配一套**框定问句**：用它可以框定/审视/修订任何一章。审查镜由此而来，不每次临时磨。
>
> 版本与结构权威见 `00-全书框架.md`；案例细节见 `00-案例设定.md`。
>
> **怎么用本文件**：写新章前，对着四层起草（先立枢纽 → 钉概念 → 判据/自查/练习在掌握线之上 → 案例落实践）；审既有章，对着每层"框定问句"逐条过；**重构既有章（结构未对齐时），按 §六 重构方法**；过完，落到 `00-全书框架.md` §五 七块模板 与 三道自检。

## 一、底色（根本预设：给全书染色的那层）

- **三重祛魅**：反记忆崇拜（懂≠记住，会背只是"见过"）／反天赋论（能力是练出来的，有五环流水线）／反绝对真理（概念是共识不是真理，枢纽可修正）
- **工程师判据主义**：不给没有判据的定义、不给没有失效边界的工具、不给没有反例的概念——"不是什么""往哪去"（失效边界）比"是什么"更见功力——且判据要配"违反即崩"的画面，让失效边界可辨认
- **意义即用法**（维特根斯坦）：概念的意义在用法里；用"它做什么"定义"它是什么"（功能主义，非本质主义）
- **谦逊诚实**：给边界、给失效、不把话说满；每一章自己践行自己教的判据；区分"陈述共识"与"作者主张"，让"概念是共识"可对账
- **人本定位**：AI 时代记忆已外包，人剩下的稀缺能力是概念性的——知识可外包，能力不能

**框定一章 · 问这几句**：
1. 章首误解现场，祛的是"记忆崇拜／天赋论／绝对真理"中至少一个吗？还是只堆知识点？
2. 核心概念有没有可检验判据？有没有失效边界？有没有反例？（判据主义三问）
3. 定义是"它做什么"（用法），还是只说了"它是什么"（词典）？
4. 章内有没有"一句冷静的话"式的边界交代——承认这章的局限？
5. 有没有落到"人"——人为什么值得掌握它，而不只是系统机制？

## 二、理念（全书相信什么）

1. 学习是建构结构，不是堆信息——知识是网络不是列表，大脑是压缩机器（学习做除法：先搭四梁八柱）
2. 概念要"拥有"不是"记住"——掌握线划在"应用"之上（布鲁姆六级）
3. 能力比知识更根本、更可迁移、更稀缺
4. 方向先于努力——杠杆第一性是方向；方向错了，其余全在放大错误
5. 概念是活的、可修正的——勤校准是正常纠偏，不是失败

**框定一章 · 问这几句**：
1. 这章是把知识当"结构／网络"讲，还是当"清单／事实"堆？
2. 核心概念推到"拥有"（会用、能迁移）还是停在"见过"（记得、会背）？
3. 章末落点是"能力／可迁移"，还是只收了"知识点"？
4. 有没有体现"方向／判断先于执行"（而不是只讲步骤）？
5. 有没有体现概念可修正（勤校准），还是把概念当死规矩？

## 三、思路（每章怎么组织论证）

- 从误解现场出发（问题先行，不是理论先行）——且问句要是从业者真会被卡住的"真困惑"，判据翻译垫后
- 沿"为什么 → 靠什么 → 怎么练 → 怎么检验 → 怎么用"推到底
- 每一环落到可检验判据
- 既立又破：给证据同时给边界（如第1章"一句冷静的话"）、给工具同时给限定（如杠杆三限定）
- 处处用反事实检验（识别枢纽、检验概念、跨域迁移）
- 用自己示范自己：写"识别枢纽"的章自己先立枢纽；教"四问"的章自己就是四问的示范
- 先内涵、后子概念：概念含子概念时，先讲父概念的内涵（子概念作为其中一个内容），再解释子概念的内涵——不在父概念里展开子概念

**框定一章 · 问这几句**：
1. 章首是不是从误解现场出发，而不是从定义出发？（问题先行）
2. 正文是否沿"为什么 → 靠什么 → 怎么练 → 怎么检验 → 怎么用"推到底？缺了哪一环？
3. 每一环有没有落到可检验判据？
4. 有没有既立又破——给证据同时给边界、给工具同时给限定？
5. 有没有用反事实检验（如"去掉它，领域还成立吗"）？
6. 有没有"用自己示范自己"？
7. 概念含子概念时，先讲父概念内涵了吗（子概念只作为一项列出）？有没有在父概念里直接展开子概念？

## 四、方法（每章该带的工具）

| 工具 | 用途 | 每章落点 |
|------|------|---------|
| 术语定义链（概念→核心概念→根概念→基本原理→概念体系能力→根概念能力） | 从最小单位垒出核心词 | 章首先立本章的枢纽 |
| 三层体系（一般⊃核心⊃根，判据逐层收严） | 概念是一套层层包含的体系 | 建立领域概念骨架；辨"重要"≠"源头" |
| 枢纽六功能 / 识别枢纽（第0步本体论一问"什么存在"→ 三步识别法 → 判定矩阵+演绎链为根概念辩护） | 论证"为什么先研究核心概念"、识别枢纽与根 | 核心概念必须是枢纽（解释别人、自己前置少）；先定本体，再抓承重柱 |
| 概念体系能力四构件（识别枢纽×织关系×迁移×辨边界；简称"概念能力"；子能力=根概念能力·方向盘：先定本体，再抓承重柱） | 概念体系能力的结构 | 概念间织关系，不只孤立定义 |
| 四问法（纲） | 检验"真拥有" | 概念卡答全四问（尤其"从哪来"溯源） |
| 九格（目） | 作者/审稿人查全 | 薄格可省，不可跳过 |
| 五环模型（立枢纽→织关系→逼输出→勤校准→落实践） | 训练流水线 | 判据/自查/练习考"应用"不考"记忆"；案例落实践 |
| 概念来源三方式（创造/发现/凝结）＋共识≠真理 | 校准依据 | 概念给溯源、给可修正性 |
| 认知链 / 误解预告 / 三种读法 | 全书枢纽清单与读法 | 每章在认知链上位置清晰 |

**框定一章 · 问这几句**：
1. 每张概念卡答全四问了吗？尤其"从哪来"（溯源）——最容易缺的一问？
2. 判据/自查/练习考的是"会用"还是"记得"？
3. 案例承载概念了吗（落实践）？双线镜照在不在？
4. 九格薄格可省但没跳过吧？

## 五、贯彻规则（十二条硬要求，每条带检查问句）

| # | 硬要求 | 检查问句 |
|---|--------|---------|

| 2 | 从"见过"到"拥有" | 章末反转，是否把概念从"背得出"推到"答得全四问"？ |
| 3 | 判据主义 | 核心概念是否带可检验判据＋失效边界＋反例？ |
| 4 | 掌握线之上 | 判据/自查/练习是否考"会用"，不考"记得"？ |
| 5 | 勤校准 | 是否给概念的边界与可修正性，不把话说满？ |
| 6 | 落实践 | 案例是否承载概念（五环第5环）？双线镜照是否在？ |
| 7 | 先内涵、后子概念 | 概念含子概念时，是否先讲父概念内涵（子概念作为一项列出）、再解释子概念的内涵，不在父概念里直接展开子概念？ |
| 8 | 判据给崩样 | 每条判据是否带一个"违反即崩"的具体画面（1-2 句，接案例/判词）？读者能否认出"错的现场"，而不只"对的标准"？ |
| 9 | 真困惑问句 | 本章问题是否以从业者真会被卡住的困惑为首要（从误解现场提炼）？把问题给不懂判据的从业者看，ta 被问住了吗？ |
| 10 | 共识/主张署名 | 定义类论断，读者能否分辨"陈述共识"（ISO 42010、NASA TRL）与"作者主张"（本书判据/命名）？最可能被拿去对账的论断有没有署名？ |
| 11 | 论证句简洁 | 正文论证段是否用最短句序承载严密论证？口语/设问是否让位给误解现场/案例段？ |
| 12 | 语言风格混用 | 叙事（误解现场/故事/设问）是否只做开场勾读者（1-2 页），正文论证是否切回严谨（定义+出处+对照表）？章末是否有承上启下的过渡？叙事有没有渗进论证、稀释严谨？ |

## 六、重构方法：把一章改造成能力导向骨架

> 前五节的"框定问句/检查问句"告诉你**审一章**；本节告诉你**重构一章**——把底子弱、结构未对齐的章，从"现状"改造成"能力导向骨架"。设计驱动，不迁就现状。第10章（架构）按此重构为试点，其余章同法。

### 五步流程

| 步 | 动作 | 产出 |
|---|---|---|
| ① | 定这章的活 | 认知链位置（承谁/启谁）+ 反直觉命题 + 核心档案 + 案例任务（主/镜/触发点/方法底座时刻） |
| ② | 从能力导向推导理想骨架 | 读者读完要"拥有"什么 → 章节组织成"困惑→辨清→运用→拥有"的旅程 |
| ③ | 现状降级为素材 | 现有章节只提供素材（案例/段落/卡片），不迁就它的结构 |
| ④ | 设计新骨架 | 每部分回答"这段带读者完成哪个认知动作" |
| ⑤ | 对照落地 | 素材进新骨架、重写衔接、机械校验 |

### 十条重构规则

1. **先立枢纽（骨架先行）**：章首误解现场后，正文开篇先立本章枢纽骨架（核心概念 + 关系 + 判据 + 原则），再进细节——骨架是读者后续所有内容的挂载点。
2. **四问为纲组织主体**：主体按"是什么 → 不是什么 → 从哪来 → 往哪去"组织；四问重量天然不均时可合并（从哪来织进是什么）或拆分（往哪去拆成描述+用途），不教条；每个概念卡显式四问化（四问为纲、九格为目）。
3. **"不是什么"收拢成一条磨边界弧**：把散落在各处的"不是 X"（不是图/不是选型/不是多个）集中成连续一节——判据主义成为读者的亲身体验（概念靠正例活、靠反例定型）。
4. **溯源显眼化**：演化史/词源/诞生动机不埋进定义里，提为可见位置——概念"活"起来。
5. **案例为线，不是补充**：案例进展从"部分末尾的补充"升级为"推动每个认知动作的主线"（误解现场 → 案例推进 → 反转收束）。
6. **判据主义贯穿**：每个核心概念带可检验判据——判据既是"是什么"的辨认工具，也是"不是什么"的边界工具。
7. **方法论贯穿（与第1章接线）**：把本章演示的第1章方法显式命名（反事实检验用在系统上 / 架构是压缩=压缩学习 / 勤校准=枢纽修正），不止显影段。
8. **章末"见过→拥有"显式收束**：认知反转后点破——能答全四问才算拥有，把尺子装进读者手里。
9. **不造新事实**：素材全取自现状或 00 三份；重构 = 重排 + 重写衔接，不凭空造内容。
10. **机械校验**：段落≤150、围栏/加粗平衡、版本 v+1、章题与认知链位置不动、概念总图/判据/自查/练习与新结构联动。

### 每章重构的输入清单（动工前先取四样）

1. 认知链位置 + 反直觉命题（框架 §三）
2. 核心档案（框架 §三/§四）
3. 案例任务：主/镜/触发点/反转落点/方法底座时刻（案例设定 §三）
4. 素材包（案例设定 §十）

### 特殊章适配

| 章型 | 骨架怎么推 | 四问化怎么落 |
|---|---|---|
| 角色章（ch9/16） | 能力清单 + 判词（无概念档案） | 清单四问化：能力清单按"是什么/不是什么/判据"组织 |
| 整合章（ch15） | 切片 + 接缝，反直觉命题收束 | 无概念档案，概念跨域对照为骨架 |
| 附录（ch17） | 五抽屉不动结构 | 只对齐各章重构后的档案/术语——跟随者，最后做 |
