## 四、概念档案（九格尺子）

```
概念档案 · XX
┌─ 定界 · 它是什么 ────────────────────────┐
│ ① 定义        一句话 + 一个可检验判据      │
│ ⑥ 对立面      它站在谁的对立面（远界，常分维度）│
│ ⑦ 辨析        和谁最像但不一样（近界）     │
│ ⑨ 术语英文来源 中文术语↔英文原词（含词根）  │
├─ 溯源 · 它从哪来 ────────────────────────┤
│ ② 背景        诞生于什么处境、为什么造它    │
│ ③ 演化的历史   词源/标准版本/机构改写/翻译定译/跨域迁移 │
├─ 致用 · 它干什么 ────────────────────────┤
│ ④ 问题        没有它之前世界什么样、它回答什么 │
│ ⑤ 场景        什么时候用、边界在哪、何时不用 │
├─ 纠误 · 它错在哪 ────────────────────────┤
│ ⑧ 误区        最常见的误解 · "你以为的"vs"精确的" │
└──────────────────────────────────────────┘
```

- **叙述顺序**：定界 → 溯源 → 致用 → 纠误
- **使用规则**：薄格可省，不可跳过；档案织进正文，只给本章最重概念显式"概念卡片"
- **全书核心档案**（约 40 张）：**概念、核心概念、根概念、基本原理、概念体系能力、根概念能力（第1章 学习方法论档案）**、工程、工程系统、需求、设计开发、质量、规定需求、需求工程、**三类需求、验证载体、承制方主导**、**概要定义、详细定义、分解、分配、符合性分析**、**产品数据、两域三态、价值沉淀池**、评审、验证、确认、架构、架构描述、**架构设计、基本概念、基本属性**、架构决策、不可逆性、配置、版本、基线、治理、管理（ch1 学习方法论档案 6 张，ch3/4/5/6/7/8 各 3 张以上，ch2/10/12/14 各 2 张，ch11/13 各 3 张；ch9 工程师为角色章，无新档案，以"六项能力清单"替代；ch15 整合章无新档案；ch16 架构师为角色章，无新档案，以"十项能力清单"替代）

## 五、每章七块模板（书版）

> 写作/审查每章前，先对照方法论的底座（`00-方法论的底座.md`）——先立枢纽、概念答全四问、判据在掌握线之上、案例落实践。

1. **章首·误解现场**——案例团队正在犯的病（悬念开场，呼应使命）
2. **本章问题**——3~10 个读完能回答的问题（判据全覆盖优先；各章问题设计以覆盖本章判据为原则；ch9/ch16 角色章重排后判据增至 8/12，问题 10）
3. **正文·概念档案**——本章核心概念各填九格档案（定界→溯源→致用→纠误），案例进展小节奏章内多次出现，双域镜照穿插
4. **章末·认知反转**——最重反转呼应章首（每概念⑧格=小反转，章末=大反转）
5. **本章判据**——金句 + 可操作判据清单（应用层落点）
6. **练习**——与训练教材题卡同源；另有"自查·这些说法对吗"
7. **小结 + 参考文献**——章末按「标准 / 经典文献」两类列清单（带 R 编号并注明本章引用条款；研习笔记为本书内部原料，不列入参考文献）；= 附录 D 按「出现章节」切片的视图，**D 为单一权威**（新增正文引用 → 先登记 D 编号 → 再同步章内切片）；参考文献是**活资产**——标准换版、链接失效时在附录 D 更新并同步章内切片（成书后仍维护，可并入勘误/训侧流程），不随成书冻结
8. **版本变更记录**——每章文件末尾附版本表（版本｜日期｜变更说明，时间倒序）；任何修订后在最上方加一行（版本 +1、当日日期、一句话摘要）
9. **编号约定（范式丙：章号进节号，全局自定位）**——编号 = `章号.块序.节序`（如 §7.2.4）
   - **章级**：`# 第N章 标题`，章号全书全局连续（1~16）；附录不算章，用 `# 附录`。
   - **编号结构**：块序自章首起计——`N.1` = 章首·误解现场，其后每个叙事块（幕/部分）依次占序；三幕章为 `N.2`~`N.4`，节序为块内从 1 起的连续号。
   - **层级**：章 `#` → 章首/幕/章末件 `##` → 节 `###` → 无编号小标题 `####`；幕/部分标题保留序数名（"第一幕/第一部分"）。
   - **无编号对象**：本章问题、开篇·本章枢纽、案例进展（`## 案例进展①｜`）、概念卡片、章末件（概念总图/认知反转/判据/自查/练习/小结/参考文献/版本记录）一律不编号。
   - **引用格式（C 双轨）**：精确引用一律 `§章号.块序.节序`（自定位，不加「第N章」前缀）；叙述性提及章级写「第N章」。
   - **目录**：章→幕→节 三级，自动目录按层级直接映射。
   - **例外·ch1**：方法论章用「部分制」替代幕制——章首 `1.1`、六部分 `1.2`~`1.7`、节 `1.块序.节序`；词汇病与九格工具并入第六部分（`1.7.4`/`1.7.5`）。
   - **附录**：字母抽屉 A~E + 抽屉内编号（D.1/D.2）；E 区按章分块。

## 六、加厚五料（到 2 万不注水）
