## 一、定位与使命

| 项 | 定案 |
|---|---|
| 书名 | **《架构师是个怎样的物种？——从工程师到架构师》**（2026-08-21 定） |
| 成书方式 | **独立成书**——不依赖任何具体方法论，跨行业成立 |
| 标准处理 | **标准当骨架**——正文概念叙述不依赖条款号，条款下沉出处栏/定义引用 |

| 规模 | 约 24 万字（第1章 + 14 内容章 + 附录） |

## 四、概念档案（九格尺子）

```
概念档案 · XX
┌─ 定界 · 它是什么 ────────────────────────┐
│ ① 定义        一句话 + 一个可检验判据      │
│ ⑥ 对立面      它站在谁的对立面（远界，常分维度）│
│ ⑦ 辨析        和谁最像但不一样（近界）     │
│ ⑨ 术语英文来源 中文术语↔英文原词（含词根）  │
├─ 溯源 · 它从哪来 ────────────────────────┤
│ ② 背景        诞生于什么处境、为什么造它    │
│ ③ 演化的历史   词源/标准版本/机构改写/翻译定译/跨域迁移 │
├─ 致用 · 它干什么 ────────────────────────┤
│ ④ 问题        没有它之前世界什么样、它回答什么 │
│ ⑤ 场景        什么时候用、边界在哪、何时不用 │
├─ 纠误 · 它错在哪 ────────────────────────┤
│ ⑧ 误区        最常见的误解 · "你以为的"vs"精确的" │
└──────────────────────────────────────────┘
```

- **叙述顺序**：定界 → 溯源 → 致用 → 纠误
- **使用规则**：薄格可省，不可跳过；档案织进正文，只给本章最重概念显式"概念卡片"
- **全书核心档案**（约 30 张）：工程、工程系统、需求、设计开发、质量、规定需求、需求工程、**三类需求、验证载体、承制方主导**、**概要定义、详细定义、分解、分配、符合性分析**、评审、验证、确认、架构、架构描述、**架构设计、基本概念、基本属性**、架构决策、不可逆性、配置、版本、基线、治理、管理（ch3/5/6/7 各 3 张以上，ch2/4/9/11/13 各 2 张，ch10/12 各 3 张；ch8 工程师为角色章，无新档案，以"六项能力清单"替代；ch14 整合章无新档案；ch15 架构师为角色章，无新档案，以"十项能力清单"替代）

## 五、每章七块模板（书版）

1. **章首·误解现场**——案例团队正在犯的病（悬念开场，呼应使命）
2. **本章问题**——3~9 个读完能回答的问题（判据全覆盖优先；各章问题设计以覆盖本章判据为原则）
3. **正文·概念档案**——本章核心概念各填九格档案（定界→溯源→致用→纠误），案例进展小节奏章内多次出现，双域镜照穿插
4. **章末·认知反转**——最重反转呼应章首（每概念⑧格=小反转，章末=大反转）
5. **本章判据**——金句 + 可操作判据清单（应用层落点）
6. **练习**——与训练教材题卡同源；另有"自查·这些说法对吗"
7. **小结 + 延伸阅读**——笔记章节 + 标准条款指引
8. **版本变更记录**——每章文件末尾附版本表（版本｜日期｜变更说明，时间倒序）；任何修订后在最上方加一行（版本 +1、当日日期、一句话摘要）

## 六、加厚五料（到 2 万不注水）

① 案例在章内多次出现（正文埋 2-4 个"案例进展"小节，带对话）
② 概念档案在正文完整展开（每核心概念 3000-4000 字一节，九格卡片放节末）
③ 辨析/对立成段（带论证，非表格）
④ 推导过程完整推演（如第3章终点四轮推导、第5章三个参照）
⑤ 练习扩到 7-11 题 + 自查题

## 八、术语与口径约定（统一）

| 英文 | 中文 | 备注 |

| requirement / need / expectation | 需求 / 需要 / 期望 | 需求=明示/隐含/必须履行的需要或期望 |
| specified requirement | 规定需求 | 验证的参照；不译"规定要求" |
| review / verification / validation | 评审 / 验证 / 确认 | 评审对目标、验证对需求、确认对用途；3.11 vs 3.8 |

| quality / conformity / grade | 质量 / 符合性 / 等级 | 程度 / 二元 / 分级 |
| design and development | 设计开发 | 不拆成"设计+开发" |

| configuration / configuration item / configuration information | 配置 / 配置项 / 配置信息 | 锚定"实体" |

## 十一、与研习笔记、训练教材的关系

- **一个源，两个产品**：研习笔记（01~08）= 概念原料；书 = 叙述形态；训练教材 = 问题形态
- **单一权威长在书里**：术语表 + 概念档案集在书附录，训练/笔记引用书，不各自维护
- **书↔训练逐格映射**：章首误解现场↔题卡Q1、正文档案↔讲师版九格点评、章末反转↔反转话术、判据↔知识卡片、练习↔题卡
