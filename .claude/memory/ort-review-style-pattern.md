2026-08-17 ort01 趟出「ort01 风格」可读性审视模式并完成同链应用：**ort01 v0.52/v2.34（样板）→ ort00 v0.30/v2.5 → ort02 v0.18/v2.3 → ort03 v0.35/v2.3（均已应用）**。

**可复用审视模式清单**：
1. **逐章通览**（一~五章 + 全文收官），先列发现、用户确认后动手（先发现后修改）
2. **章首一句话 + 节首一句话**——每章/每节一句人话引导
3. **定义单源化**——同一概念只在权威处定义一次，其余引用（如反馈状态条件表只在 §2.2 定义、Step 引用；重跑子行为归 §2.4.2；22 候选线索取值口径单源化）
4. **术语瘦身**——砍冗余同义术语（ort01 15→7；ort00 统一「重跑」触发词；ort03 去「增量标记」术语）
5. **人类参与导航**——操作流程章加「人类参与」列 + 执行模式白话注，Step 补「一句话」+ AI 细则标可跳过
6. **命名约定**——产物/候选单元命名 = 主责角色 + 场景业务（ort01 适用；ort00 无切分不适用，补软链接同名区分注记；ort03 无切分不适用，改处理「模板命名」——文档内嵌状态摘要表改名）
7. **状态/反馈分块**——设计基础章拆「状态怎么追踪」与「反馈怎么收拢/检测」两子分组（ort01/ort00/ort02/ort03 §2.2 同构）
8. **模板一致性**——字段取值口径补全（含两分支）；SKILL 与人类方案同字段取一致
9. **变更记录 + 双文档同步**——每次版本 bump 登记、SKILL 同步（语义不变也 bump）、登记簿 02-eos-sysdev-review.md 追加、记忆更新

**待推广**：同链（ort00~ort03）已完成；未来同类 Skill（如其他链的预处理 Skill）首次审视照此清单。

**Why:** 用户要求按 ort01 风格优化同链 skill——模式已趟通，避免重新发明；也避免在超大上下文中继续叠加。

**How to apply:** 审视同类 Skill 时读取本记忆 + 登记簿 + ort01 v0.52 作样板，逐章通览，先列发现等确认再改；版本/SKILL/登记簿同步照惯例。重点查三类：悬空引用（人类方案无附录时「附录 x」残留）、重排残留（步骤重排后旧 Step 编号、且 SKILL/人类方案双向核对）、双文档不同步。
