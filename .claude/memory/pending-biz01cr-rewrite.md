## 六、可直接继承的尺子

**原有八条**：过程／规则的判别句；规则名的形（名字写足限定；按过程里首次被点到的次序排；别处引名不引表号）；清单体例；**常量不占列**；动词查归属；「定义」是加工程度；**自足**。

**2026-09-23 三条**：一段话只答一个问题；凡两处出现同一个词先问「它主语是谁」；深度与内容是两个正交坐标；「有证据≠有权改」只管权威文档。

**2026-09-24 三条**：先看宾语再看动词；同一件事只留一种口气；自造名先在权威里找根。

**2026-09-25 六条**：一个词换对，一处不一致自行消失；凡「父由子导出」的规则，单独问一次「子从哪来」；**「找根」的产出可以是修订清单而不必是批准**；三样各一处——目标写「做什么」、要素表写「有什么」、规则写「怎么算」；凡要判「这里该不该有退回」，先问两端是不是同一份产品数据；**「交接」与「承接」是两个关系，别互相代答**。

**2026-09-25 下半场九条**：

1. **组装型句式搬进深化型会现形**——「需求侧」、「末三级与 X 同指」、「两列全同的对应表」都是 abr 的话。凡见到一个**子集被单挑出来说**的句子，先问「为什么不是整体」。
2. **单位名随活取窄，不随上游抄宽。**
3. **引语只留「下一节或下一张表不会逐行说一遍」的东西。**
4. **注区判据**——落得进「某一级的某一行」的，归那张表；落不进的才留注。
5. **要素表的一行该答「是什么」，不该答「用途」。**
6. **同一份文件里两处逐字相同的图／表就是重复**——Y ＝ X ＋ Δ 时，加号左边只在 X 侧给一次。
7. **删重之后要顺着引用扫一遍。**
8. **判转换方向：把跨级取值列出来数**——向上多是自下而上，向下多是自上而下。根子是**别把「包含」当「生成」**：包含关系推得出"先有整体才能核对"，推不出"先有整体才能取值"。
9. **「清单序」与「过程序」是两回事**——同一批级，清单按升序好查、过程按降序好跑；两序不同不是错，但要在过程那一边点一句。

**2026-09-25 第二场七条**：

1. **每个转换＝AI 生成方案建议 ＋ 对话讨论确认方案**（人类定）——只做其中一半的事不该单独成步。
2. **判「检验该不该单独成步」，先问它有没有增量动作**——若那趟对照已由生成期的规则逐级承担，它就只是同一趟活走第二遍，并进生成期、就地叫「本步的关口」。
3. **组名随 Step 走**：Step 没了，自检里那个组也就没有了；别留一个名字找不到家的组。
4. **权威表里的「表里只列输入侧的合法状态」**——Y 侧退回态是入口、不是门槛行。
5. **判定列的取值随任务类型走**：深化型不外退就没有「退回上游」那一类；「软限制」不是全链的合法取值（合法的是**软提示**）。
6. **凡绝对句「不 X」，先找它与清除条件／变更分流的接缝**——「共用祖先不重写」就是这么被改掉的。
