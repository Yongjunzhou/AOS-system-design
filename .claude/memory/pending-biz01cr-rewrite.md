## 一、第四章（第 23 版，本轮全篇落定）

**定案（人类 2026-09-25）**：**转换秩序自下而上——本轮的输入有多个层级节点时，先转换层级数大的节点。**

### 1 · 它为什么对（本轮的深入分析，是新尺子的来源）

把 R 树上**每一处跨级取值**数一遍：**向上 7 处、平行 4 处、向下 0 处**。向上的是菜单三级可见性（并）、④ 的访问权限需求（并）、④ 的文档序列（序）、④ 的场景装配（编排）、④ 的任务间触发关系（关系）、⑥ 的可执行动作（并）；平行的是 ⑤ 的正文实体结构与 ⑥ 的表单字段（同源于 X 的正文实体类型）、⑤ 在文档序列中的位置（同源于 X）、⑦ 的形态与执行结果（自该场景语义）。

**根因**：①② 是分组、③ 无落点、④ 是菜单末级＋工作区——**这三级的每一项需求都是合成**（名与下挂取自 X，其余全从下级并/序/编排而来），实质内容只在 ⑤⑥⑦ 生成。所以上面三级除了指向它的下级，无话可说。

**由此得一条可复用的尺子**：**判一个任务的转换方向，把跨级取值列出来数——向上多则自下而上（本任务加的是从下合成的东西），向下多则自上而下（本任务加的是分配下去的东西）。** 承接/分配型向下多，深化到界面的向上多。

### 2 · 上一轮判错的根子（记下来免得再犯）

**把「包含」当成了「生成」。**「⑥ 的字段是 ⑤ 的实体结构在那一页上的子集」是**包含**关系，我由此推出"先有整体"——但那推的是"先有整体才能*核对*"，不是"先有整体才能*取值*"。而「本步要填而正文里没有的字段一并列出」恰恰是**向上补**（⑥ → ⑤）。

### 3 · 落了什么

- **引题**：一次转换按节点层级自下而上走五步，并写出自下而上的理由、③ 不设步、以及「第三章按级升序、本章按级降序」两序不同。
- **步按级切，不再按界面档切**（菜单档原一口吃 ①②④ 三级，与按级走对不上）。新五步＝**① 定义功能操作项需求（⑦）／② 定义表单标签页需求（⑥）／③ 定义窗口标签页需求（⑤）／④ 定义末级菜单与岗位标签页需求（④）／⑤ 定义非末级菜单需求（② ①）**。①② 合成一步，是因为它们共用**非末级菜单规则**——合成一步免得出现一个无新规则的节。
- **顺带修掉旧病**：④ 原来被劈在两步里（第一步的末级菜单＋第二步的岗位标签页），现在合成一步、两面一次做完。
- **三处取值翻向**（原为向下或错位）：
  - **⑥ 的表单字段**——改为与 ⑤ 的正文实体结构**同源于 X 的正文实体类型**；本页要填而正文没有的字段，**上一级（⑤）那一步并进来**。

**原有八条**：过程／规则的判别句；规则名的形（名字写足限定；按过程里首次被点到的次序排；别处引名不引表号）；清单体例；**常量不占列**；动词查归属；「定义」是加工程度；**自足**。

**2026-09-23 三条**：一段话只答一个问题；凡两处出现同一个词先问「它主语是谁」；深度与内容是两个正交坐标；「有证据≠有权改」只管权威文档。

**2026-09-24 三条**：先看宾语再看动词；同一件事只留一种口气；自造名先在权威里找根。

**2026-09-25 六条**：一个词换对，一处不一致自行消失；凡「父由子导出」的规则，单独问一次「子从哪来」；**「找根」的产出可以是修订清单而不必是批准**；三样各一处——目标写「做什么」、要素表写「有什么」、规则写「怎么算」；凡要判「这里该不该有退回」，先问两端是不是同一份产品数据；**「交接」与「承接」是两个关系，别互相代答**。

**2026-09-25 下半场（据本轮裁法与追问）**：

1. **组装型句式搬进深化型会现形**——「需求侧」、「末三级与 X 同指」、「表4-1 的两列对应」都是 abr 的话。凡见到一个**子集被单挑出来说**的句子，先问「为什么不是整体」。
2. **单位名随活取窄，不随上游抄宽。**
3. **引语只留「下一节或下一张表不会逐行说一遍」的东西。**
4. **注区判据**——落得进「某一级的某一行」的，归那张表；落不进的才留注。
5. **要素表的一行该答「是什么」，不该答「用途」。**
6. **同一份文件里两处逐字相同的图／表就是重复**——Y ＝ X ＋ Δ 时，加号左边只在 X 侧给一次。
7. **删重之后要顺着引用扫一遍。**
8. **判转换方向：把跨级取值列出来数——向上多是自下而上，向下多是自上而下。** 根子是**别把「包含」当「生成」**：包含关系推得出"先有整体才能核对"，推不出"先有整体才能取值"。
9. **「清单序」与「过程序」是两回事**——同一批级，清单按升序好查、过程按降序好跑；两序不同不是错，但要在过程那一边点一句，免得读者以为有一处写翻了。
