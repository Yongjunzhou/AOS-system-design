## 五、可直接继承的尺子

**原有八条**：过程／规则的判别句；规则名的形（名字写足限定；按过程里首次被点到的次序排；别处引名不引表号）；清单体例；**常量不占列**；动词查归属；"定义"是加工程度；**自足**。

**2026-09-23 三条**：一段话只答一个问题；凡两处出现同一个词先问"它主语是谁"；深度与内容是两个正交坐标；"有证据≠有权改"只管权威文档。

**2026-09-24 三条**：先看宾语再看动词；同一件事只留一种口气；自造名先在权威里找根。

**2026-09-25 六条**：一个词换对，一处不一致自行消失；凡"父由子导出"的规则，单独问一次"子从哪来"；**"找根"的产出可以是修订清单而不必是批准**——同一次搜索，前一种用法卡设计，后一种用法把权威变成杠杆；三样各一处——目标写"做什么"、要素表写"有什么"、规则写"怎么算"；凡要判"这里该不该有退回"，先问两端是不是同一份产品数据；**「交接」与「承接」是两个关系，别互相代答**。

**本会话新增七条（据人类这半天的裁法与追问）**：

1. **组装型句式搬进深化型会现形**——"需求侧"（第二章头一句）、"末三级与 X 同指"（§3.1 的注）都是 abr 的话。凡见到一个**子集被单挑出来说**的句子，先问一句"为什么不是整体"。
2. **单位名随活取窄，不随上游抄宽**——同一件事 abr 叫「末三级」（它的活恰好落在三级上）、abp 叫「末级」（它的活只到 ⑤）。
3. **引语只留"下一节或下一张表不会逐行说一遍"的东西**——表说得清的不进引语；引语只交代"这张表在说什么"与"表说不清的那一条边界"。
4. **注区判据**——落得进"某一级的某一行"的，归那张表；落不进的（管全级、跨两级、档名）才留注。
5. **要素表的一行该答"是什么"，不该答"用途"**——「内联稳定标签 | 下游逐级对上的追溯键」是反例。
6. **同一份文件里两处逐字相同的图／表就是重复**——Y ＝ X ＋ Δ 时，加号左边只在 X 侧给一次。
7. **删重之后要顺着引用扫一遍**——删 表3-1 时带出 §3.3 与 §4.4 两处「表3-1」要改指表2-1。
