## 二、本轮新立的口径（下一轮以此为准，别引中间态）

- **动作名＝「定义 X 需求」**：动词 `定义` ＋ 宾语 `<页面落点>需求`。不写「写实 X」（造物口吻），也不写「定义 X」（宾语落在页面件上，等于说本任务造页面，而页面由平台的功能引擎按配置生成、本任务不交出）。
- **宾语决定责任归属**——同一个动作、同一个页面档，宾语是"需求"才说对：名字说本任务定的是哪一档需求，正文说这一档要写足哪些条目。
- **形态名与内容名是两回事**——`框架／概要／定义` 是形态名，`需求定义` 是内容名，故「定义 X 需求」与"本任务交出的是定义"不打架。
- **一个概念只留一个词**——本轮把「要求」清干净（该词在 91／93／94 里本就无根）。
