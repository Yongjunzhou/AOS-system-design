[07-generalspec-architecture-fundamentals.md](00-generalspec/07-generalspec-architecture-fundamentals.md)，v3.0。

**八章结构**（经审视重组后）：
- 第一章 基本术语（系统/架构/架构描述与视图/架构决策/相关方与关注点 + 设计链缩写表含 OR/STR/BP/SR/PA/FR/NFR + 阅读指引）
- 第二章 基本原理（一个系统一个架构/架构决策不可避免/约束即解放/视图完备性由相关方决定/架构是不可逆决策的提前投资）
- 第三章 架构的目的与意义（认知/决策/变更/组织/经济五层面 + 系统理论 + 电商双理论案例）
- 第四章 架构决策（三层不可逆性判断框架 + 决策记录六问格式 + 操作化落地：标注/审查门禁/推迟决策）
- **第五章 设计链中各层的架构决策**（原 §7 前移，紧接 §4 形成"决策理论→决策应用"主线：医学类比 + OR/STR 分界 + STR/BP/SR/PA 逐层决策表 + BP 表已显式标注 L1~L5 + 四层全景对比 + 链两端高风险规律）
- 第六章 架构视图（主流框架对比 + 从相关方推导七候选视图 + 完备性自检 + 五层链×七视图映射与缺口分析）
- 第七章 企业架构 4A 辨析（Zachman 起源 / 4A=四个管理地盘 / 4A×七视图交叉矩阵 / 三问题 / 三原因 / 共存各司其职）
- 第八章 业务架构实践（BA 视图形态与颗粒度 + 能力描述方法 + 五层价值 + 相关方参与 + 能力成熟度提升循环）

**术语区分**：设计链层缩写为 **BP**（业务流程，Business Process），五层链为 OR → STR → BP → SR → PA；4A 域和行业业务架构概念使用 **BA**（业务架构，Business Architecture）。§8 全文使用 BA 指代业务架构领域概念，仅在 §8.2.3 中以 BP 指代本方法论设计链层以与行业 BA 对照。

**Why**: 从「什么是系统、什么是架构」出发，推至架构决策的不可逆性、架构视图的完备性推导、EA 四域的本质、需求方案与架构的边界、设计链各层决策特征、业务架构实践。

**How to apply**: 作为 `01-generalspec-sysdev.md` §1.1 中「架构」词条的扩展阅读；新成员入门先读本文档建立架构认知，再读通用系统设计规范学习具体操作。八章可按读者角色选读：建立认知→§1~§3，学习决策方法→§4+§5，理解视图→§6，辨析 EA 4A→§7，实践 BA→§8。
