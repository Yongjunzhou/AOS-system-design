## 下一阶段定案：eng 链设计归属重构（设计 → wft01-eng，wft02-eng 退详细定义）★ 最重要

2026-08-20 讨论中人类逐步钉死核心概念，逻辑上逼出重大结论：

**人类定义：设计 = 分解、分配、分析**（不含概要定义、不含详细定义）。

**推理链（人类逐步确认）**：
1. 设计的对象与动作：**引擎需求概要末级节点（=名称级 CU 候选）** → 分解 → **详细定义的需求条目** → 分配 → **找一个 CU 承接**（1:1）
2. 分解 = 概要末级节点 → 详细需求条目；分配 = 详细需求条目 → 找 CU 承接；分析 = 检查分解分配正确性
3. **设计决策与设计过程不可分离**——01 定概要（决策）、02 定分配（过程）= 权威错位；决策在哪、过程就在哪
4. **收敛判定 ⊂ 分配**——"找一个 CU 承接"本身就是复用/新建/拆分/合并的决策（对应七判定）
5. **∴ 设计（分解分配分析）应在 wft01-eng**（含收敛判定上移）；**wft02-eng 退为详细定义**（配置信息组/配置能力/依赖/状态迁移）

**定案后的分工**：
- **wft01-eng（设计）**：概要定义 + 分解（概要末级→详细需求条目）+ 分配（条目→CU 候选承接，含收敛判定）+ 分析（完备性）；STR-E 产出 = 概要 + 详细需求条目 + CU 承接关系
- **wft02-eng（详细定义）**：展开已分配的 CU——配置信息组拆分、配置能力四要素、依赖、状态迁移

**牵动范围**（改动量大，需专项会话实施，参照 v9.0 知识层重构的"先定方案→讨论-裁决→逐步落地"节奏）：
