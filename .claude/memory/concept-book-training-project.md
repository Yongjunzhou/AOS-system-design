2026-08-19 启动：把 50-reserch/01~08 八份概念研习笔记做成两个**共享同一套架构**的产出——分组研讨式培训教材 + 独立成书的教材书。

**培训教材决策**：同类分组（产品组/IT组分开答同一组题，老师做镜像对照）；时长不设限、内容全覆盖、业务逻辑由浅入深；放 `50-reserch/培训教材/`；单元模板=导读/题卡/讲师版（答案分级+反转话术+产品IT对照）/知识卡片/课后阅读；单元一样章已产出（`50-reserch/培训教材/01-单元一-工程-样章.md`）。

**教材书定位**（已定）：独立成书（不依赖 EOS 方法论，跨行业成立）；标准当骨架（正文概念叙述、条款下沉出处栏）；思想著作风格（非教科书、非参考手册）；成功标志=消除概念误解——「大部分人在不准确的地基上盖房子」。使命推论：**每章以流行误解为主轴**，认知反转从章尾点缀升级为章主轴（误解→它怎么害你→精确概念→可操作判据）。

**误解是词汇病**（用户定性）：大多数人连架构/评审/验证/确认/概念这类最底层词都"能用、不会定义、各指各的"。三类误解病：①未建立定义（只能举例）②同词异义（同一词各指各的概念，含翻译伪朋友如评审/验证/确认——3.11与3.8不同术语组）③近邻混用/乱用。

**理解概念框架 = 概念档案（用户逐步定型，九格，四层）**：定界层——①定义（一句话+可检验判据）⑥对立面（远端边界，常分维度，如工程×科学/手艺/艺术、治理×统治）⑦辨析（近端边界，和谁最像但不一样）⑨术语英文来源（中英对照+词根，如 governance←kybernân 掌舵；破解翻译伪朋友/跨域对齐）；溯源层——②背景（诞生处境）③演化的历史（词源/标准版本/机构改写/翻译定译/跨域迁移——更正：非"演化的理解"）；致用层——④拟解决的问题 ⑤适应场景（何时用/边界/何时不用）；纠误层——⑧误区（最常见的误解）。叙述顺序：定界→溯源→致用→纠误。第0章教这把尺子，第1~9章每个核心概念填一张档案；训练讲师版按九格点评。

**教材书结构**（已定）：**第0章"概念的语法"**（术语≠概念·能指≠所指·翻译伪朋友·五维理解工具·认知链全景图）+ 三篇九章：
- 上篇·概念的地基：ch1 工程(05) · ch2 三基座-需求设计开发质量(01) · ch3 需求工程(02)
- 中篇·判断与决策：ch4 评审验证确认(03，从原第6章提前，因三个参照直接建立在ch2/3上) · ch5 架构概念(06§1-3+07) · ch6 架构决策(06§4-5)
- 下篇·控制与治理：ch7 配置管理(04) · ch8 治理(08) · ch9 整合贯通(全部)

**每章模板**（已认可，七块）：①章首·误解现场（案例团队正在犯的病，悬念）②本章问题（3-5问）③正文·概念档案（本章N个核心概念各填九格档案，内序定界→溯源→致用→纠误；双域案例镜照穿插；概念间按链条/对照排列）④章末·认知反转（最重反转呼应章首；每概念⑧格=小反转，章末=大反转）⑤本章判据（金句+可操作自检清单）⑥练习（5题，与训练题卡同源，答案章末）⑦小结+延伸阅读。落地处理：档案织进正文不显式框格，仅辨析/对立/误区做显式栏+本章最重概念给显式概念卡片；九格是作者完整性清单，薄格一句话或省略。

**改编策略（笔记→书，五步）**：①定章骨架——反推法：把源笔记全部反直觉点捞成本章靶子清单，章首/档案/章末反转按靶子分配 ②定主场——每个概念唯一主场章，其他章只交叉引用（去重：systematic辨析主ch1、评审验证确认主ch4、配置基线版本主ch7、概念符号学主第0章、工程四要素主ch1）③填档案——按九格从笔记抽取 ④穿案例——案例承担全部举例功能 ⑤补书件——判据清单/练习答案/概念总图/附录。强制点：独立成书——06 §4.2 EOS流水线示例须换通用例；OR/STR/BP/SR/PA 仓库自造术语须通用化。

**三者关系**（已定）：一个源（研习笔记=概念原料）、两个产品（书=叙述形态/训练=问题形态）；单一权威**长在书里**——术语表+概念档案集在书附录，训练/笔记引用书，不各自维护；书↔训练逐格映射（章首误解现场↔题卡Q1、正文档案↔讲师版九格点评、章末反转↔反转话术、判据↔知识卡片、练习↔题卡）。

**写作顺序与篇幅**（已认可，七步）：①定两个贯穿案例→②写第0章（术语口径+九格尺子+认知链全景图）→③写第2章三基座样章（理论核心/风格试金石）→④写第1章工程→⑤写3~8章→⑥写第9章整合→⑦附录（术语表/档案集/误解清单/标准索引）+全书逐章一致性通读。篇幅：每章1.2-2万字，第0章0.8-1.2万，全书约15-20万字；每章过"七块模板齐不齐+九格完整性"双自检。训练教材书成型后按映射重派生（单元一样章先行，书风格定盘后回改）。
