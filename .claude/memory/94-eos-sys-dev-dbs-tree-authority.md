- **§1.3 产品数据的两个形态**——级语义表（叶＝末级 / 枝梢＝叶上一级 / 概要＝根→枝梢 / 完整态＝根→叶）；叶只在完整态产出；**叶的判据**：叶须切到"可被独立解释、独立验证、可被唯一交出去"的粒度，故"树到哪一级为止"是**判断**非位置约定，终止标准引通用规范 §2.2.2（**只引不写**）。
- **§1.4 形态之间的承接与已定的树间对应**——承接规则（**可 N:1、不可 1:N**，依据指向 §1.2 前提三）＋ **反误读注**（"叶→枝梢"是两侧**各自最深可用原子**的对齐，**不是层级换算**）；对应关系按性质拆两张表（承接 / 非承接）；末补【待裁】注：§2.3.1 的叶（⑥ IPO功能）由 §2.4 哪一级承接待定。
