# 91 规范 v4.0 引擎体系重构（2026-07-09 讨论定稿）

## 引擎体系变更（11→13引擎，移除1→净+2）

### 新增引擎
| 引擎ID | 名称 | 层级 | 一次句能力定位 |
|--------|------|------|--------------|
| @engine-document | 文档引擎 | 功能级·产品数据类 | 将物理表转换为有封面（单据头+元数据）的功能表单，管理正文内容与文档属性 |
| @engine-ledger | 台账引擎 | 功能级·产品数据类 | 将物理表转换为无封面的条目化功能表单，管理对象=台账的定位标识 |
| @engine-indicator | 指标引擎 | 功能级·业务管理类 | 定义指标的名称/口径/目标/维度/图示，生成指标结果功能表单（列表/图示 2×3网格） |

### 移除引擎
| 引擎ID | 原因 |
|--------|------|
| @engine-requirement | 不再独立保留 |

### 保留引擎（不变）
@engine-entity / @engine-flow / @engine-workorder / @engine-project / @engine-wbs / @engine-task / @engine-kanban / @engine-progress / @engine-scheduler / @engine-menu

## 两类场景业务的结构

### 执行类（D）
```
场景业务
  └── 输出文档（PL5，文档引擎）
       ├── 封面（单据头+元数据）
       ├── 正文内容
       ├── 活动节点（PL6，工单/计划/流程三选一）
       └── 支持信息（输入文档/文档规范/合规要素/作业指南/所需资源——非节点）
```

### 管理类（PCA）
```
场景业务
  └── 输出文档（PL5，台账引擎→管理对象=封面）
       └── 管理子项（PL6）
            ├── 指标清单 → 指标引擎
            ├── 看板清单 → 看板引擎
            ├── 项目清单 → 项目引擎
            ├── WBS清单 → WBS引擎
            ├── 任务清单 → 计划引擎
            ├── 风险清单 → 工单引擎
            ├── 问题清单 → 工单引擎
            └── 进展记录 → 进展引擎
```

## Biz 三 Skill 新职责

| Skill | 职责 |
|-------|------|
| **wft01-biz** | 基于OR推断定义场景业务节点和子节点（含类型判定D/PCA），基于端到端补充业务需求 |
| **wft02-biz** | 生成A2+Bn产品业务架构；推断输出文档及子节点/管理子项的需求及支撑引擎；基于Bn构件的WBS补充需求 |
| **wft03-biz** | 生成菜单树/场景业务/输出文档内容/任务/管理子项各层配置需求，基于配置需求补充引擎需求 |
