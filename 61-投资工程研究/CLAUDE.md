# CLAUDE.md（61-投资工程研究 子项目）

本目录是 AOS 大项目下的**投资工程研究子项目**——**产出型子项目**，工作路径为「材料准备 → 输出」，两个阶段：

- **当前阶段：材料准备期**（2026-09-19 起）。广积材料，不求产出。
- **后续阶段：输出**。产出形态（研究报告书／方法论提炼／培训材料等）**待后续确定**，届时在此补写产出清单与目录。

材料源为 `00-投资工程研究报告/`（播客/访谈转写稿、读书笔记、专题研究稿），按 `NN-` 顺号编号，新增材料直接落入该目录。

## 材料体例（沿用首份材料，2026-09-19 定）

首份材料（`00-知行小酒馆E251-…md`）确立的**整合版**体例，后续材料照此办理——单文件自足，要点与逐字稿并存，可单独阅读也可检索：

| 区 | 内容 |
|----|------|
| 标题 | `<来源> <期号> · 对话<嘉宾>：<话题>` |
| 元信息表 | 播客／主播／嘉宾／时长／链接／转写方式 |
| 说明注 | 转写保真声明（机器转写、清了什么、没改什么、校正依据） |
| 目录 | 两部分锚点链接 |
| 第一部分 · 要点摘要 | 一句话主旨／时间轴（表格：时间｜内容）／核心观点（编号小标题＋段）／术语校正清单／值得记住的一段 |
| 第二部分 · 完整逐字稿 | `**[HH:MM:SS]**` ＋ 段落 |

**材料保真原则**：转写稿保留口语原貌（重复、语气词不删改），只做两件事——清除语音识别的复读幻觉、校正专有名词；每处校正须在说明注或「术语校正清单」中留痕，可回溯。

## 子项目边界（互不干扰）

本子项目**自包含在本目录内**（AOS 主 CLAUDE.md §九 子项目原则）：

- **处理本子项目**：工作目录 = 本目录（`61-投资工程研究/`），读本文件 + `10-claude memory/`。
- **处理 AOS 主项目**：工作目录 = 仓库根，读 AOS 根 CLAUDE.md + 主记忆 `.claude/memory/`——**不触碰本目录内容**，除非明确要求。
- **判断归属**：任务内容落在本目录 → 按本文件执行；落在 AOS 主线目录 → 按 AOS 根 CLAUDE.md 执行。

## 记忆隔离协议（必须遵守）

本子项目的记忆**独立存放**，与 AOS 项目根记忆（`.claude/memory/`）**互不干扰**：

- 本子项目的记忆位于 [`10-claude memory/`](10-claude%20memory/)：`10-claude memory/MEMORY.md`（索引）+ `10-claude memory/投资工程研究项目.md`（主记忆）。
- **处理本子项目内容时**：先读 `10-claude memory/MEMORY.md` 与相关记忆文件，写入 `10-claude memory/` 目录。
- **禁止**把本子项目内容写入 AOS 根 `.claude/memory/` 或 AOS auto-memory。AOS 根 MEMORY.md 只保留一行指向本目录的指针。
- 每个会话结束时，把最新状态同步回 `10-claude memory/`；跨设备共享走 git（机制见 AOS 根 CLAUDE.md §八）。

## 提交边界（单仓库 + 约定分区）

仓库是 AOS 单一 git 仓库，本子项目不建独立 git。提交时按目录语义分区：

- 本子项目改动与 AOS 主线改动**分别 commit**（commit message 以 `[投资工程]` 标注归属）。
- 处理本子项目时，不把 AOS 主线改动混入本次提交；处理 AOS 主线时，不把本子项目改动混入（除非明确要求）。

## 工作风格

- **禁止选项式交互**：讨论/确认事项时一律自由散文陈述（背景 + 问题 + 建议 + 理由），不用 AskUserQuestion 选项卡片让用户做多选题；用户自由回答"改/不改/怎么改"（2026-08-25 用户定，见 AOS 根 CLAUDE.md §十）。
