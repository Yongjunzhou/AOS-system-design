## 第 1 步 · 读透章，定核心与重要内容

**章问题**：同一个词为什么各指各的？误解长什么样？怎么把概念钉死？

**① 一条主线（§1~§2，定义与诊断）**
- **思想实验**：晨星/暮星 = 同一颗星、两个名 → "语言的世界里到处都是晨星暮星"——同物异名是常态不是例外
- **索绪尔**：符号 = 能指 + 所指（能指任意、所指是实质）；**语言（langue）/ 言语（parole）**——语言是全社会共有的规则系统、言语是某人某次具体使用；**每一次漂移都始于某个人的某一次言语**
- **弗雷格**：符号 → 涵义 → 指称（涵义 ≠ 指称）；晨星暮星 = 同一指称、两种涵义
- **拼图**：术语是名牌，概念是名牌背后的人
- **两种游戏**：**同物异名** = 漏的根源（隐性，合并才爆）；**同名异物** = 吵的根源（显性，当场爆）
- **术语漂移**：架构 建筑→软件→组织→数据，一次借用叠一个所指；漂移无害，**不对齐才可怕**；钉死不是反对演化，是反对同一场会议用三个版本演化
- **词汇病三形态**：病一 说不出定义只能举例（例子是插图不是定义；定义要带可检验判据）／病二 同词异义各指各的（平时不爆关键时刻爆：增量不显形、判定时刻定义才成依据）／病三 翻译伪朋友（三因：翻译逐词对应 + 90 年代术语涌入译法不一 + 中文意合语言；三动作：回英文原词 / 查词根 / 看归组）
- **验收翻车案例**：一个中文词"验收"糊住 ISO 9000 里的验证 / 确认两个概念；**拆词不是发明，是对准**；概念不对齐的代价平时看不见、合同纠纷时一次性结算

**② 一把尺子（§3，操作核心）**
- **九格 = 从三类误解反推**：病一"说不出定义"→ 定义①／对立⑥／辨析⑦；病一变种"说不出边界"→ 对立⑥辨析⑦；病二"同词异义"→ 背景②／历史③；病三"翻译伪朋友"→ 英文来源⑨；乱用 → 问题④／场景⑤；残余 → 误区⑧
- **四层九格**：定界（定义 / 对立 / 辨析 / 英文）· 溯源（背景 / 历史）· 致用（问题 / 场景）· 纠误（误区）
- **使用规则**：薄格可省，不可跳过——跳过的那格往往是误解潜伏的地方（填不出误区⑧ = 正站在误区里；填不出背景② = 不知道为什么用它）；格子为治误解服务，不为填满服务（架构的⑥为空、⑦接住伪概念）
- **现场演示**：量"架构"（注意⑥对立为空、⑦辨析接住"伪概念"）；等级薄格示范（薄格可省的实战，误解集中在"等级≠质量"一处）
- **案例进展①**：重新开那场会——摆词 → 对齐 → 分头处理，四十分钟吵架变十五分钟对齐
- **三场景**：开会前对齐清单（三分钟）／审文档当检查单（显微镜）／写规格先填档案（反而更快）
- **三层**：个人层（两分钟）／团队层（五分钟）／组织层（术语表是活标准）
- **常见问题四问**：字典定义够不够（治不了三病）/ 九格是否繁琐（该查时查全）/ 一个词多概念用哪个（**语境决定所指**）/ 全书每词都填九格吗（不，只钉值得钉的词）

**③ 一张链（§4，导航）**
- 认知链：发尺子(1) → 工程(2) → 三基座(3) → 需求工程(4) → 需求的完整性(5) → 设计开发落地(6) → 评审验证确认(7) → 架构(8) → 架构决策(9) → 配置管理(10) → 治理(11) → 整合(12)；越往后越接近"整个组织的运转"
- 两条案例线（冰链 / 恒信）· 各章误解预告表 · 三种读法（通读 / 查概念 / 做练习）

**④ 一个反转（章末）**
- 三个人都没错，错的是会议本身；"你没有错，但你说的话没法验证对错，因为你没有用定义说话"；对齐三分钟 vs 不对齐两个月

**重要度分层**：
- 一级（定义 + 操作核心）：术语≠概念（能指 / 所指）/ 病二机制（平时不爆关键时刻爆）/ 九格反推 + 薄格规则
- 二级（重要分界）：词汇病三形态 / 同物异名·同名异物 / 例子≠定义（判据可检验）/ 翻译伪朋友（三因三动作）/ 术语漂移 / 语言·言语
- 三级（落点）：九格三场景 / 对齐代价 / 语境决定所指 / 认知链 / 等级薄格示范 / 验收翻车

**五判据**：术语是能指概念是所指 / 误解三形态 / 九格钉死（薄格可省不可跳过）/ 用定义说话不用例子 / 九格是动作不是知识

**章末认知反转**：你没有错，但你说的话没法验证对错，因为你没有用定义说话。

## 第 2 步 · 提炼掌握清单

### A. 概念层（11 条）

| # | 概念 | 一句话 | 掌握标准 |
|---|---|---|---|
| 1 | 术语 / 概念 | 能指 / 所指——名牌 / 名牌背后的人 | 背出"术语≠概念"；用能指所指解释同词异义 |
| 2 | 符号 | 能指 + 所指统一体（索绪尔） | 说清"三个架构 = 同一能指三所指"；能指只是形式面 |
| 3 | 语言 / 言语 | langue 全社会规则系统 / parole 某人某次使用 | 说清"语言规则怎么变、漂移从哪开始" |
| 4 | 涵义 / 指称 | 呈现方式 / 实际对象（弗雷格） | 用晨星暮星证明"涵义≠指称" |
| 5 | 同物异名 | 同一指称多涵义 | 说出 = 漏的根源（隐性，合并才爆） |
| 6 | 同名异物 | 同一符号多所指 | 说出 = 吵的根源（显性，当场爆） |
| 7 | 词汇病 | 误解三形态（说不出定义 / 同词异义 / 伪朋友） | 认清病，知道用什么药 |
| 8 | 翻译伪朋友 | 英文原词不同、中文形近 | 回英文现形（review / verification / validation） |
| 9 | 概念档案 | 九格完整档案 | 会填；知道薄格可省不可跳过 |
| 10 | 九格尺子 | 四层九格 | 背出四层；会从三病反推 |
| 11 | 术语漂移 | 借用叠出多所指 | 解释"漂移无害、不对齐有害" |

### B. 原理层（12 条）

| # | 原理 | 机制 | 掌握标准 |
|---|---|---|---|
| P1 | 术语≠概念 | 能指任意，所指是实质；**语境决定所指** | 解释"架构三个意思正常，但得说清指哪个"；"一个词多概念用哪个 → 看语境" |
| P2 | 涵义≠指称 | 同一指称多涵义、同一涵义多符号 | 用晨星暮星 + 例句证 |
| P3 | 语言是约定 | 约定是历史积累不是逻辑推导；模糊是 feature | 解释"苹果为什么叫苹果"；模糊的另一面 = 歧义 |
| P4 | 漂移始于言语 | langue 规则全社会慢变，每次漂移始于某人某次 parole | 解释"我多用一次词义没什么"错在哪 |
| P5 | 漂移无害、不对齐有害 | 借用叠概念；害在没人察觉漂移 | 区分"反对演化"与"反对一场会议三个版本" |
| P6 | 例子≠定义 | 定义答"是什么"、带判据；例子答"长这样" | 当场给"需求"下定义；评审判据 = 结论 + 记录 |
| P7 | 病二"平时不爆关键时刻爆" | 增量不显形，判定时刻定义才成依据 | 解释"没爆过≠没病"；两份合同合并才冲突 |
| P8 | 伪朋友三因 | 翻译逐词对应 + 术语涌入译法不一 + 中文意合 | 解释中文为何尤其易踩；回英文现形 |
| P9 | 九格是反推产物 | 每种病需要什么信息就给一格 | 从三病推出对应格 |
| P10 | 薄格可省不可跳过 | 空着的格 = 误解潜伏处 | 填不出误区⑧ = 正站在误区里 |
| P11 | 九格是动作不是知识 | 三场景：开会前 / 审文档 / 写规格 | 各场景说出具体动作 |
| P12 | 对齐代价 | 三分钟 vs 两个月；矛盾时对齐 = 收拾残局 | 解释"不对齐的会议把错误付诸执行" |

### C. 判据层（5 把尺子）

术语≠概念（能指 / 所指；语境决定所指）／ 误解三形态（病一病二病三）／ 九格钉死（四层；薄格可省不可跳过）／ 用定义说话不用例子（判据可检验）／ 九格是动作不是知识（三场景）。

**掌握标准三档**：
- **必须脱口**：术语≠概念 / 例子≠定义（判据可检验）/ 病二"平时不爆关键时刻爆" / 九格反推 + 薄格
- **能解释**：涵义≠指称 / 语言·言语（漂移始于 parole）/ 同物异名·同名异物 / 翻译伪朋友三因 / 对齐代价 / 语境决定所指
- **知道即可**：认知链 / 等级薄格示范 / ISO 归组细节 / 各章误解预告

**覆盖校验**：概念 11/11、原理 12/12 有题；判据 5 条两组各钉一层（详见 §7 覆盖校验）。

## 第 3 步 · 反推学员常识与误解

**总根源**：人信"看得见的词"，概念判据全在"看不见的所指"。四机制：**①载体误判**（用什么做 = 是不是）｜**②结果误判**（做成了 = 做得好）｜**③范围误判**（看得见的局部 = 全部）｜**④定义缺席**（词汇病：用名词 / 例子代替定义）。机制可**复合标注**（主 + 次）。

**概念层误解（完整）**：

| 概念 | 学员常识（原话） | 误解点 | 机制 | 反转 |
|---|---|---|---|---|
| 术语/概念 | "术语和概念是一回事" | 用词代替概念 | ④①★ | 能指≠所指；名牌≠人 |
| | "架构就是架构，三个意思正常" | 把歧义当正常 | ③ | 正常≠不用对齐；各干各的 = 埋分歧 |
| | "名词会告诉你它是什么" | 词即定义 | ④★ | 名词不能替你定义 |
| 符号 | "符号就是词/图标" | 把部分当整体 | ③★ | 符号 = 能指 + 所指统一体；能指只是形式面 |
| 语言/言语 | "词义是国家/字典定的，是规则系统" | 只见规则不见使用 | ③ | langue 是全社会慢变；每次漂移始于某人某次 parole |
| | "我多用一次词义没什么" | 低估单次言语累积 | ②★ | 每个不精确使用都在为漂移添一块砖 |
| 涵义/指称 | "晨星暮星是两颗星" | 把涵义当指称 | ①★ | 指称相同，涵义不同 |
| | "同一个东西就该叫一个名字" | 涵义 = 指称 | ④① | 同指称可多涵义 |
| 同物异名 | "同物异名只是别名，无害" | 只看到显性 | ②★ | = 漏的根源，合并才爆 |
| 同名异物 | "同名异物吵一吵就过去了" | 低估代价 | ③ | = 吵的根源，把错误付诸执行 |

| 翻译伪朋友 | "评审/验证/确认差不多" | 中文字面判词 | ①★ | 英文原词完全不同；回英文现形 |
| 概念档案 | "九格每格都要填满" | 把完整性清单当仪式 | ③ | 薄格可省，不可跳过 |
| 九格 | "看懂就够了，填格 = 形式主义" | 定义缺席 | ④①★ | 看懂不可检验；九格是反推产物 |

| P9 | "九格是拍脑袋/模仿别人" | 当摆设 | ④ | 九格从三病反推 |

## 第 5 步 · 定纠错策略

**强化点优先级（按消除误解的杠杆排序）**：

| 优先 | 强化点 | 反制哪些误解 | 练到何种程度 |
|---|---|---|---|
| ★1 | 术语≠概念（能指 / 所指） | 病一 + 病二 + 病三（所有误解的根源） | 肌肉记忆：听到"架构就是架构"自动问"你说的架构指称什么" |
| ★2 | 病二"平时不爆关键时刻爆" | 结果误判（"我们没这病"最顽固） | 关键时刻前自动问"这个判定，定义对得上吗" |
| ★3 | 例子≠定义（判据可检验） | 病一 | 听到"评审就是开会"自动问"判据呢" |
| ★4 | 翻译伪朋友（回英文现形） | 病三 | 遇到"中文长得像"自动回英文原词 |
| ★5 | 九格反推 + 薄格 | "形式主义 / 每格必填" | 知道每格治什么病，该查时查全、该空时空 |
| ★6 | 漂移始于言语（langue/parole） | "我多用一次没什么" | 每次不精确使用前问"我在为漂移添砖吗" |
| ★7 | 对齐三分钟 vs 两个月 | "对齐太麻烦" | 开会前先问一句核心词所指一样吗 |

**十条纠错红线**：
1. **先表态、后翻案**——跳过踩坑，翻案不疼（误解是"信了相反"，不是不知道）
2. **反转精确，别反转过头**——术语≠概念 ≠ 术语不重要（名牌要挂对人）；模糊是 feature ≠ 不需要对齐（歧义是另一面）；任意性 ≠ 随意性（约定建立后个体须遵守）；钉死定义 ≠ 反对演化（反对一场会议三版本）
3. **判据配机制**——会背"术语≠概念"≠会用，每把判据配"为什么"
4. **归责落到可对照动作，不指责人**——验收留白 = 把定义权交给扯皮那天（是合同没对准，不是有人耍赖）
5. **教机制不教断言**——纠正"术语=概念"后，遇到"质量就是档次"还能踩病一
6. **先立尺子再翻案**——第1章发尺子，后面各章用尺子（认知链起点）
7. **拉开强度层次**——留 3~4 个最重靶子下重手（术语≠概念 / 病二机制 / 例子≠定义 / 伪朋友）
8. **每个纠正落到可操作动作**——定义一句 / 判据一条 / 开场三分钟对齐
9. **单一权威**——训练引书 + ISO 9000 / 索绪尔 / 弗雷格，不另立标准
10. **网搜当弹药不当铁证**——事实进题面、观点进讲师版

**第一组 · 概念与原理（概念层能定义辨析、原理层能解释为什么）**

**Q1（破题 · 见树见林① 概念本身 · 术语≠概念）** 一家公司季度会，三个人三句话三个"架构"：老板说"我们公司的**架构**不行，管理层级太多"；产品总监说"我说的是产品**架构**，M3 的模块边界该重新划了"；技术总监说"你们说的都不是**架构**，系统架构是服务边界、数据所有权这些事"。吵了四十分钟，谁也没说服谁。有人劝架："三个'架构'各有各的意思很正常——语言本来就是灵活的约定，模糊是它的本性。术语和概念就是一回事，各干各的就行，何必较真。"**请先表态："术语和概念是一回事，各干各的就行"站得住吗？然后用一句话定义"术语"和"概念"（用能指/所指），并用你的定义判断：三个"架构"是一个概念还是三个概念？** 追问：①索绪尔：符号=能指+所指——三个"架构"是同一个能指、三个所指，对吗？②弗雷格：符号→涵义→指称——"晨星/暮星"是两个能指、两种涵义、同一个指称。这是"术语≠概念"的证据吗？③"语言灵活"和"概念对齐"都对——那到底什么时候该较真？给一条判据。（同一场会议里三个版本演化 = 该对齐；语言整体演化 = 不必钉死）④如果这场会不散、老板拍板"架构要改"，产品和技术各按自己的理解去改——两个月后会发生什么？（"各干各的"省下四十分钟，付出去的是什么？）⑤反身：你刚才给"术语 / 概念"下的定义，本身可检验吗？——还是你只能"举例说明"？（这一章的核心：懂 ≠ 能定义）

**Q2（见树见林② 概念关系 · 索绪尔×弗雷格七词 + langue·parole）** 有人说："索绪尔说符号=能指+所指，弗雷格说符号→涵义→指称——两套理论，我该记哪个？反正都是说'词和意思'。"也有人说："符号学是研究词的，跟我们做系统有什么关系？"**请给出符号、能指、所指、涵义、指称、术语、概念这七个词的关系——谁包含谁、谁对应谁；再把"语言（langue）"和"言语（parole）"放进这张图。然后回答：索绪尔和弗雷格是两套理论，还是同一件事的两层？** 追问：①索绪尔停在"符号有形式和内容"（能指+所指）；弗雷格多出的一元是什么？它回答什么问题？（涵义 = 呈现方式——同一个东西为什么能有两种说法）②"术语是名牌，概念是名牌背后的人"——比喻里"名牌"对应哪个词、"人"对应哪个？"涵义""指称"在比喻里又对应什么？③用这张关系图解释：晨星/暮星（同物异名）和章首"架构"（同名异物）——各是哪个关系出错了？（多涵义一指称 / 一符号多所指）④langue 和 parole 在哪一层？——"语言的规则是全社会慢慢变的，而每一次漂移都始于某个人的某一次言语"。这对"我自己用词随便点没事吗"给出了什么答案？⑤这张图对"判断一个词该不该对齐"有什么用？（先分清是漏还是吵——漏的根源 vs 吵的根源）

**Q3（原理 · 语言是约定 · 术语漂移 · 真悖论）** 有人说："语言是精确的编码系统——一个词就该对一个意思。'架构'一个词挂了五个意思，这是语言出了 bug，得修。"也有人说："术语漂移是坏事，应该把每个词的词义都钉死，禁止演化。"还有人说："能指和所指本来就是随便配的——反正任意，我用什么词义都行。"**语言是 bug 还是 feature？术语漂移是坏事吗？'钉死定义'在反对什么？'语言任意'等于'随便用'吗？** 追问：①"苹果"为什么叫苹果？语言为什么是约定不是精确编码？（约定的灵活 = 几亿人共用一套符号；灵活的另一面 = 歧义）②"架构"从建筑→软件→组织→数据，每一次借用叠一个所指——漂移本身有害吗？有害的是什么？（没人察觉漂移 / 不对齐）③"钉死定义"反对的是什么？（反对在同一场会议里用三个版本演化，不是反对演化）④"语言任意性"说的是什么？——能指和所指之间没有必然理据（当初叫"banana"也行）；但约定一旦建立，"我随便用"还成立吗？（任意性 ≠ 随意性：langue 是规则系统，个体必须遵守才能被听懂）⑤你们团队有没有一个词正在漂移、没人察觉？（哪个词在不同部门各自长了一个意思？）

**Q4（原理 · 病二机制 · 平时不爆关键时刻爆 · 真悖论）** 有人说："我们团队从没出过'同一个词各指各的'的问题，说明我们没这个病。"也有人说："词对齐等出问题再对齐也不迟——平时各干各的挺顺的，何必为可能不发生的矛盾提前花时间。"**平时没爆过，是没病，还是还没到判定时刻？词对齐能等矛盾出现再做吗？** 追问：①平时讨论"加个功能"（增量），为什么各自的定义不显形？关键时刻讨论"算不算/该不该"（判定），为什么定义才第一次成为依据？（两份合同平时各自执行没事、合并才冲突）②矛盾出现时的对齐，是在干什么？（收拾残局）——"验收"翻车案例：四个月扯皮才拆词，拆只要两天，为什么没人早拆？③真悖论收束："平时不较真"（效率）和"关键时刻对得上"（正确）都对——靠什么判据分清什么时候该花对齐的三分钟？④一场会议"没对齐就散会"和"对齐三分钟再开"，差别在哪？（四十分钟 vs 两个月）⑤你们团队最近一次"关键时刻"（评审/验收/变更），有没有一个词让大家突然发现"我们说的不是一回事"？（自我指涉）

**Q5（原理 · 九格反推 · 薄格可省不可跳过）** 有人说："理解一个概念，看懂就够了，何必填九个格子——九格是形式主义。"也有人说："九格既然是九个格子，每一格都必须填满，少一格就是偷懒。"**九格是形式主义，还是从误解反推出来的尺子？每一格都必须填满吗？** 追问：①"看懂"这个标准本身可检验吗？——当场用一句话给"质量"下定义（不许举例）。下不出来的，是你不懂，还是"看懂"站不住？②九格怎么反推？——病一"说不出定义"要哪几格（定义①/对立⑥/辨析⑦）？病二"同词异义"要哪几格（背景②/历史③）？病三"翻译伪朋友"要哪几格（英文来源⑨）？③"薄格可省，不可跳过"——哪一格最容易空着？为什么空着的那格往往是误解潜伏的地方？（填不出误区⑧ = 正站在误区里；填不出背景② = 不知道为什么用它）④一个词有多个概念（"架构" = 组织/产品/系统），我到底该用哪个？——九格规定"只能用哪个"吗？（不——语境决定所指；九格要求"说清用的哪个"）⑤"每次开会都填九格谁受得了"——九格是"每次量全"还是"该查时查全"？（作者/审稿人的完整性清单；日常只动①或⑧⑦或①⑤两三星）

**第二组 · 落地与实践（判据运用 / 场景落地 / 回部门动作）**

**Q6（判据运用 · 病一 · 例子≠定义）** 有人说："'评审就是开会过一遍''验证就是测试''质量就是档次高'——这些就是定义，大家都这么理解，够用了。"**请先表态：这些是定义吗？然后用一句话给"需求"下定义（不许举例）——定义要带什么才算数？"评审"的可检验判据是什么？** 追问：①例子是插图还是定义？——"不走流程的聊天算不算评审"，用"开会过一遍"判得出来吗？（例子只答"它长这样"，定义才答"它是什么"）②"说得出口的例子"为什么最危险？（让人误以为自己懂了；到评审结论/验收标准/需求变更这些关键时刻，一个没有判据的理解就是事故的种子）③你们最近一次"评审"，开完有没有结论、有没有记录？没有的话——按定义它最多算什么？它为什么会发生？（自我指涉）

**Q7（判据运用 · 病二 · 验收翻车 · 真悖论）** 一家医疗器械公司跟医院签验收条款："系统通过验收后，尾款付清。"谁也没定义"通过验收"是什么。半年后系统上线，医院说"验收没过——临床科室用得顺才算"；公司说"验收过了——功能测试通过"。扯了四个月，最后查合同，"验收"一次都没定义。有人说："总有一方在无理取闹——要么医院耍赖，要么公司推卸责任。"**请先表态：哪方在无理取闹？然后回答：如果两方都没错，错在哪个词上？'验收'糊住了几个概念、各是什么？** 追问：①真悖论收束：医院要"临床用得顺"（合理）和公司要"功能测试过"（也合理）——两个都对的要求，怎么化解？（拆成两条：功能验收 = 对照技术规格 / 临床确认 = 对照实际使用——验证 vs 确认，ISO 9000 本来就是两个词）②四个月没人拆，为什么拆只要两天？（概念早就存在，没人让合同对准概念——**拆词不是发明，是对准**）③该由谁负责定义"验收"？（承制方/专业方）——把"通过验收"留白，等于把定义权交给了哪一天？（扯皮那天）④你们合同/规格里有没有"大家都懂、但没写清"的词？哪个最贵？（自我指涉）

**Q8（判据运用 · 病三 · 翻译伪朋友 · 真悖论）** 有人说："'评审''验证''确认'——意思差不多，都是检查产品有没有问题。"也有人说："中文是意合语言，翻译又逐词对应，这三个词长得像不是我们的错，没法改。"**请先表态：第一句话对吗？第二句话呢？然后回答：三个词的英文原词各是什么？中文为什么看不出区别、英文一眼就能看出？"中文长得像"注定无解吗？** 追问：①review / verification / validation 词根各是什么？（re-view 再看 / veri-fication 求真 / valid-ation 有效化）——中文为什么看不出？（意合语言 + 翻译逐词对应）②看归组：评审和"确定/监视/测量/检验"是一组（ISO 3.11），验证/确认和"规范"是一组（3.8）——归组说明什么？（该和谁放在一起辨析）③按参照物给三个词各归各：评审对____、验证对____、确认对____。（目标/需求/用途）——为什么这个区分能治病？（一次"评审"开完没结论没记录，按定义最多算聊天）④真悖论收束："中文模糊是历史造成的"和"术语必须说清"——两个都对，靠什么解开？（第⑨格：中文看不清的地方，回到英文就看清了）⑤你们行业有没有"中文长得像、英文根本不是一回事"的词？（治理/统治、需求/要求……）

**Q9（判据运用 · 九格是动作 · 三场景 · 真悖论）** 有人说："九格是好尺子，但我们平时用不上——写文档、开会、审文档都是靠经验，谁有空填九个格子。"**九格是知识还是动作？在开会前、审文档时、写规格前三个场景里，各怎么用？** 追问：①开会前：三分钟对齐清单（核心词各说一句"我指的是什么"）——省下的是什么？为什么很多成熟团队的开会邀请函里附一页"术语口径"？②审文档时：九格当检查单，先查什么？（定义给了吗/判据有吗/哪个概念只有例子没定义/哪格空了）——为什么说九格是审文档的显微镜？③写规格前：先填档案再写正文——为什么反而写得更快？（不用边写边纠结"这个词到底什么意思"）④真悖论收束："每次开会都填九格，谁受得了"（对——九格不是仪式）vs "该查的时候查全"（也对——跳过的那格是雷区）——怎么调和？（九格是作者/审稿人的完整性清单，日常只动其中两三星）⑤落地：设计一次"带尺子的会议"——列三个最易歧义的词，各写一句"我指的是什么"，让会议开场三分钟完成对齐。

**Q10（落地生根 · 回部门词汇体检）** 章首那场架构吵架：对齐三分钟就分流了（组织架构交 HR、产品形态另开产品评审、系统架构留下做专项），不对齐则花两个月收拾残局。有人说："那是别人的公司，我们团队没有这种'同一个词各指各的'的问题。"**先诚实回答：你们团队最近一次关键会议（评审/验收/变更），有没有一个词让大家突然发现"我们说的不是一回事"？然后：①列出你们团队最容易出歧义的三个词，各写一句"我指的是什么"；②设计一次开场三分钟完成对齐的会议（谁带头、问哪句、对齐后干什么）；③给出你们部门最应该改进的三个事项——每个事项落到一个可操作动作。**（提示："我们没这病"正是病二"平时不爆"的自我例证——先诚实面对，再谈改进。）
