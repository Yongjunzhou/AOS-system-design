# 培训教材总览（12 单元 · 以教材书为源）

> 本文件是培训教材的权威框架。与教材书共享同一套架构——**一个源（教材书），两个产品（书=叙述形态，训练=研讨/问题形态）**；术语表、概念档案集、误解清单的权威都长在书末附录，训练引用书，不各自维护。
> 编制日期：2026-08-19。本版本**以教材书 12 章为源逐格映射重派生**，替代旧 10 单元样章。

---

## 一、定位

| 项 | 定案 |
|---|---|
| 形态 | **分组研讨式**——产品组 / IT 组分开答同一组题，老师做镜像对照 |
| 时长 | 不设限；单元内节奏：组内讨论 25 分钟 + 上台讲解 4–5 分钟 |
| 内容 | 全覆盖 12 章；业务逻辑由浅入深 |
| 使命 | 与书同源：消除概念误解；同一概念，两个世界（硬件产品 / 业务流程系统）的例子 |
| 风格参照 | **参照《正向设计》培训课件**（Q&A 驱动 · 破题讨论 · 课后作业 · 讲-练-用-总），轻量借用，不改变既有单元模板 |

## 三、单元模板（六件套）

每个单元六个小节，顺序固定：

1. **单元导读**——主题、开场破题提示、本单元要反转的直觉（书"反直觉命题"）、本轮题卡的内在逻辑、同类分组说明。
2. **题卡（打印分发）**——学员版问题纸，答题要求固定（组内讨论 25 分钟 / 答案 ≤5 行 / 上台讲解 4–5 分钟 / 观点不同必须给理由）。设计规则：
   - **紧密围绕各章核心内容（首要规则）**：每道题直接从书的核心内容"问题化"——反直觉命题、核心概念档案、判据、自查题、章首误解现场、书内常见问题；用书自己的案例（恒信/冰链/晨星暮星/验收翻车/泰坦尼克·挑战者·737 MAX/机场等），**不发明平行例子**。题目举例与书主要内容的距离，就是该砍掉的部分。
   - **题目数 = 核心概念数 + 3**（破题 + 应用/关系 + 落地），5 题起步、8 题封顶：单/双概念章 5-6 题，三概念章 6-7 题，五概念章 7-8 题，贯通章 4-5 综合题。
   - **按概念分组**，组内「概念 → 原理 → 方法」递进：概念层（用定义/判据判断）、原理层（书里为什么这么定义）、方法层（判据怎么用、落地动作）。
   - **陷阱题**：把书的反直觉命题 / 自查题改造成"断言 → 表态 → 翻案"，先逼学员表态、大概率踩坑；翻案后接「追问链」（机制 / 判据 / 推演 / 自我指涉）。Q1 对齐章首误解现场作破题。**靶子必须选"大家都信、从没怀疑过"的常识，不是知识盲区**——越被当成"这不是明摆着吗"，翻案越值钱；学员听完想都不想就点头的，才是好靶子。
   - **反直觉强度（深度 · 意外 · 难度 · 收获）**——每道题的打磨目标，四维一致：
     - **意外**：断言打在大家最自信的地方，与通常认识的距离越大越好——"验收过了就是成功""有流程有测试就是在做工程""版本就是基线"，越像常识越要翻；
     - **深度**：难度不来自绕弯子 / 冷门知识，来自**机制还原**——把"显然如此"追问到"底层机制是什么、缺了哪一层、换个人换个场景还成不成立"；答得出第一层、答不深第二层的，才是深题；
     - **难度**：要答对需走完整条追问链——第一层直觉表态、第二层机制还原、第三层归责 / 判据，层层有坑、没有一望即知的正解；
     - **收获**：翻案后必须落回**可操作**处——一条判据、一个动作、一句归责；讨论完没有"那我该做什么"，题就没讨论透。
   - **概念理解支持在导读 + 讲师版，不进题卡**——题卡保持纯问题（概念速览曾加入又因"小儿科"移除）。
   - **自检**：①直觉能答对的题 → 重写；②无追问链的题 → 加深；③不看导读就无法下手的题 → 导读没把概念锚点给够；④题目内容在书里找不到依据 → 离题，砍；⑤学员听完点头"本来就知道 / 这还用讨论" → 意外度不足，换靶子；⑥翻案后答不出"那怎么办" → 收获度不足，补落到判据 / 动作的追问；⑦学员只是"不知道"而非"信了相反的东西" → 那是知识点不是陷阱题，改断言。
3. **点评要点·讲师版**——每题三栏：各组答案常见形态分级（弱/中/好）+ 讲师判读、产品侧 vs IT侧、**反转话术**、参考答案要点（引用书章节）。
4. **知识卡片**——一页图（书"概念总图"）+ 金句（书"本章判据"提炼）。
5. **课后作业**——3 题：2 题来自书"练习"（与题卡同源），1 题**"回部门落地"**（借鉴《正向设计》"请给出部门最应该改进的三个事项"，两周后回来报告）。
6. **课后阅读指引**——对应书章 + 附录检索位（附录 A 术语表 / B 概念档案集 / C 误解清单 / E 练习答案）。

## 四、书↔训练逐格映射

| 书（教材书） | 训练（培训教材） |
|---|---|
| 章首·误解现场 | 题卡 Q1（破题题） |
| 正文·概念档案 | 讲师版九格点评 |
| 章末·认知反转 | 讲师版反转话术 |
| 本章判据 / 概念总图 | 知识卡片（一页图 + 金句） |
| 练习 / 自查 | 题卡 Q2~Q5 + 课后作业 |
| 案例设定（冰链 / 恒信） | 题卡题目语境 + 讲师版产品侧 vs IT侧 |

## 五、分组研讨规则

- **同题异答**：产品组和 IT 组拿到**相同的 5 题**，各自用自己的工作语境作答。
- **镜像对照**：老师把两边的答案摆在一起点评——产品组的例子和 IT 组的例子是**同一个概念的两面**，这正是本套概念"领域中立"的证据。
- **案例走位**：主案例章 = 恒信主 2/4/6/7/9/11、冰链主 3/5/8/10、第12章双线合流；另一条线做"镜照"段落。
- **答题纪律**：允许观点不同，但必须给出理由；每题答案不超过 5 行；每组选派一人上台讲解。
