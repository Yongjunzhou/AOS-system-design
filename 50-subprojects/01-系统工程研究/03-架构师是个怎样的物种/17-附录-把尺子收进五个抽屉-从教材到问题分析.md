### 核心原理（参考原理的机制层，P1~P11）

**第一幕 · 是什么的底层机制**
1. **P1 附录不新增任何概念**——它的全部内容都来自正文，功能是"归档 + 取用"，不是"讲授"（头部"不新增任何概念"）。
2. **P2 掌握标准 = 该查时查全**——不是每次量全、不是从不查；附录的掌握标准就是它自己演示的内容（头部用法段）。
3. **P3 该查时查全 = 第1章"查"字落地**——第1章说九格是"该查的时候查全"的尺子，这五个抽屉就是那个"查"字落地的地方（头部用法段）。
4. **P4 术语宪法的单一权威**——凡是正文用词以本表为准；防词汇病（同词异义 / 同名异物 / 翻译伪朋友）靠"回到本表看指称的是哪个概念"（A 引语）。
5. **P5 跨域先查表**——恒信"合同编号"与冰链"数据所有权"：同一个词、两个世界、两个指称，先查表再谈别的（A 引语）。
6. **P6 B 区字典式查询**——"薄格可省，不可跳过"：查的是你缺的那格；跳过误区格 = 最容易切错的那刀没人警告（B 引语）。
7. **P7 C 区误解两用**——读前当预习 / 读后检验把话说准（C 引语）。
8. **P8 D/E 的回答分工**——"这条原理出自哪个标准"查 D / "这个概念怎么定义"查 A/B / "答案对不对"查 E，按"问什么"决定查哪个抽屉；D 是参考文献总表的单一权威（新增正文引用先登记编号再同步章内切片），版本号为正文实际引用的版本（D/E 引语）。
9. **P9 答案要点的方向性**——E 区给的是"往哪个方向想、用哪把尺子"，不是唯一答案（E 引语）。
10. **P10 学习闭环**——训练教材题卡与附录 E 同源；遇到任何一题答不上来，先回对应章节，再回这五个抽屉（附录收束）。
11. **P11 附录收束**——概念是刀，系统是大象。切得再细，也要缝得回来：A 是刀的目录、B 是刀的规格、C 是"哪把刀最容易切错"的警示、D 是刀的出处、E 是"刀法练得对不对"的对照答案（附录收束）。

### 本章判据（八把使用判据）

1. **该查时查全**：遇到说不清的词 / 最易误解的概念 / 误解错在哪 / 原理出处 / 答案对照——该查时查全，不是每次量全、不是从不查。
2. **术语宪法**：正文用词以术语表为准；同词异义时回本表看指称的是哪个概念。
3. **跨域先查表**：遇到跨域对不上的词（恒信"合同编号" ↔ 冰链"数据所有权"），先查本表，再谈别的。
4. **档案字典**：B 区字典式查询——从①定义开始到⑧误区为止；薄格可省，不可跳过。
5. **误解两用**：C 区读后检验把话说准 / 读前当预习。
6. **标准出处**：D 区查"这条原理出自哪个标准"；A/B 区查"这个概念怎么定义"。
7. **答案方向**：E 区给"往哪个方向想、用哪把尺子"，不是唯一答案。
8. **学习闭环**：遇到任何一题答不上来，先回对应章节，再回这五个抽屉。

## 第 2 步 · 量学立标：掌握清单

### 概念层（应能答全四问，三档标注）

> v2.1：概念层掌握标准提为**四问**（定义/辨析/溯源/致用）；档位先抓根——本章承重柱（掌握标准 = 该查时查全）与最常用抽屉入"必须脱口"，溯源/致用维度至少入"能解释"；薄格标注"可省"，不得默认跳过。

1. **掌握标准（该查时查全）**【根 · 必须脱口】：能定义（该查时查全，不是每次量全、不是从不查）；能辨析（三态各配一个误用例子）；能溯源（第1章九格"该查的时候查全"的尺子——五抽屉是"查"字落地的地方）；能致用（五场景：说不清的词/最易误解的概念/误解错在哪/原理出处/答案对照）。
2. **附录 A 术语表（术语宪法）**【必须脱口】：能定义（英中对照，正文用词唯一权威，T-01~151）；能辨析（查 vs 背；成品用词权威 vs 框架写作口径权威）；能溯源（取料于正文各章用词【薄格·可省】）；能致用（同词异义/跨域对不上的词先查本表）。
3. **附录 B 概念档案集（档案字典）**【必须脱口】：能定义（33 张最常被查最易误解九格完整版，字典式查询）；能辨析（B 33 张 vs 全书约 45 张；读 vs 查；九格=四问的展开）；能溯源（取料于各章概念卡【薄格·可省】）；能致用（从①定义到⑧误区，薄格可省不可跳过）。
4. **附录 C 误解清单（误解两用）**【能解释】：能定义（反直觉命题速查，16 行病/药/判据三栏）；能辨析（读后检验 vs 读前预习两用 vs 只用一半）；能溯源（取料于各章反直觉命题【薄格·可省】）；能致用（读完正文检验把话说准 / 读前当预习）。
5. **附录 D 参考文献总表（标准出处）**【能解释】：能定义（参考文献总表 R-01~R-85，D.1 标准 + D.2 经典文献，单一权威）；能辨析（参考文献列表 vs 检索位；出处到 D vs 定义回 A/B）；能溯源（正文引用登记机制【薄格·可省】）；能致用（查"这条原理出自哪个标准"，版本号写到条款）。
6. **附录 E 练习答案（答案方向）**【能解释】：能定义（各章练习与自查答案要点 + 对/错速查）；能辨析（方向 vs 唯一答案；同源 vs 相同）；能溯源（与训练教材题卡同源）；能致用（对答案——考有没有把话说准）。
7. 能说出"附录 vs 正文"（参考 vs 叙述；附录是刀的目录、正文是挥刀的人）与"附录 vs 索引/目录"（五抽屉各有规格，不只是指针）。

### 原理层（应能解释为什么）

1. 能解释为什么附录不新增任何概念（只是把正文发过的尺子收进随时能回来取用的地方）——P1。
2. 能解释为什么"该查时查全"是附录的掌握标准（不是每次量全、不是从不查；附录的掌握标准就是它自己演示的内容）——P2。
3. 能解释为什么附录是第1章"查"字落地的地方（第1章说九格是"该查的时候查全"的尺子——这五个抽屉就是那个"查"字落地的地方）——P3。
4. 能解释为什么术语表是"术语宪法"（凡是正文用词以本表为准——防词汇病：同词异义 / 同名异物 / 翻译伪朋友）——P4。
5. 能解释为什么跨域要先查表再谈别的（恒信"合同编号" vs 冰链"数据所有权"——同一个词两个指称，先查再谈省的是白争的时间）——P5。
6. 能解释为什么 B 区要字典式查询、薄格可省不可跳过（字典查的是缺的那格，不是全背；误区格不可跳过）——P6。
7. 能解释为什么 C 区两用（读后检验把话说准 / 读前当预习）——P7。
8. 能解释为什么 D 区查出处、A/B 查定义的分工（按"问什么"决定查哪个抽屉；D 是参考文献总表的单一权威，各章章末参考文献 = 本表切片）——P8。
9. 能解释为什么 E 区给"方向"不是唯一答案（要点给的是往哪个方向想、用哪把尺子）——P9。
10. 能解释为什么学习闭环是"先回对应章节、再回五个抽屉"（章节是上下文，抽屉是速查；先找对"它"再查）——P10。
11. 能解释附录收束句"概念是刀，系统是大象。切得再细，也要缝得回来"与五抽屉的关系（A 目录 / B 规格 / C 警示 / D 出处 / E 对照——五抽屉就是"缝回来"的工具箱）——P11。

### 判据层（应会用）

1. **该查时查全**：遇到说不清的词 / 最易误解的概念 / 误解错在哪 / 原理出处 / 答案对照——该查时查全，不是每次量全、不是从不查；三种场合（说不清时 / 检验时 / 对答案时）各会用。
2. **术语宪法**：正文用词以术语表为准；同词异义时回本表看指称的是哪个概念——当场翻表确认。
3. **跨域先查表**：遇到跨域对不上的词（恒信"合同编号" ↔ 冰链"数据所有权"），先查本表，再谈别的——先查再谈，比先争省时间。
4. **档案字典**：B 区字典式查询——从①定义开始到⑧误区为止；薄格可省，不可跳过。
5. **误解两用**：C 区读后检验把话说准 / 读前当预习——两用都用，不只用一半。
6. **标准出处**：D 区查"这条原理出自哪个标准"；A/B 区查"这个概念怎么定义"——引用时写到条款号。
7. **答案方向**：E 区给"往哪个方向想、用哪把尺子"，不是唯一答案——不照抄。
8. **学习闭环**：遇到任何一题答不上来，先回对应章节，再回这五个抽屉。

### 纠错红线十条

1. **先表态后翻案**：先让学员说"附录可有可无，这还用讨论吗"，再翻，不让结论先入。
2. **反转精确不造新误解**："该查时查全"别翻成"查得越勤越好 / 什么都要查"；"附录不新增概念"别翻成"附录没内容 / 不用学附录"；"掌握 = 该查时查全"别翻成"每次都查一遍才叫负责"。
3. **判据配机制**：每条反转都有"为什么"（机制）和"怎么当场验证"（判据）。
4. **归责到可对照动作**：把"没掌握附录"落到"该查时没查 / 查了没查全 / 把字典当全书读"三个可对照动作，不归咎"记性差"。
5. **教机制不教断言**：教"为什么该查时查全"（尺子收容所 + 测试效应 + 遗忘曲线），不教"多查就对了"。
6. **先立尺子再翻案**：先给"该查时查全"三态 + 八判据，再翻"附录可有可无"。
7. **拉开强度层次**：★★★ 常识（附录可有可无 / 真懂从不查 / 背熟 = 会用）重点翻。
8. **每个纠正落到可操作动作**：讨论完给"回去做一件事"（如用附录 A 查一个刚说错词的指称，回 C 区预习下一章）。
9. **单一权威不另立标准**：判据引用书（八把使用判据），不发明新尺子。
10. **网搜当佐证**：N1~N7 只作"这不是书里一个人的说法"佐证，药与判据全在书内。

## 第 6 步 · 化尺为用：落地工具

### 作业指南（主产出）：用"该查时查全"把部门最近一次概念争论查清楚

> 目标：把"该查时查全"从一句话变成一次可照着做的查全动作——选一个你们部门最近争论过 / 说不清 / 跨域对不上的词或标准，用五个抽屉把它查全，产出三件可执行改进。
> 场景：回部门落地。时长：一次 45 分钟；两周后复查。

1. **选一个词（先立枢纽）**：选"最近在部门里争论过 / 说不清 / 跨域对不上"的词——最常被争论的词，往往正是查全价值最大的词。
2. **抽屉一 · 术语宪法（A）**：翻开附录 A 查这个词的编号 / 英文 / 一句话定义 / 主章——它指称的是哪个概念？是不是同名异物？**话术**："我们先定这个词指称的是哪个概念，再谈别的。"
3. **抽屉二 · 档案字典（B）**：若在 33 张卡里，从①定义到⑧误区逐格过；不在则回主章概念卡——薄格可省、不可跳过，尤其⑧误区格：最容易切错的那刀。
4. **抽屉三 · 误解清单（C）**：在附录 C 找这个词所在章行，读"病 → 药 → 判据"三栏——读前预习 / 读后检验两用都做了吗？把话说准了吗？
5. **抽屉四 · 标准出处（D）**：这条原理出自哪个标准？在附录 D（参考文献总表，单一权威）找到锚定它的标准 / 文献——版本号是正文实际引用的版本，引用时写到条款号。
6. **抽屉五 · 答案方向（E）**：若与某章练习相关，翻 E 的答案要点——给的是"往哪个方向想、用哪把尺子"，不是唯一答案。
7. **跨域先查表**：这个争论是不是跨域对不上的词（像恒信"合同编号" vs 冰链"数据所有权"）？查表后还吵吗？——先查再谈，比先争省时间。
8. **出查全报告**：五抽屉各查到了什么、这个词的正确用法一句话、你们部门最该改的一个动作（如把口头定义改成回表确认）。

**卡住怎么判断**：答不上来的那一格就是该查的格（检索练习标准）；查了还吵 = 没查"指称"（同一个词两个所指）；五抽屉都不用查 = 这个词你们正在用、随手能调用——那就对了，该查时查全不是每次量全。

### 工作检查单（配套素材）

| 检查项 | 是/否 | 否 → 可讨论发现 |
|---|---|---|
| 遇到说不清的词先查 A/B 了吗？（该查时查全） | □ | 凭感觉讨论 = 词汇病复燃 |
| 术语表是唯一权威吗？（术语宪法） | □ | 正文与表冲突时听表——"凡是正文用词以本表为准" |
| 跨域对不上的词先查表再谈？（跨域先查表） | □ | 恒信"合同编号" vs 冰链"数据所有权"——同一个词两个指称 |
| B 区从①定义到⑧误区、薄格可省不可跳过？（档案字典） | □ | 跳过误区格 = 最容易切错的那刀没人警告 |
| C 区读后检验 / 读前预习都用了吗？（误解两用） | □ | 只当预习 = 没把话说准的检验环节 |
| 查"出自哪个标准"到 D、查"怎么定义"回 A/B？（标准出处） | □ | 两个抽屉回答两个不同的问题 |
| E 区答案要点给的是方向不是唯一答案？（答案方向） | □ | 照抄 E = 把方向当标准答案 |
| 题答不上来先回章节再回抽屉？（学习闭环） | □ | 跳过章节直接查 = 查错"它" |

### 第一组 · 概念与原理（5 题）

**Q1（破题 · 见树见林① · 概念本身）**

追问：① 该查时查全 vs 每次量全 vs 从不查——三种态度各自错在哪？② "该查时查全"是不是说"查得越勤越好"？什么时候"不必查"反而是对的（正在用的、随手能调用的、已内化的）？③ 反身：你们部门最近一次"这个词什么意思"的争论，是查了，还是争了？

**Q4（真悖论 · 背熟 vs 查 / 从不查 vs 每次量全）**
"『真懂的人从不查表』和『背熟术语表 = 会用』——这两句是同一个直觉的两面：把『查』当『不熟』。可这一章说：掌握 = 该查时查全，不是每次量全、不是从不查。哪个对？什么判据区分『该查』和『不该查』？"
追问：① 术语宪法的功能是"查"不是"背"——遇到同词异义（如恒信"合同编号" vs 冰链"数据所有权"），背过的人为什么还要回来查表？② "查"在什么场合是负价值（每次量全：逢词必查、打断思路），什么场合是正价值（该查时查全：说不清 / 要检验时）？③ 反身：你们团队有人"从不查"某个规范 / 标准，靠的是记忆还是运气？

**Q5（真悖论 · 字典是读的还是查的）**
"字典是读的还是查的？——附录 B 开头画了一张『九格 = 四问的展开』：它是什么＝①定义、不是什么＝⑥⑦辨析、从哪来＝②③⑨、往哪去＝④⑤⑧。有人把 B 从①背到⑧、每格都记，觉得这才叫『查全』；可 B 区说字典式查询『薄格可省，不可跳过』。『可省』和『不可跳过』听起来像打架——到底省什么、不跳过什么？什么判据分清『该查哪格』和『哪格可以省』？"
追问：① 字典式查询从①定义开始到⑧误区为止——为什么必须从定义开始？② "薄格可省"省的是内容薄的格（定义已够用），"不可跳过"不可跳过的是判断本身——尤其⑧误区格：最容易切错的那刀没人警告，跳过误区格 = 把最容易错的地方跳过去了？③ 反身：你们上次查一个概念档案，是查缺的那格，还是从头背到尾？

**Q9（方法时刻 · 规则 15 · 该查时查全 + 转述）**
"这一章的方法底座时刻就是『该查时查全』本身——附录不新增任何概念，它的掌握标准就是它的内容。请亲手做一次『该查时查全』练习：① 从附录 A 挑一个你刚学过的词，用 B（档案）/ C（误区）/ D（出处）/ E（答案方向）四抽屉把它查全一次；② 或者：把你们部门最近一次『复习』改成『检索练习』——不重读，直接合上书回答『这个概念的定义 / 误区 / 出处』，答不上来的那格，就是你要查的格。③ 最后加一道转述测试：用三五句话把『附录是干什么的』讲给一个完全外行的人——讲到哪卡住，缺口就在哪。做完对照『该查时查全 vs 每次量全 vs 从不查』三态——你落在哪个态？"
追问：① 你查的这个词，最容易被切错的误区格是哪格（B 卡⑧ / C 区行）？② 你的"检索练习"暴露了哪格没查全——该查时查全的标准是什么（答不上来的那格 = 该查的格）；附录收束说"概念是刀，系统是大象"——你这次查全是在"磨刀"，还是"数刀"？③ 转述：你讲"附录是干什么的"时，会不会自然用上"尺子收进抽屉 / 刀和大象"的比喻？讲不清 = 五抽屉结构没成型，卡壳处 = 那个抽屉的边界或用途缺口。④ 反身：你刚才是"该查时查全"，还是"每次量全"（从头到尾全读）？——有标签是见过，该查时查全才算拥有。

**Q10（落地生根 · 回部门"查全体检"）**
"结合你们部门现状，用『该查时查全』给部门做一次『查全体检』——选出最近一次『说不清 / 跨部门争论 / 引用标准只写名字』的事，用五个抽屉把它查全，给出最该改进的三件事，每件落到一个动作。"
追问：① 五抽屉先查哪两个（最常被争的词查 A/B，最常被引错的标准查 D）？② 你们部门有没有"从不查"/"每次量全"的人——怎么用"该查时查全"纠正（该查时查全不是查得越勤越好，也不是从不查）？③ 两周后回来报告：查全了哪个词 / 哪条标准、部门改了什么动作？
