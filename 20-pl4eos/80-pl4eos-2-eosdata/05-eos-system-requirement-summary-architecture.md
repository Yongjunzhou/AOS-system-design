## 3. 规则区 / 口径区

### 3.1 功能部分生成规则

1. `wft03` 只将 `首次出现` 的 bpd-biz末级节点生成为 srh-biz末级节点。
2. `非首次出现` 的 bpd-biz节点不重复生成 srh-biz，只在映射和复用说明中登记。
3. srh-biz默认按 `业务定义类型 → 具体业务定义` 组织。
4. 仅当同一类型下节点过多、语义差异过大或 pa-eng承接边界不清时，才增加可选中间聚合层。
5. 每个 srh-biz末级节点应能追溯到来源 bpd-biz IPO 和对应 业务概要末级节点。

### 3.2 非功能部分生成规则

1. 非功能需求不经过 bpd-biz，直接从 bph-nfr 详细定义末级节点映射。
2. SysReq-NFR 应保留可验证量化指标，并明确对 pa-eng的约束。
3. NFR 分类应优先引用 `22-eos-nfr-taxonomy.md` 中已确认分类。

### 3.3 状态口径

| 节点类型 | 状态口径 | 推荐状态 |
|----------|----------|----------|
| 非末级节点 | 分类方案是否稳定 | 待确认分类 / 分类已确认 / 分类迭代中 |
| 末级节点 | 是否可进入产品架构设计 | 待产品架构 / 已产品架构 / 迭代中 |
