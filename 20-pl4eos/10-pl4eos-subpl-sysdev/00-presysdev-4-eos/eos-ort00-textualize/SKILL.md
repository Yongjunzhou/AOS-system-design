# eos-ort00 · 原始需求材料 → 文本化文档 · 纯文本化与原料登记

> **设计依据**：[eos-ort00-textualize.md](../eos-ort00-textualize.md)（人类方案——权威源）
> **领域规范**：[91-eos-biz-eng-spec.md](../10-wfsysdev-4-eos/91-eos-biz-eng-spec.md)

## 一、职责定位

### 负责与不负责

| 负责 | 不负责（路由指向） |
|------|-------------------|
| 扫描 `10-raw-files/`，发现未文本化的原始材料 | OR 语义切分、切分方案 → `eos-ort01-chunk` |
| 执行纯格式转换（PDF/图片/文本→Markdown 工作副本） | 模糊需求澄清 → `eos-ort02-clarify` |
| 正文区全文精确查重，重复材料→软链接文档+`已废弃（重复）` | OR 条目规范化/分类/编号 → `eos-ort03-norm` |
| 维护状态文档表 A（登记/文本化/废弃） | 修改/摘要/解释/补充原始需求内容 |
| 输出行动清单（待选入切分清单+重复通知+下一步指引） | — |

**核心原则**：AI 在本步是"转录者"而非"理解者"——文本化只改变载体格式，不改变内容。

---

## 二、操作流程

### Step Start · 前置校验

按顺序校验，首次遇缺即处理：

1. 检查 `../../80-pl4eos-2-eosdata/00-origin-requirement-materials/` 存在
2. 检查 `10-raw-files/` 存在
3. 检查 `01-eos-sysdev-status.md` 存在——不存在则创建 OR 阶段表 A/B/C
4. `10-raw-files/` 为空 → 输出"请将原始材料放入后重新启动" → 结束
5. 全部就绪 → Step 1

### Step 1 · 材料发现与登记

1. 扫描 `10-raw-files/` 中的文件
2. 跳过规则：

| 条件 | 动作 |
|------|------|
| 文件名以 `.textualized.md` 结尾 | 跳过（本步产物） |
| 文件名包含 `.chunk-` 且以 `.md` 结尾 | 跳过（下游切分文档） |
| 表 A 已有记录，生命周期≠空 | 跳过（已在流程中） |
| 表 A 无记录 | 登记：`生命周期=已登记`，`AI建议=可以切分` |

3. 无新材料 → 输出"所有材料已文本化" → 结束

### Step 2 · 文本化与查重

**1. 文本化转换**——逐源文件执行格式转换：

| 场景 | 处理 |
|------|------|
| PDF 表格 | 转 Markdown 表格，保留行列结构 |
| 图片/扫描件 | 识别文字内容，标注 `[AI 识别，待人工确认]` |
| 录音转写 | 标注发言人+时间戳，无法确认标 `[听写不清]` |
| 手写内容 | 可辨识标 `[AI 推测]`，不可辨识标 `[原文模糊]` |
| 完全无法识别 | 占位符 `[图片：无法识别文字内容]` |
| 文档明显不完整 | 文档开头标 `[文档疑似不完整]` |

**2. 查重检测**——新文本化正文区与既有文本化正文区逐字精确比对（忽略行尾空白和连续空行差异）：

| 结果 | 处理 |
|------|------|
| 无重复 | 输出文本化文档；表 A→`生命周期=已文本化`、`AI建议=可以切分` |
| 重复 | 输出软链接文档（正文区仅定向引用）；表 A→`生命周期=已废弃（重复）`、`AI建议=已废弃（重复）` |

**3. 三区文本化文档写入**：

| 区域 | 内容 |
|------|------|
| 管理区 | 状态摘要表（阶段/AI建议/待处理/操作指引） |
| 正文区 | 纯原文（无标注、无方案块） |
| 历史区 | 空（本步无历史归档） |

**同步契约**：AI 每次写入时**先更新状态文档表 A（权威源），再从表 A 推导写入文本化文档管理区**。

### Step End · 运行结束输出

输出行动清单：

```text
══════════════════════════════════════════
  eos-ort00 本轮完成 · 行动清单
══════════════════════════════════════════

● 本轮已文本化：[文件名] → 文本化完成
● 本轮发现重复：[文件名] → 与 [源文件名] 完全重复

━━━ 待选入切分 ━━━
打开 状态文档 → 表A：
├─ 选入切分 → 设 人类决策=同意切分
└─ 暂不切分 → 设 人类决策=暂不切分

━━━ 下一步 ━━━
选入切分的文档运行 eos-ort01-chunk
```

## 三、重进入规则

| 场景 | 处理 |
|------|------|
| 新增原始材料 | 无对应表 A 记录 → 进入文本化 |
| 重新文本化 | 无下游消费时清除表 A 生命周期值替换副本；已有下游消费时先输出变更影响声明再重跑 |
| 重复误判 | 清除表 A 生命周期值，删除软链接文档，重跑 |
