## 一、职责定位

| 负责 | 不负责（路由指向） |

### Step 3 · 配置页面设计

#### Phase A — 页面候选生成与宿主匹配

逐非占位 CU 按配置能力要素生成五类页面候选，然后按 `引擎+CU+页面类别+页面职责` 匹配已有 SR-F：

| 条件 | 路由 |
|------|------|
| 页面类别+职责落入已有 SR-F，布局需求可兼容 | 归入 → Phase B |
| 不满足 | 待聚合池 → Phase C |
| 页面职责冲突或同一 CU 被多个页面争用 | `[需裁决]` |

#### Phase B — 修订已有 SR-F

1. **要素提取**——从本轮 CU 提取页面职责、布局线索和操作活动候选
2. **宿主匹配检查**——复用→追加来源；扩展→全量重写保留历史；冲突→`[需裁决]`
3. **重判定与关系检测**——基于全部 CU 重判页面类别与布局组合，比对基线判定六种关系：

| 关系 | 判定 | 处理 |
|------|------|------|
| 确认 | 页面匹配+类别/布局一致+来源升级 | 追加 BP/CU 来源 |
| 无新增 | 页面匹配+全部已确认 | 增量合并细节 |
| 页面职责扩展 | 类别一致+操作活动/PA收敛项边界扩展 | 全量重写，保留历史 |
| 布局组合变更 | CU配置能力变化导致布局不同 | 更新布局+重判构件 |
| 补充 | 页面不匹配 | 新增配置页面 SR-F |
| 过时 | 基线页面未被本轮覆盖 | `[过时]`+保留不删 |

4. **变更影响声明**——判定变更类型，写入 SR-F 末尾

#### Phase C — 新建 SR-F

1. **确定页面类型与类别**——页面类型固定为配置页面；按配置职责判定五类之一
2. **判定布局组件**——独立判断页面需要的布局组件组合（附录 A.3）
3. **定义页面职责**——页面类别 + 用途 + 配置对象 + 使用角色
4. **设计操作活动**——逐活动定义十字段（附录 A.5）
5. **标注 PA 层收敛项**——组件边界/接口/存储/运行机制/NFR 均标注
6. **组装 SR-F**——写入 `05-*.md`

---

### Step 4 · 功能架构与操作活动

**1. 页面功能架构**——TAB/导航顺序、主子页面关系、页面间跳转与上下文传递、权限/状态/版本/发布依赖、追溯矩阵（页面→CU→配置能力→运行期能力）。

**2. 操作活动设计**——先按四类构件检查覆盖（附录 A.4），再为相关构件定义操作活动。五类活动（附录 A.5），十字段全量 `[推断]`。

**3. PA 层收敛项**——逐活动检查五类（附录 A.6），存在则写入 `PA层收敛-*` 标记。本 Skill 不设计组件——只传递待处理问题。

**4. 要素机械检查**——TAB/导航/主子/跳转已定义、权限/状态/版本/发布依赖已标注、追溯矩阵完整、操作活动十字段齐全、PA 收敛项已标注、所有非占位 CU 均被页面承接。

---

### Step 5 · 覆盖自查与变更声明

**八项覆盖自查**：CU覆盖 / 配置入口覆盖 / 配置要素覆盖 / 系统处理覆盖 / 运行期能力覆盖 / 构件线索覆盖 / 追溯覆盖 / PA收敛项覆盖。

**缺口处理**：

| 缺口类型 | 处理 |
|----------|------|
| 配置入口或要素未覆盖 | 补充页面或退回 wft02-eng |
| 系统处理未覆盖 | 补充操作活动或标注 PA 收敛 |
| 运行期能力未覆盖 | 补充运行支撑页面或说明由 biz 承接 |
| 构件线索缺失 | 补充按钮/右键/快捷键/图表/钻取线索 |
| PA 收敛项缺失 | 补充收敛项，不推进到可消费 |

## 附录A：判据速查

### A.1 配置页面五类别

| 页面类别 | 用途 | 典型来源 |
|----------|------|----------|
| 配置维护页 | 维护 CU 配置要素 | 配置入口、配置要素 |
| 配置管理页 | 管理配置版本、状态、引用关系 | 系统处理、治理依赖 |
| 发布生效页 | 校验、发布、装载、回滚、停用 | 系统处理 |
| 运行支撑页 | 查看运行期能力、刷新、重试、异常 | 运行期能力 |
| 治理追溯页 | 审计、影响范围、引用关系、操作日志 | 横切治理依赖 |

### A.2 页面类型/类别/布局组件三维正交

| 维度 | 本 Skill 取值 | 来源 |
|------|-------------|------|
| 页面类型 | 固定为 `配置页面` | 91 规范 §1.2 |
| 页面类别 | 五类之一 | 91 规范 §8.3 |
| 布局组件 | 七种组合 | 91 规范 §四 |

### A.3 布局组件判定

| 判定条件 | 布局组件 |
|----------|----------|
| 多条配置对象或版本记录维护 | 多级横版 + 列表页面 + 辅助栏（可选） |
| 层级对象维护 | 多级横版 + 列表页面（树表）+ 辅助栏（可选） |
| 单个配置对象编辑 | 多级横版 + 单据页 + 辅助栏（可选） |
| 主配置与子规则强相关 | 多级横版（双窗）+ 列表页面/单据页 + 辅助栏（可选） |
| 发布/装载/回滚或运行状态处理 | 列表/指标/看板页面 + 单据页/弹窗页 |
| 审计/引用关系/影响范围追溯 | 列表/指标页面 + 辅助栏（可选） |
| 临时选择/确认/局部参数/冲突处理 | 弹窗页 |

### A.4 构件完整性四分类

| 类别 | 典型构件 |
|------|----------|
| 展示类 | 列定义、字段布局、图表类型、卡片、树节点、阶段/里程碑 |
| 交互类 | 功能按钮、右键菜单、快捷键、下钻、行选中、TAB 切换 |
| 数据类 | 筛选器、排序器、分页器、导入、导出 |
| 反馈类 | 通知提示、进度条、状态标签、校验提示 |

### A.5 操作活动五类十字段

| 活动类型 | 典型动作 | 适用页面 |
|----------|----------|---------|
| 配置维护 | 新建/编辑/复制/删除/导入/导出 | 配置维护页 |
| 校验处理 | 校验/预览/冲突检查/依赖检查 | 配置维护/管理页 |
| 发布生效 | 保存/提交/发布/装载/回滚/停用 | 发布生效页 |
| 运行支撑 | 查看生效结果/刷新缓存/重试/异常处理 | 运行支撑页 |
| 治理追溯 | 查看版本/审计/引用关系/影响范围 | 治理追溯页 |

十字段：活动名称/操作入口/所属页面构件/前置条件/用户动作/系统处理摘要/结果状态/校验规则/异常处理/PA层收敛项。

### A.7 SR-F 完备性判据

| 检查项 | 判据 |
