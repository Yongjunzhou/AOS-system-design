# 每章重写分四个阶段（2026-09-26 定三阶段；2026-09-27 增设第一个阶段）

**用户原话（2026-09-27）**：「**修订手册中给出的修订过程是三个阶段，我希望增加一个阶段，而且是第一个，给出你认为本章的目的、目标、内容概要，我确认后再进入第二阶段**」。

| 阶段 | 产出 | 过的关 |
|---|---|---|
| **一、本章的目的、目标、内容概要** | **为什么写**（目的）／**写出来要达成什么**（目标）／**打算写哪些内容**（内容概要）——**在取料之前先把"这一章要干什么"立住**。**★ 读解基础＝四类（2026-09-27 用户定，读完再立）**：**① 书目录顶层全部 00 号文档**（16 md＋2 py，通读取规矩）**② 报告库所有研究报告与标准**（编号 00~34 含 7 份对话记录／库内标准正本／非编号件／`90-治理登记`，逐份过、每份给判定）**③ 本章之前的全部章正文**（第1章~第N−1章，读懂"讲到哪、立了哪些判据"）**④ 本章现行内容**（**通读但只作参考**，看清缺口与承接，不用它定目的） | **★ 展示（贴全文）**→ 对话确认 → 进阶段二 |
| **二、原料清单** | 本章重写要用的全部原料（版本·位置·用法）；取料＝四步（先读顶层全部 00 号文档 → 再逐份过报告库全库并每份给判定 → 后出清单；**现行内容仅作参考、不参与定清单**） | **★ 展示（贴全表）**→ 确认 → 进阶段三 |
| **三、本章框架** | 七件＝主张＋结构＋内容重做清单＋案例与对话＋比喻处置＋连带清单＋待裁事项 | **★ 展示（贴全文或逐条对照表）**→ 逐条确认 → 进阶段四 |
| **四、本章内容** | 按确认的框架写出正文（含章末件与全部连带） | **★ 展示（可读成稿＋改动与复算）**→ 确认 → **提交＋双推** |

**五条纪律**：① **阶段一不过，不取料**（不知道要写什么，就不知道要什么料）；② 阶段二不过，不设计框架；③ 阶段三不写正文；④ 阶段四确认之后才提交＋双推；⑤ 每一阶段的产出都要**先展示、后确认**——只给摘要、只给路径、或把一句"同意"当成对没展示过的东西的确认，都不算过关。

**一句话记法**：**目的与概要 → 原料清单 → 框架 → 内容，一阶段一确认；每一阶段先展示、后确认；未经确认，不进下一阶段、更不落库。**
