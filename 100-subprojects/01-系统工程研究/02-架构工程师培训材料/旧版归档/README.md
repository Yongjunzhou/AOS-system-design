# 旧版归档（培训材料 · 2011 口径存档）

> **⚠️ 本目录是存档，不是现状——勿引用、勿据以重派生。**

## 这是什么

本目录收的是**架构工程师培训材料被替换下来的一代旧单元稿**（v1.x 期）。它们的基线早于教材书 ch10~ch18 的七阶段重写，因此内容里保留着 ISO/IEC/IEEE 42010 **2011 版**的架构定义句法——即 `embodied in its elements, relationships`（中译"体现于其元素、关系"）那一版，以及此后的"五块设计清单"（基本概念／基本属性／设计准则／演进准则／元素关系）等已经废弃的骨架。

## 为什么留着

**它们是"2011 → 2022"这次变迁的一手留痕，属解药，不属痕迹。** 要看"当年讲的是哪一套、后来为什么塌了三根梁"，只有在这里能一次看全。

**现行口径**（2026-10-11 用户裁定后，全库统一）：

- **架构** ＝ 实体在其环境中的基本概念或属性，以及为实现和演化该实体及其相关生存周期过程的管控原则（42010:2022 §3.2）——**定义只给两样**；元素与关系**不在定义句内**，是架构"**可以关乎**"的对象（§5.2.2），其规格归下游设计定义过程（15288:2023 §6.4.5／§3.13）。
- **架构设计** ＝ 一个动作（把需求翻译成"架构"）＋两样内容（基本概念或属性＋管控原则）＋一次表达（架构描述）＋一条链。
- **三条本性**：概念幸存／属性涌现／原则自加（"关系克制"已退出本性集，降为**落点纪律**）。

## 纪律

1. **不改**——存档件正文一字不动。
2. **不引**——现行培训材料、教材书、课件、成书均不得引用本目录表述。
3. **不据此重派生**——重萃取一律以定稿正文与现行训侧件为准。
4. 现行培训材料为 **17 单元**（`01-单元一`…`17-单元十七`），见上级目录 `00-培训教材-总览.md`。
