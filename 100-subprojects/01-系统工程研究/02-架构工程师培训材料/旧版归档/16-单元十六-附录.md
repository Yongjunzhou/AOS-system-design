## 一、单元导读

### 主题

"读完十四章，就掌握这本书了吗？"——**附录不新增任何概念——它只是把正文发过的尺子（概念、判据、案例）收进五个抽屉，供你随时回来取用**。五个抽屉：**A 术语表**（宪法——凡正文用词以本表为准）、**B 档案集**（规格——16 张最常被查、最容易误解的完整九格）、**C 误解清单**（警示——14 章病/药/判据）、**D 标准索引**（出处——按"锚定哪个概念"编排）、**E 练习答案**（对照——要点给方向不是唯一答案）。**九格是"该查的时候查全"的尺子——这五个抽屉，就是那个"查"字落地的地方**。掌握 = 该查时查全，不是每次量全、也不是从不查；遇到任何一题答不上来，先回对应章节、再回五个抽屉。

### 开场破题

念出附录的第一页给谁用：

**读完了十四章**，Ada 问老周："工程的定义？"老周脱口而出："科学原理×判断创造，在约束下，用系统方法，造出有用且安全的东西。""它和手艺、科学、艺术各差在哪？"老周顿住了："我学的时候会，现在有点模糊。"Ada 翻开书末那五个抽屉："九格是'该查的时候查全'的尺子——这五个抽屉，就是那个'查'字落地的地方。"

**三千公里外**，冰链实验室。疾控审计员复查批次追溯，问："这批补采的记录，采集时间戳是哪来的？"老周答设备本地时钟，云端工程师答服务器时间归档——一个箱子，两个时间。小林说："上次我们把中间那条缝变成了一站。这次别凭印象——书末抽屉里，'数据所有权'这个概念的档案在 B、它的出处标准在 D、它最容易切错的地方在 C。该查时查全。"

让各组表态：一本书读完了，三个月后遇到"学的时候会"的词，是翻书/翻表，还是凭印象答？——"读完了"和"说得准"，之间差了什么？

### 本单元要反转的直觉

- **概念学过一遍就掌握了，用不着查**（× 掌握 = 该查时查全——需要判断时查全；五个抽屉是"查"字落地的地方；学到的东西要能随时回来取用）
- **附录就是字典/参考文献，读完正文就不用看它**（× 附录是学习闭环的一部分——C 读前预习、读后检验；E 对答案；遇到题答不上来先回章节再回抽屉）
- **术语表是给翻译看的，跟我们无关**（× 术语表是"术语宪法"——凡正文用词以本表为准；同词异义回到本表看指称——词汇病的药房）
- **查档案集 = 抄答案，背下来才是本事**（× 查档案是把话说准——B 字典式查询完整九格；行家的本事是"该查时查全"不是背下来）
- **误解清单读一遍"知道了"就行**（× C 是两用——读正文前当预习、读完后当检验（把话说准了吗）；不是"知道了"，是"说得准"）
- **标准索引是参考文献列表，摆摆样子**（× D 按"锚定哪个概念"编排——查"这条原理出自哪个标准"到这里；概念锚定标准、单一权威不另立）
- **练习对完答案就完事，答案就是标准答案**（× E 答案要点给的是方向不是唯一答案——考的是有没有把话说准）
- **查表是丢人的事——行家都靠记**（× 该查时查全是九格尺子的本意——不是每次量全、也不是从不查；行家恰恰在该查时查全）

### 本轮题卡的内在逻辑（10 题 2×5）

**第一组 · 概念与原理（先立概念）**：Q1 附录是什么（概念本身·破题·"不新增任何概念"）→ Q2 五个抽屉关系 + 与正文关系（概念关系·单一权威）→ Q3 该查时查全 vs 每次量全（真悖论）→ Q4 附录=字典 vs 学习闭环（真悖论）→ Q5 查=抄答案 vs 把话说准（真悖论）。由"是什么"走到"为什么"。

**第二组 · 落地与实践（用尺量）**：Q6 恒信编号·术语宪法 + 跨域先查表（真悖论）→ Q7 C 误解清单两用（预习/检验）→ Q8 质量·标准出处（真悖论）→ Q9 训练题卡·同源/学习闭环 → Q10 回部门"词汇体检"（落地生根）。判据运用 + 落地动作。

### 同类分组说明

产品组与 IT 组答同一组题，答案互为镜像——而这一章的镜像，长在附录里：**C 误解清单 14 章、E 答案要点 14 章，恒信（跨部门业务流程系统）与冰链（硬件×软件冷链温控箱）在所有抽屉里并排可查**。产品组从冰链这侧读（固件基线查 B、时间戳口径=数据所有权查 A、断链事故误解查 C、ISO 10007 查 D、批次追溯练习对 E），IT 组从恒信这侧读（编号术语查 A、合同系统档案查 B、编号事故误解查 C、ISO 9000 查 D、编号练习对 E）。这正是第14章"概念跨域成立"的第一落点——**遇到跨域对不上的词（恒信"合同编号" vs 冰链"数据所有权"），先查术语表看指称的是哪个概念，再谈别的。**

## 二、题卡（打印分发）

**答题要求**：组内讨论 25 分钟 / 答案 ≤5 行 / 上台讲解 4–5 分钟 / 观点不同必须给理由。

### 第一组 · 概念与原理

**Q1｜附录发的是什么？为什么说它"不新增任何概念"？**
"读完了十四章，Ada 问老周：'工程的定义？'老周脱口而出：'科学原理×判断创造，在约束下，用系统方法，造出有用且安全的东西。''它和手艺、科学、艺术各差在哪？'老周顿住了：'我学的时候会，现在有点模糊。'Ada 翻开书末那五个抽屉：'九格是"该查的时候查全"的尺子——这五个抽屉，就是那个"查"字落地的地方。'——附录发的是什么？为什么说它"不新增任何概念"？"

追问：① 反直觉命题：附录不新增任何概念——它只是把正文发过的尺子（概念/判据/案例）收进一个随时能回来取用的地方？正文发的是概念，附录发的是什么（"怎么找回来"）？② 五个抽屉：A 术语表（宪法）/ B 档案集（规格）/ C 误解清单（警示）/ D 标准索引（出处）/ E 练习答案（对照）各管什么？③ 该查时查全 vs 每次量全：九格是"该查的时候查全"的尺子——遇到说不清的词翻 A/B、误解错在哪翻 C、原理出处翻 D、做完练习翻 E？不是每次量全、也不是从不查？④ 你们部门读完一本规范/手册，三个月后遇到"学的时候会"的词，是翻表/翻书，还是凭印象答？

**Q2｜附录 A/B/C/D/E 五个抽屉是什么关系？它们和正文是什么关系？**
"请给出 附录 A/B/C/D/E 五个抽屉的关系，再说明：它们和正文是什么关系？为什么说它们是同一把刀的五个部位（目录/规格/警示/出处/对照答案）？"

追问：① 五抽屉分工：A 是刀的目录（术语宪法——凡正文用词以本表为准）、B 是刀的规格（16 张完整九格字典式查询）、C 是哪把刀最容易切错的警示（14 章病/药/判据）、D 是刀的出处（标准索引按"锚定哪个概念"编排）、E 是刀法练得对不对的对照答案（要点给方向）？② 与正文的关系：正文发概念/判据/案例，附录发"怎么找回来"——不新增任何概念？③ 单一权威：术语表=宪法、判据以书和标准为准、训练/笔记引用书不各自维护——为什么权威要长在一处？④ 你们部门有没有"同一件事两处写、改一处漏一处"的文档？那个"漏"的代价是什么？

**Q3｜该查时查全，还是每次量全？**
"小林做需求评审，把九格尺子摊在桌上，从①定义到⑧误区每一格都要现场填满，填不满就认定'还没学会'。Ada 说：'九格是"该查的时候查全"的尺子，不是"每次量全"。'——那到底是该查时查全，还是每次量全？"

追问：① 该查时查全：遇到说不清的词翻 A/B、误解错在哪翻 C、原理出处翻 D、做完练习翻 E——需要判断时查全？② 每次量全：每次判断都要把九格过一遍、每一格都填满才算数？过度在哪儿（判断被尺子拖垮，该判的没判）？③ "每次量全才稳妥（把九格全部过一遍=覆盖完整、万无一失，漏一格的判断就是拍脑袋）" vs "该查时查全才高效（需要判断时查全，判断不需要的格不必过；五个抽屉就是为'该查时'准备的，不是为'每次'准备的）"——两个都对，靠什么判据分清？④ 你们最近一次评审/检查，是"该查时查全"、"每次量全"，还是"从不查"？

**Q4｜附录和学习到底是什么关系？**
"读完十四章，有人说：'附录就是字典/参考文献，用到再翻就行，跟学习本身没关系。'——附录和学习到底是什么关系？"

追问：① 字典式查询：B 是字典式查询——16 张最常被查、最容易误解的完整九格？② 学习闭环：C 读正文之前当预习、读完当检验（把话说准了吗）；E 做完练习对答案（与训练教材题卡同源）；遇到任何一题答不上来，先回对应章节、再回五个抽屉？③ "附录是字典，用到再翻就行（参考书本来就是按需查询的，不需要主动学——它不新增概念，所以不在学习内容里）" vs "附录是学习闭环的一部分（C 预习/检验、E 对答案、题答不上来先回章节再回抽屉——它是'查'字落地的地方，是学习过程的收尾，不是学完之后才出现的摆设）"——两个都对，靠什么判据分清？④ 你们用参考资料，是"用到才翻"，还是把它当成学习过程的一部分（预习/检验/复盘）？

**Q5｜对答案到底在对什么？**
"小林做练习，对完附录 E 的答案要点，发现和自己的不一样，急得把答案改成了要点的原话。Ada 说：'要点给的是"往哪个方向想、用哪把尺子"，不是唯一答案。'——那对答案到底在对什么？"

追问：① 方向原理：答案要点给的是"往哪个方向想、用哪把尺子"——考的是有没有把话说准，不是背标准答案？② 对/错速查：自查只给对/错判定，理由随章已给；答案要点与训练教材题卡同源？③ "查档案/对答案 = 抄答案（答案在那，照着抄准没错；背下来才是本事，考试考的就是背得准不准）" vs "查 = 把话说准（答案给的是方向不是唯一答案；考的是你有没有把话说准——方向对了、话术是自己的，才算会）"——两个都对，靠什么判据分清？④ 你们部门对"参考答案/标准模板"，是抄原话，还是对方向？抄出来的和说准的差在哪？

### 第二组 · 落地与实践

**Q6｜为什么遇到跨域对不上的词，要先查术语表再谈别的？**
"恒信开会讨论'编号对不上'。财务说'编号是 CA 来的'，法务说'编号按法务归口的编号标准'，IT 说'编号是系统生成的'。三个人三个说法，越吵越大声。Ada 说：'先别吵——翻书末附录 A，看"编号"这个词指称的是哪个概念。'——为什么遇到跨域对不上的词，要先查术语表再谈别的？"

追问：① 术语宪法：术语表是"术语宪法"——凡正文用词以本表为准；遇到同词异义，回到本表看指称的是哪个概念？② 跨域先查表：遇到跨域对不上的词（恒信"合同编号" vs 冰链"数据所有权"），先查本表，再谈别的？③ 词汇病：第1章三类词汇病（说不出定义/同词异义/翻译伪朋友）——术语表是词汇病的药房？④ "同词异义靠上下文猜就行（开会嘛，听上下文就知道说的是哪个，查表打断讨论效率低）" vs "回到术语表看指称（上下文只能猜场景，表才钉住指称——恒信三个'编号'靠上下文各猜各的，越猜越吵）"——两个都对，靠什么判据分清？⑤ 你们部门最近一次"吵起来"的会，是不是同一个词各指各的？当时查过表/字典吗？

**Q7｜附录 C 是给什么时候用的？**
"学第9章架构之前，Ada 先翻了附录 C：'架构 = 一张框图，画完就完事'。学完之后她回来再看这行：'架构是系统不可还原的涵义；系统 ≠ 架构 ≠ 架构描述。'她说：'学之前看不懂这行字在说什么，学之后看懂了它为什么是陷阱。'——附录 C 是给什么时候用的？"

追问：① 两用原理：C 误解清单两用——读正文之前当预习、读完后当检验（把话说准了吗）？② 预习的用处：学之前看到"病"，带着问题去读正文，读到"药"时对上了？③ 检验的用处：学完之后回来，能说清"这行的病错在哪、药是什么、判据是什么"才算掌握？④ 你们部门学新标准/新规范，有没有"学之前先看它要破除什么误解"的习惯？

**Q8｜"常识"和"出自哪个标准"差在哪？为什么要按"锚定哪个概念"编排标准索引？**
"评审会上有人质疑：'你凭什么说质量 = 特性满足需求的程度？'老周说：'这是常识。'Ada 说：'书末附录 D 写着——ISO 9000:2015 §3.6.2。'——'常识'和'出自哪个标准'差在哪？为什么要按"锚定哪个概念"编排标准索引？"

追问：① 锚定原理：D 标准索引按"锚定哪个概念"编排——查"这条原理出自哪个标准"到这里；查"这个概念怎么定义"回 A/B？② 概念锚定标准：质量锚定 ISO 9000 §3.6.2、验证锚定 §3.8.12、评审锚定 §3.11.2——概念和标准是一对一的锚定，不靠"常识"？③ "常识够用（口头约定省事，能干活就行；把每条判据都追到标准，太重了）" vs "概念锚定标准（'常识'人人不同，标准才可追溯、可对齐——没有出处，评审会上三个人三种'常识'就吵起来）"——两个都对，靠什么判据分清？④ 你们部门常用的判据/规则，有几条能说出出自哪个标准？说不出的那几条，靠什么维持？

**Q9｜"答案要点与题卡同源"意味着什么？为什么答不上来要先回章节而不是先对答案？**
"训练教材的题卡做完，各组答案五花八门。有人问：'到底哪个是对的？'讲师翻开附录 E：'答案要点和题卡同源——给的是方向不是唯一答案；遇到任何一题答不上来，先回对应章节，再回五个抽屉。'——'答案要点与题卡同源'意味着什么？为什么答不上来要先回章节而不是先对答案？"

追问：① 同源原理：训练教材题卡与附录 E 同源——考的是有没有把话说准，不是背答案？② 学习闭环：遇到任何一题答不上来，先回对应章节、再回五个抽屉——为什么先回章节（正文发尺子）再回抽屉（附录收尺子）？③ 方向 vs 唯一答案：要点给"往哪个方向想、用哪把尺子"——方向对、话术是自己的才算会？④ 你们部门培训/考试对答案，是"对方向"还是"对原话"？

**Q10｜给部门做一次"词汇体检"**
"结合你们部门现状，用八把使用判据（该查时查全 / 术语宪法 / 跨域先查表 / 档案字典 / 误解两用 / 标准出处 / 答案方向 / 学习闭环）做一次'词汇体检'——列出部门最常见的十个术语，逐个问'我说得准一句话定义吗？说不准的翻哪张表？'，再给最该改进的三个事项，每个落到一个可检查动作。"

## 三、点评要点·讲师版

> 点评纪律：先表态后翻案 / 反转精确不造新误解 / 判据配机制 / 归责到可对照动作 / 教机制不教断言 / 先立尺子再翻案 / 拉开强度层次 / 每个纠正落到可操作动作 / 单一权威不另立标准 / 网搜当佐证。

### Q1 附录发的是什么？为什么说它"不新增任何概念"？

| 答案分级 | 形态 | 讲师判读 |
|---|---|---|
| 弱 | "附录就是术语表加答案，收尾用的。" | 正是要翻的——把附录当"收尾的字典" |
| 中 | "附录把概念收起来方便查。" | 结论对，五个抽屉分工/该查时查全说不清 |
| 好 | 反直觉命题（附录不新增任何概念——只是把正文发过的尺子收进随时能回来取用的地方）+ 五个抽屉分工（A 宪法/B 规格/C 警示/D 出处/E 对照）+ 该查时查全（需要判断时查全，不是每次量全、不是从不查） | 命题 + 五抽屉 + 查全全到位 |

**产品侧 vs IT侧**：产品组答"冰链读完 M3 相关的概念（数据所有权/基线/确认），三个月后说不清'补采时间戳按什么归档'——翻 B 的基线档案、C 的断链事故误解"；IT 组答"恒信读完十二个概念，三个月后说不清'编号来源'该归谁——翻 A 术语表看指称、C 的编号事故误解"。同一个"该查时查全"。

**反转话术**（对应附录定位 + 收束）：这一章（附录）和前面正文不一样——正文**发尺子**（概念、判据、案例），这一章**收尺子**（把发过的尺子收进五个抽屉，随时回来取用）。它不教你新东西，它教你怎么把学过的**找回来**。老周"我学的时候会，现在有点模糊"——不是学得不好，是该查时查全的本意。第1章说过：九格是"该查的时候查全"的尺子，不是"每次量全"。**这五个抽屉，就是那个"查"字落地的地方。** 附录收束那句话：概念是刀、系统是大象——A 是刀的目录、B 是刀的规格、C 是哪把刀最容易切错的警示、D 是刀的出处、E 是刀法练得对不对的对照答案。**切得再细，也要缝得回来。**

**参考答案要点**：附录定位见 §首 + §收束；五抽屉分工见附录 A~E 各节；该查时查全见附录首 + 第1章九格；判据 1/4。

### Q2 附录 A/B/C/D/E 五个抽屉是什么关系？和正文是什么关系？

| 答案分级 | 形态 | 讲师判读 |
|---|---|---|
| 弱 | "A 是术语、B 是档案……"（只报名字不分关系） | 正是要翻的——把五抽屉当五个独立清单 |
| 中 | "五抽屉各管一类。" | 结论对，同一把刀/单一权威说不清 |
| 好 | 五抽屉=同一把刀的五个部位（目录/规格/警示/出处/对照）+ 与正文关系（不新增任何概念，正文发尺子、附录发"怎么找回来"）+ 单一权威（术语表=宪法、判据以书和标准为准、不各自维护） | 五部位 + 正文关系 + 单一权威全到位 |

**产品侧 vs IT侧**：产品组答"冰链的五个抽屉——固件基线查 A、M3 档案查 B、断链事故误解查 C、ISO 10007 查 D、批次追溯练习对 E"；IT 组答"恒信的五个抽屉——编号术语查 A、合同系统档案查 B、编号事故误解查 C、ISO 9000 查 D、编号练习对 E"。同一个"一把刀的两个世界、骨相相同"。

**反转话术**（对应附录首 + 各抽屉 + 收束）：五个抽屉不是五件事，是**同一件事的五个部位**——A 是刀的目录、B 是刀的规格、C 是哪把刀最容易切错、D 是刀的出处、E 是刀法练得对不对。它们一起回答一个问题：**"怎么把学过的找回来"。** 所以附录收束说"它们不新增任何概念——它们只是把正文发过的尺子，收进了一个随时能回来取用的地方"。正文发的是概念、判据、案例；附录发的是"怎么找回来"。还有一个词值得钉死：**单一权威**。术语表是"术语宪法"，判据以书和标准为准，训练/笔记引用书、不各自维护——**权威长在一处，改一处不漂移**；各写各的，就是改一处漏一处。

**参考答案要点**：五抽屉分工见附录 A~E；不新增任何概念见收束；单一权威见附录 A 引言 + 训练总览；判据 2/4。

### Q3 该查时查全，还是每次量全？

| 答案分级 | 形态 | 讲师判读 |
|---|---|---|
| 弱 | "每次量全，把九格都过一遍才保险。" | 正是要翻的——把"查全"当"每次量全" |
| 中 | "该查时查全。" 结论对，过度/机制说不清 | 结论对，机制缺 |
| 好 | 该查时查全（需要判断时查全——遇到说不清的词翻 A/B、误解错在哪翻 C、原理出处翻 D、做完练习翻 E）+ 每次量全的过度（判断被尺子拖垮）+ 真悖论收束（每次量全 vs 该查时查全 → 判据该查时查全） | 查全 + 过度 + 收束全到位 |

**产品侧 vs IT侧**：产品组答"冰链评审固件升级，'补采时间戳口径'说不清时翻 A/B 查全——不是每次评审都把九格过一遍"；IT 组答"恒信评审'编号来源'说不清时翻 A 看指称——不是每次变更评审都从①定义量到⑧误区"。同一个"需要判断时查全"。

**反转话术**（对应附录首 + 第1章九格 + 判据1）：小林把九格摊开每格现场填满——这个动作本身没错，错在**"每次"**。九格是"该查的时候查全"的尺子：需要判断时查全（遇到说不清的词翻 A/B、误解错在哪翻 C、原理出处翻 D、做完练习翻 E），**不是每次判断都把九格过一遍**。每次量全 = 判断被尺子拖垮（该判的没判，全在填格）；从不查 = 凭印象拍脑袋（恒信的编号、冰链的时间戳，都是"该查时没查"）；该查时查全 = 需要时查全。**行家恰恰在该查时查全**——参考能力是专业能力的一部分，不是能力弱的表现。

**参考答案要点**：该查时查全见附录首 + 第1章九格；判据 1。

### Q4 附录和学习到底是什么关系？

| 答案分级 | 形态 | 讲师判读 |
|---|---|---|
| 弱 | "附录是字典，用到再翻。" | 正是要翻的——把字典当附录的全部 |
| 中 | "附录是学习的一部分。" 结论对，闭环机制说不清 | 结论对，机制缺 |
| 好 | 字典式查询（B 是字典式查询——16 张完整九格）+ 学习闭环（C 预习/检验、E 对答案、题答不上来先回章节再回抽屉）+ 真悖论收束（字典 vs 闭环 → 判据学习闭环 + 误解两用） | 字典 + 闭环 + 收束全到位 |

**产品侧 vs IT侧**：产品组答"冰链学'数据所有权'——学之前翻 C 看'改字段是小事'的误解、学完用 C 检验、批次追溯练习对 E 答案"；IT 组答"恒信学'架构'——学之前翻 C 看'架构=一张框图'的误解、学完用 C 检验、架构练习对 E 答案"。同一个"附录是学习过程的收尾，不是摆设"。

**反转话术**（对应附录 C/E + 学习闭环 + 判据5/8）："附录=字典"不全是错——**B 确实是字典式查询**。但字典只是五个抽屉里的一个形态；附录整体是**学习闭环的一部分**：C 读前预习、读后检验；E 做完练习对答案（与训练教材同源）；遇到任何一题答不上来，先回对应章节、再回五个抽屉。它不是学完之后才出现的摆设，是"查"字落地的地方——**学习过程的收尾**。只把它当字典，等于把"预习/检验/对答案"从学习里拿掉了，学到什么程度没人验证。

**参考答案要点**：字典式查询见附录 B；学习闭环见附录 E 引言 + 收束；判据 5/8。

### Q5 对答案到底在对什么？

| 答案分级 | 形态 | 讲师判读 |
|---|---|---|
| 弱 | "答案就是标准答案，对完就完。" | 正是要翻的——把"对答案"当"抄答案" |
| 中 | "答案给方向。" 结论对，把话说准说不清 | 结论对，机制缺 |
| 好 | 方向原理（要点给"往哪想、用哪尺子"——考的是有没有把话说准）+ 把话说准（方向对了、话术是自己的才算会）+ 真悖论收束（抄答案 vs 把话说准 → 判据答案方向） | 方向 + 说准 + 收束全到位 |

**产品侧 vs IT侧**：产品组答"冰链对'三类需求各有专属验证载体'练习——对的是'每类需求都答出用什么交付物验证'这把尺子，不是把要点原话背下来"；IT 组答"恒信对'规定需求'练习——对的是'可验证吗'这把尺子，不是抄要点的句子"。同一个"对方向不对原话"。

**反转话术**（对应附录 E + 判据7）：对答案**对的是方向，不是原话**——E 的要点给的是"往哪个方向想、用哪把尺子"，不是唯一答案。抄原话 = 话术被统一成模板（听着像标准答案，换个场景就答不上来）；对方向 = **话术是自己的才算会**（方向对了、话术自己长出来）。考的是有没有**把话说准**——把话说准不是背书，是用自己的话说对同一件事。与训练教材题卡同源：考的都是同一个"把话说准"。

**参考答案要点**：方向原理见附录 E 引言；判据 7。

| 答案分级 | 形态 | 讲师判读 |

| 弱 | "术语表是给翻译/文档用的。" | 正是要翻的——把术语表当翻译词典 |
| 中 | "同词异义要查表。" 结论对，跨域先查表/词汇病说不清 | 结论对，机制缺 |
| 好 | 术语宪法（凡正文用词以本表为准，同词异义回到本表看指称）+ 跨域先查表（先确定指称再谈对齐——合同编号 vs 数据所有权）+ 词汇病药房 + 真悖论收束（上下文猜 vs 回表 → 判据术语宪法 + 跨域先查表） | 宪法 + 跨域 + 药房 + 收束全到位 |

**产品侧 vs IT侧**：产品组答"冰链'数据所有权'和恒信'合同编号标准'跨域对不上——先翻 A 看各自主章与定义，确定指称的是同一个概念，再谈对齐"；IT 组答"恒信三个'编号'（CA 来源/法务归口/系统生成）——翻 A 看'编号'指称的是哪个概念，先钉住再谈"。同一个"先查表，再谈别的"。

**反转话术**（对应附录 A + 第1章词汇病 + 判据2/3）：恒信三个"编号"——财务说 CA 来的、法务说按归口标准、IT 说系统生成——**不是三个答案，是同一个词各指各的**（第1章词汇病第二型"同词异义"）。上下文只能猜场景，**表才钉住指称**。术语表是"术语宪法"：凡正文用词以本表为准，遇到同词异义回到本表看指称的是哪个概念。更进一步：**遇到跨域对不上的词（恒信"合同编号" vs 冰链"数据所有权"），先查本表，再谈别的**——先确定指称的是哪个概念，跨域对齐才谈得上。这就是第14章"概念跨域成立"的第一落点：跨域对齐之前，先回到术语表。

**参考答案要点**：术语宪法见附录 A 引言；跨域先查表见附录 A 引言；词汇病见第1章；判据 2/3。

### Q8 "常识"和"出自哪个标准"差在哪？为什么要按"锚定哪个概念"编排标准索引？

| 答案分级 | 形态 | 讲师判读 |
|---|---|---|
| 弱 | "标准索引是参考文献摆样子。" | 正是要翻的——把出处当装饰 |
| 中 | "概念要锚定标准。" 结论对，一对一锚定/单一权威说不清 | 结论对，机制缺 |

**产品侧 vs IT侧**：产品组答"冰链'配置'定义锚定 ISO 10007、'验证'锚定 ISO 9000 §3.8.12——不是凭常识，是查 D"；IT 组答"恒信'评审/验证/确认'锚定 ISO 9000 §3.11.2/§3.8.12/§3.8.13——三个看门人各有一对一出处"。同一个"概念锚定标准，不靠常识"。

**反转话术**（对应附录 D + 判据6）："这是常识"——三个人的常识三种说法，评审会就吵起来（恒信的编号、冰链的时间戳，都栽在"该查出处时没查"）。D 标准索引按**"锚定哪个概念"编排**：质量→ISO 9000 §3.6.2、验证→§3.8.12、评审→§3.11.2。**概念和标准一对一锚定，不靠"常识"**——"常识"人人不同，标准才可追溯、可对齐。这就是单一权威：判据以书和标准为准，不另立标准；出处可追溯，对齐才有依据。

**参考答案要点**：锚定原理见附录 D 引言；判据 6。

### Q10 给部门做一次"词汇体检"

| 答案分级 | 形态 | 讲师判读 |
|---|---|---|
| 弱 | 泛泛"多查资料、多对标准答案"。 | 没落到八把使用判据任何一把，不可检查 |
| 中 | 用一把尺子查出缺口（如"部门有个词各指各的""判据说不出出处"） | 有判据，但只照了一面 |
| 好 | 十术语逐句问定义 + 同词异义/跨域清单 + 两到三张九格 + 判据锚定清单 + 三件可检查动作 + 说出先做哪把尺子、两周后报告什么 | 体检完整，动作可执行，有复查机制 |

**产品侧 vs IT侧**：两组各给部门做词汇体检——体检表本身是同一份（八把使用判据），这正是"概念跨域成立"的现场证明：同一套尺子，一个硬件产品组、一个业务系统组都能用。

**反转话术**：这一章的判据不是彼此孤立的——该查时查全管"说不清的词翻 A/B 吗"（只凭印象=词汇病现场）、术语宪法管"同词异义回表钉指称吗"（各指各的=越吵越大声）、跨域先查表管"跨域对不上的词先查表再谈吗"（各说各的=对齐无从谈起）、档案字典管"最常误解的概念有完整九格吗"（薄格可省不可跳过）、误解两用管"学前预习、学后检验吗"（只读正文=把话说准了吗没人验证）、标准出处管"判据能说出出自哪个标准吗"（靠常识=三种常识三种说法）、答案方向管"对答案对方向还是对原话"（抄原话=换个场景答不上来）、学习闭环管"题答不上来先回章节再回抽屉吗"（凭印象绕过去=查证能力没建成）。**八把尺子合起来，才是一次完整的"词汇体检"。** 不用等全打完——找到第一个"否"，就能开工。

**参考答案要点**：八把使用判据见"本章判据"；作业指南见课后作业。

### 金句（附录 + 书"本章判据"提炼）

- **附录不新增任何概念——它只是把正文发过的尺子，收进一个随时能回来取用的地方。**
- **九格是"该查的时候查全"的尺子——这五个抽屉，就是那个"查"字落地的地方。**
- **掌握 = 该查时查全，不是每次量全，也不是从不查——行家恰恰在该查时查全。**

## 五、课后作业

1. **书练习（对答案看方向 · 用附录 E）**：从附录 E 挑一章练习（如第12章练习 1"配置三问检验客户可改参数"），**不看要点先做**，做完拿要点对"方向"——你差在哪把尺子上？（书练习 1，答案要点见附录 E）
2. **书练习（术语宪法 · 用附录 A + D）**：从附录 A 挑 5 个你们部门常用的术语，用一句话定义钉死（参照 T-01~96 格式），标注主章，再翻附录 D 找它锚定的标准——找不到的标"待锚定"。（书练习 2）
3. **回部门落地**：结合现状，用八把使用判据（该查时查全 / 术语宪法 / 跨域先查表 / 档案字典 / 误解两用 / 标准出处 / 答案方向 / 学习闭环）做一次"词汇体检"——列出部门最常见的十个术语，逐个问"我说得准一句话定义吗？说不准的翻哪张表？"，给最该改进的三个事项，每个落到一个可检查动作。**两周后回来报告**：哪一项做成了、哪一项卡住了、卡在哪把尺子上。

### 作业指南（回部门落地的步骤 + 话术）

> 照着做，1~2 小时内完成一次体检：
>
> 1. **该查时查全（尺1）**：列出你们部门最常见的十个术语，逐个问"我说得准一句话定义吗？"说不准的，翻 A 或 B 查全再判断。产出：术语清单 + 说不准的标注（这就是"该查时查全"的靶子）。
> 2. **术语宪法（尺2）**：同词异义检查——同一个词在部门里各指各的吗（像恒信"编号"三个说法）？回到参照表看指称的是哪个概念。产出：同词异义清单 + 每个词钉死的一句话指称。
> 3. **跨域先查表（尺3）**：跨部门/跨域对不上的词（像恒信"合同编号" vs 冰链"数据所有权"），先查参照表，再谈对齐。产出：跨域对照一例。
> 4. **档案字典（尺4）**：把部门最常被误解的两三个概念，按完整九格（①定义→⑧误区）各填一张——薄格可省、不可跳过。产出：两到三张九格档案。
> 5. **误解两用（尺5）**：学新概念前翻 C 预习（先看要破除的误解）、学完用 C 检验（把话说准了吗）。产出：一次预习/检验的实例记录。
> 6. **标准出处（尺6）**：把部门常用的判据/规则逐条问"出自哪个标准？"——查 D 锚定；查不到的标"待锚定"。产出：判据锚定清单（含待锚定项）。
> 7. **答案方向（尺7）**：对一次练习/评审问题的"参考答案"——对的是方向（往哪个方向想、用哪把尺子），不是原话。产出：方向核对记录一例。
> 8. **学习闭环（尺8）**：收尾问一句——遇到说不清的词/对不上的数/答不出的题，第一反应是"回对应章节、再回参照抽屉"，还是"凭印象/绕过去"？产出：一句判定 + 最该改的一处。
>
> 卡住时：找到第一个"否"就能开工，不必打完全部。产出三件最该改进事项（每条 = 一个可检查动作）。
