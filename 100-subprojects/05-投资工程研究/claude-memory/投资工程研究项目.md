**扫描版 epub 清洗经验（2026-09-19 第三份素材，可复用）**：该 epub 由纸书扫描件转制，两类结构性缺陷**同一个病根**——印刷分页处既把页眉（章名／书名）并进了正文，又硬插了一个段落断点，于是句子被切成两段、中间夹着页眉。量化：1691 个正文段中 156 处如此。清洗口径：
- **剥页眉**走两条路，缺一不可：①从各章 `<h1>` 与 `dc:title` 生成词典做模糊匹配（`difflib` 阈值 0.55，因 OCR 把「金钱进化论」识别成「金钱迸化讵」＝相似度 0.60）；②**数据驱动**——段首反复出现的短串即页眉，印刷页眉每页都出现，「重复」本身是最强证据，只有这条路才能抓到词典匹配不上的变形（「从极简主义到幸福哲学」被识别成「双毅筒主义到牵福皙学心」，相似度仅 0.36）。
- **修断句**双向判定：段末落在虚词／逗号上就接回下一段；段首是不成句的虚词（的／了／着）就接回上一段。**「地／得／过」绝不作判据**——「地球／地方／得到／过去」都是正常起句词。跨章标题的断口（13 处）把悬在标题前的残句移到标题后接上，保持全文顺序。
- 结果：剥页眉 190 处、段落合并 386 次、跨标题搬移 13 处、省略号归一 17 处、文字订正 272 处（184 词条）；正文 1281 段，段末无句末标点的 0 段。
- **判据要用「有没有句末标点」，不要用「是不是虚词结尾」**（2026-09-19 用户举反例后修正）：后者只抓到「…致以我／最真挚的谢意」这类，漏掉「…不太想让**孩子**｜们变成」这种上一段收在名词或动词上的断口。换成「段落结尾不是 。！？…"）」即判为硬切断」，一次抓出 76 处，逐条核验全是词被劈开（`惊涛骇｜浪`、`看见未｜来的我`、`分｜享`、`此情此｜景`、`竞争激｜烈`、`自｜己`），零误伤。
